# 地图传送与光照：手动测试副本

入口：`Tools → 2026TapTap → 测试 → 打开地图传送与光照测试场景`。

也可双击本目录 `MapVisibilityTest.unity`。按 Play 后直接进入地图测试，不经过正式开场或读档；地图会自动打开。

## 测试方法

1. 地图中拖动、滚轮缩放，点击已激活的普通重生点，检查拉远、平移、落位、拉近以及落地后的操作恢复。
2. T 开关地图，Esc 关闭。关闭地图后正常移动玩家，观察封闭房间隐藏、绕转角连通空间可见及门开闭效果。
3. 运行时用 `Tools → 2026TapTap → 测试 → 地图测试：开关光照` 比较效果；也可选择 Main Camera，在 `WorldVisibility2D` 中文 Inspector 中保持“连通空间可见”开启，调视线范围；默认24格。不依赖玩家灯、环境亮度或附加光源。
4. 修改静态碰撞后，可在该组件点击“刷新墙体遮挡缓存”。光照看 Game 视图，普通 Scene 视图不应用此后处理。
5. 结束后停止 Play。运行时调参会随退出 Play 恢复；需要保留的参数可记录后在编辑态填写。

## 副本与正式游戏的区别

- 这是 2026-10-20 当前正式 Gaming 的磁盘快照；Scene、同名 planning、美术数据各有副本，正式场景不受这些文件的直接编辑影响。Sprite、材质及预制体仍共用，直接编辑共用资产会影响其他场景。
- Editor 专用测试工具只识别本场景路径，临时开放地图、激活普通重生点；没有修改正式 30%＋击败 Boss 门槛。Boss 重生点及战斗/Boss 房禁用规则保留。
- 测试写入目录为 `Library/MapVisibilityManualTest`，单轮自动读档和开场协调器在本测试会话中关闭。成就服务使用临时配置副本，退出 Play 的最后保存也保持测试路径。
- 不从此场景跳到正式游戏继续测试；若场景发生切换，工具会停止本次 Play，避免临时进度串用。
- 未加入 Build Settings；只有 Editor 测试辅助，不能拿此副本作为正式发布入口。
- 后续正式地图更新不会自动覆盖本副本。需要最新版时，应停止 Play 后重新复制正式 Scene、planning、美术数据并重新指向副本美术 GUID，保留本目录测试工具；不把旧测试图覆盖回正式 Gaming。
