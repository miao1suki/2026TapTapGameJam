# 井喷蒸汽特效

独立的 URP 一次性蒸汽喷发模块。资源不修改水体或颜色系统代码，也不依赖场景对象。

## 资源

- `SteamBurst.shader`：半透明 URP Unlit 粒子 Shader，使用流动噪声扭曲边缘，模拟翻卷的蒸汽团。
- `SteamBurst.mat`：Shader 默认材质。
- `SteamBurstEffect.cs`：运行时生成集中喷柱、短促亮芯和上方展开的雾冠三组粒子，形成鲸鱼喷水般的轮廓；向上喷发后在 `0.82` 秒内消散并销毁。
- `SteamBurst.prefab`：可独立实例化的一次性特效预制体。

## 接入

`Blue_WaterSource`、`Blue_WaterWay` 和 `Blue_WaterBubble` 三种蓝色水体功能预制体均已将 `SteamBurst.prefab` 指定到 `WaterVisualFeature` 的“热浪特效”字段。以后从这些预制体新放置的水源、水流和浮力柱会自动带上该效果；Test 场景里已有的对应实例也继承此配置。运行时收到红色染色反应时，会在水体 Collider 顶面中心生成蒸汽。蒸汽外观自身不到 1 秒消散；已有水体反应组件仍负责推力和反应计时。

在 `SteamBurst.mat` 的 Shader 属性中通过“效果大小”控制整团蒸汽粒子的尺寸与扩散范围，范围为 `0.5–3`，默认值 `1.6`；该值会在蒸汽触发时由特效组件读取并应用到粒子尺寸和喷发宽度。“喷发高度”范围为 `0.5–4`，默认值 `1`，在触发时按倍率调整三层粒子向上的初速度；数值越高，生命周期内上升越高，但消散时间不变。同一面板里的“雾气浓度”同时控制蒸汽不透明度和实际喷出粒子数；默认值 `0.92` 时约喷出 94 粒，设为 `1.49` 时约喷出 152 粒。水格世界尺寸、各层基础粒子数和生命周期仍可在 `SteamBurstEffect` 组件 Inspector 中单独调整。

## 像素化

在 `SteamBurst.mat` 的 Shader 属性中调整“像素化程度”：默认 `0.1`，对应约 5 像素宽的块；`0` 保持柔和雾面；大于 `0` 时按屏幕像素块采样蒸汽边缘和噪声，块宽约为 `1–48` 屏幕像素，数值越高块越大。这个效果只影响该蒸汽材质，镜头分辨率改变时屏幕上的块宽保持一致。
