# Interactive Water 预设体迁移包使用说明

适用资源：`InteractiveWater_Transfer.unitypackage` 或 `InteractiveWater_Transfer.zip`，二选一导入。源项目使用 Unity 6000.3.12f1、URP 17.3.0。包内包含预设体、脚本、材质、Shader Graph、渲染纹理、预览网格、`Renderer2D.asset` 和对应的 `.meta` 文件。

> 这个包由**原项目**的资源构建。若您已经在另一个项目中调整了材质或脚本，重新导入并勾选同名文件会覆盖那些修改。请先备份已调好的文件，或在导入窗口取消勾选它们。原项目迁移包与另一个项目后续增加的多水面独立模拟、水下画面捕获功能并不是同一版本。

## 1. 导入与放置

1. 在目标项目中选择 `Assets > Import Package > Custom Package`，选取 `InteractiveWater_Transfer.unitypackage`，导入所需资源。也可以将 ZIP 解压到**目标项目根目录**，使其落在 `Assets/ta_source/InteractiveWater/`。不要把两种包都导入一遍，也不要把包再复制回原项目的 `Assets`，以免出现重复 GUID。
2. 在 Project 面板找到 `Assets/ta_source/InteractiveWater/InteractiveWater.prefab`，拖入场景。将它移到主相机视野内；预设体保存的位置只是示例位置。根物体的缩放建议保持 `(1,1,1)`。
3. 场景需要一个 Tag 为 `MainCamera` 的主相机。预设体自带的 `ReflectionCam` 是水面反射用的子相机，不是玩家看到的主相机，不必手动开启它。

## 2. 配置渲染层与相机

1. 在 `Project Settings > Tags and Layers > Sorting Layers` 中新增 `WaterTopMesh` 和 `WaterFrontMesh`，按此顺序排列。
2. 选中预设体根物体，在 `InteractiveWater` 组件里重新选择 `Top Mesh Sorting Layer` 和 `Front Mesh Sorting Layer`；检查两个子物体的 `Sorting Group` 是否分别使用相应的层。目标项目的 Sorting Layer 数字 ID 可能与源项目不同，所以只复制预设体并不足以保证层级正确。
3. 在目标项目现有的 URP Pipeline Asset 的 Renderer List 中加入包内 `Renderer2D.asset`，让显示水面的主相机选用它。这个版本的水面使用 Sprite Lit Shader Graph；横截面的画面依赖 2D Renderer 提供的 `_CameraSortingLayerTexture`。在 `Renderer2D.asset` 中确认 `Camera Sorting Layer Texture` 已启用，并检查捕获范围与项目中的排序层一致。
4. 检查主相机的 Culling Mask、角色的 Sorting Layer 和水面材质的透明排序。水下角色若始终画在前面，先排查这些设置。不要直接覆盖目标项目的整个 `ProjectSettings` 或 URP Asset。

## 3. 预设体里的物体负责什么

| 物体 | 作用 |
| --- | --- |
| `InteractiveWater` 根物体 | 挂载 `InteractiveWater.cs`、`SimplePlanarReflection.cs`、2D/3D 触发器；管理网格、波纹和反射。 |
| `WaterTopMesh` | 从上方看到的水面，显示水面波纹。 |
| `WaterFrontMesh` | 从侧面看到的水体横截面，负责水下颜色、波纹和折射外观。 |
| `ReflectionCam` | 生成水面反射贴图；它需要能找到 `MainCamera`。 |

这是基于着色器和渲染纹理的**涟漪效果**；包里没有独立的粒子喷溅特效。

## 4. 让角色碰水产生波纹

- **2D 角色**：角色需要 `Collider2D`；通常配合 `Rigidbody2D`。水根物体已有 `BoxCollider2D`，且设为 `Is Trigger`。角色穿过水面触发区域时会调用 `OnTriggerEnter2D`。检查 `Physics 2D` 的 Layer Collision Matrix 是否允许这两层相互触发。
- **3D 角色**：角色需要 3D `Collider`，并按控制方式配 `Rigidbody` 或 `CharacterController`。水根物体已有设为 `Is Trigger` 的 3D `BoxCollider` 和运动学 `Rigidbody`。角色进入触发体时会调用 `OnTriggerEnter`。检查 `Physics` 的 Layer Collision Matrix。**2D 与 3D 物理系统不会互相触发**。
- 触发器用于检测，不应挡住角色下潜。若角色被水面挡住，检查是否额外添加了非 Trigger 的 Collider，特别是 `WaterTopMesh` 上的 Collider。
- 角色若一开始就处于触发区域内，可能不会看到“进入水面”的瞬间波纹。请从区域外移动进入。当前脚本只处理进入事件；持续游动不会自动连续产生水花。
- 若想从自己的控制脚本主动产生波纹，可取得对应水面的 `InteractiveWater` 组件，并调用 `CreateContactRippleAt(世界坐标, 强度, 初始向上)`。强度一般先从 `0` 到 `1` 之间试起。

## 5. 常用调节位置

| 想调什么 | 在哪里调 | 作用 |
| --- | --- | --- |
| 画面上看到的波纹幅度 | `ArtAssets/Materials/Water/TopMesh.mat`、`FrontMesh.mat` 的 `Ripple Scale` | 提高后波纹显示得更明显；两个材质分别控制顶部和横截面。 |
| 常驻水波的明显程度 | 同两个材质的 `Wave Scale` | 调的是环境水波，不是碰撞瞬间的力度。 |
| 涟漪消失快慢 | `ArtAssets/Materials/Water/CRT_RippleSimulation.mat` 的 `Damping` | 越接近 `1`，衰减越慢。 |
| 涟漪传播 | 同一模拟材质的 `Spread` | 值增大通常传播更明显；应小步调整。 |
| 每次物理更新的模拟次数 | 预设体根物体 `InteractiveWater` 组件的 `Ripple Simulation Iteration Per Frame` | 次数越多，波纹推进越快，也增加计算开销。 |
| 碰撞水花的原始强度 | `Scripts/InteractiveWater.cs` 中两个碰撞入口的 `Random.Range(0.2f, 0.6f)` | 分别对应 2D 和 3D；改成更大的范围会增强碰撞波纹。 |
| 碰撞波纹的初始面积 | 同一脚本 `UpdateNewRipples()` 的 `updateZoneSize = new Vector3(0.01f, 0.01f)` | 两个数是模拟纹理的相对宽、高。 |
| 横截面折射、焦散 | `FrontMesh.mat` 的 `Distortion Strength`、`Caustic Strength` | 改变水下外观，与碰撞强度分开。 |

`UpdateNewRipples()` 在每次碰撞时都会把 `initialStrength / 5` 写入模拟材质的 `Impact Height`；因此直接改模板材质上的 `Impact Height`，通常不会改变碰撞水花强度。鼠标点击测试使用旧 Input API，预设体默认关闭；如果项目只启用了新 Input System，请保持关闭。

调节**包内材质**会影响引用该材质的水面。想给不同水面分别设置显示参数，可复制材质并给每个实例单独指定；但当前迁移包的脚本仍共用模拟纹理和材质，复制材质本身并不能让多个水面的波纹模拟完全独立。

## 6. 改尺寸与多个水面

在根物体的 `InteractiveWater` 组件中，`Top Surface Size` 控制顶部宽度和进深，`Front Surface Height` 控制横截面高度。修改后在 Inspector 点击 `Generate Mesh`，并检查根物体的 2D/3D Trigger 尺寸与水面实际位置是否一致。预览网格只为编辑器显示，运行时脚本会生成网格。

**这个原项目迁移包不是多水面独立模拟版。** 多个预设体实例共用模拟纹理、材质和反射纹理，波纹可能串到另一片水面，或只看到一片水面正确互动。要在同一场景中放多个独立水面，应使用已经实现运行时资源隔离的版本，或先给这个包补上每实例的纹理、材质和反射资源复制逻辑。

## 7. 常见问题

- **预设体不显示或横截面不透明**：优先检查主相机 Renderer、`Camera Sorting Layer Texture`、Sorting Layers、主相机可见层、角色与水面的透明排序。仅复制预设体无法复制目标项目的渲染管线设置。
- **碰水没有波纹**：确认角色使用正确的 2D 或 3D 碰撞组件、层碰撞矩阵允许接触、角色确实从触发体外进入，以及 `InteractiveWater` 组件已启用。
- **角色下不去**：检查水面上是否存在非 Trigger 碰撞体；Trigger 本身不会阻挡角色。
- **反射不对或相机报错**：确认场景有 `MainCamera`，检查 `SimplePlanarReflection` 的 `Reflection Mask` 和主相机视角。侧视相机与水平水面平行时，脚本会跳过不适用的平面反射计算。
- **导入后脚本或 Shader 丢失**：确认导入了整个包及 `.meta` 文件，且目标项目启用了兼容的 URP / Shader Graph 依赖。
