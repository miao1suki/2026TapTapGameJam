# 流动岩浆与方块颗粒喷溅

源图 `0-5 (1).png` 是 215×134 图集。岩浆使用图集下排左侧的亮色 16×16 方块（左上角像素 104,105）；喷溅使用同排左侧两颗实心 2×2 方块粒子（左上角像素 49,111 与 61,111）的轮廓。材质提供喷出高亮、灼热橙红、降温深红和余烬暗色四段可调色，粒子随寿命依次变暗并消失，不绘制泡泡轮廓。修改源图排版时应同步修改两个 Shader 的图集坐标。

## 预览

打开 `StaticTest/FlowMagmaPreview.unity`。Scene 模式显示静态预览，Play 模式播放横向流动、轻微表面波动和持续但间隔随机的方块颗粒喷溅；少数时刻连续喷出两三颗。预览目录不加入正式场景流程。`FlowMagmaVisual.prefab` 是 1×1 世界单位、无碰撞的纯视觉预制体，后续可作为现有 `Red_Lava` 的视觉子物体。替换时只换表现层，保留原来的 `LavaHazardFeature`、碰撞、颜色解锁与冷却蒸汽逻辑。

## 调参接口

选中预制体或实例，在中文 Inspector 中修改：

| 参数 | 含义 |
| --- | --- |
| 横向流动速度 | Shader 双相位 Flow Map 的纹理循环次数/秒；0 停止流动。 |
| 表面上下波幅 | 岩浆顶部的世界单位振幅，限制 0～0.03；默认 0.008。 |
| 上下纹理扭曲强度 | 独立控制纹理内部的纵向位移，范围 0～0.03；默认 0.006，设为 0 时仍可横向流动。 |
| 平均喷出速率 | 每秒平均安排的喷出次数；0 关闭喷溅。 |
| 喷出间隔随机幅度 | 每次发射后重新抽取时间间隔，0 为均匀间隔，0.75 为默认变化幅度；没有固定喷发窗口。 |
| 连喷多颗概率 | 单次喷出额外跟随一到两颗的概率，形成偶发的小喷溅。 |
| 喷出初速 | 粒子向上初速度，同时决定少量横向散开。 |
| 下坠加速度 | 向下加速度，数值越大越快落下。 |
| 由大变小粒子占比 | 每颗粒子随机选择固定大小或逐渐缩小，0 全部固定、1 全部缩小，默认 0.55。 |
| 大颗粒占比 | 部分颗粒以约 1.6 倍尺寸喷出；其余颗粒叠加独立的大小随机变化。由大变小的颗粒前期略大，随后按缓入缓出的曲线缩至约 18%。 |
| 颜色变化 | `MagmaSplash.mat` 中的四段颜色依次控制新喷出的亮黄橙、橙红、深红与余烬暗色；单颗粒有轻微随机冷却偏移，临近消失及落地堆积结束时淡出。 |
| 落地堆积概率、堆积消失时间 | 部分粒子落到视觉块底缘后短暂停留并渐隐。 |
| 大小随机幅度、轨迹随机幅度 | 分别控制每颗粒子的尺寸和喷出方向/速度差异，均可设为 0。 |

运行时可通过 `FlowMagmaVisual` 的 `FlowSpeed`、`WaveAmplitude`、`VerticalWarpStrength`、`ParticlesPerSecond`、`EmissionIntervalRandomness`、`ClusterChance`、`LaunchSpeed`、`FallSpeed`、`ShrinkingParticleChance`、`LargeParticleChance`、`SizeRandomness`、`TrajectoryRandomness` 属性调参，`Restart()` 重新开始随机喷溅。粒子为固定容量网格，不生成或销毁单颗 GameObject；不参与物理、伤害或房间状态。禁用预制体后停止，重新启用重置发射计时。

图集以 Point、Clamp、无压缩、无 Mipmap 导入，确保细像素不串到邻格。预制体所用材质不应改用双线性过滤。
