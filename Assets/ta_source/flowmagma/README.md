# 流动岩浆与实心颗粒喷溅

接入 TA `7656c86`、`9c9bfd1`、`95da62e`：轻微独立纵向扭曲、持续随机间隔喷发、偶发两三颗连喷、固定大小/逐渐缩小两类颗粒、随机尺寸层级与轨迹、亮黄橙→橙红→深红→暗色余烬四段冷却。未采用 `223eb8d` 的独立预览 Scene 调参；正式 prefab 横向速度保留 `0.28`。

## 正式游戏入口

`LavaHazardFeature.OnAttach` 自动创建 `FlowMagmaVisual.prefab`；旧场景/复制的旧岩浆由 `Resources/TAReactions/ReactionArtworkSettings` 提供同一 fallback。`Red_Lava.prefab` 也显式绑定本 prefab。创建后仅关闭旧正式岩浆 sprite，未解锁的灰白识别模型、`LavaContactOcclusion`、危险碰撞、房间复原与蓝色冷却逻辑不变。

源图 `0-5 (1).png` 是 215×134 图集，body 使用亮色16×16块（左上坐标104,105）；实心喷溅使用49,111及61,111处的两颗2×2块的 alpha。四段配色在 `MagmaSplash.mat` 调整，不再使用旧的空心圆环。图集 Point、Clamp、无压缩、无 Mipmap、默认及各平台最大256，不能改用双线性过滤。

## 网格、孔洞与颜色

- 正式比例固定16美术像素/格，世界像素边长=`cellWorldSize/16`。父合并物体的整体缩放不重复放大像素。
- `ConfigureCoverage` 只生成实际覆盖的格，保留合并形状的孔洞；仅没有上方邻格的真实顶面起伏和喷发。蓝色冷却蒸汽也只从这些顶面产生。
- 新生颗粒直径至少2美术像素，冷却缩小时最小1像素；固定大小和落地堆积都不会产生小于1像素的半格尺寸。宽高为整数像素，边缘贴世界像素边界，中心根据奇偶宽度对齐整数/半像素格。
- body、splash 使用 ColorAppearanceManager 共享材质池，跟随红色解锁渐显；HSV mask 与可见轮廓使用同一表面裁切/实心颗粒约定，不复制逐颗粒材质。

## 调参

| 参数 | 用途 |
| --- | --- |
| 横向流动速度 | 双相位纹理循环，默认0.28；0停止纹理流动，不停止喷溅。 |
| 表面波幅 / 上下扭曲 | 独立0～0.03格；默认0.008 / 0.006，不拉伸原像素。 |
| 平均喷出速率 | 每表面格的基础事件频率，最多按6格计且上限80次/秒；0关闭。 |
| 间隔随机 / 连喷概率 | 默认0.75 / 0.22。无固定喷发窗口，偶发额外1～2颗。 |
| 初速 / 下坠加速度 | 按格世界大小换算；默认1.2 / 3.8。 |
| 缩小颗粒 / 大颗粒占比 | 默认0.55 / 0.22，大颗粒约1.6倍，尺寸最终量化为整数美术像素。 |
| 大小随机 / 轨迹随机 | 默认0.35 / 0.6，0取消对应随机。 |
| 飞行寿命 / 堆积 | 默认1.8秒±20%；部分颗粒落到对应实际列的底面短暂停留渐隐。 |

纯视觉无碰撞，每个岩浆 owner 一个body网格和固定96容量的splash网格，不逐颗创建/销毁GameObject。每帧事件追赶最多12次，离屏跳过粒子更新。`Restart()` 清池、重新随机计时；禁用释放生成网格，房间复原只保留一套活跃视觉。
