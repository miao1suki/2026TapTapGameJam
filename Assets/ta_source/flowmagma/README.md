# 流动岩浆与泡沫喷溅

源图 `0-5 (1).png` 是 215×134 图集。岩浆使用图集下排左侧的亮色 16×16 方块（左上角像素 104,105）；泡沫取左下两颗红色 2×2 像素之一（49,111）着色，轮廓由喷溅 Shader 像素化生成。修改源图排版时应同步修改两个 Shader 的图集坐标。

## 预览

打开 `StaticTest/FlowMagmaPreview.unity`。Scene 模式显示静态预览，Play 模式播放横向流动、轻微表面波动和周期喷溅。预览目录不加入正式场景流程。`FlowMagmaVisual.prefab` 是 1×1 世界单位、无碰撞的纯视觉预制体，后续可作为现有 `Red_Lava` 的视觉子物体。替换时只换表现层，保留原来的 `LavaHazardFeature`、碰撞、颜色解锁与冷却蒸汽逻辑。

## 调参接口

选中预制体或实例，在中文 Inspector 中修改：

| 参数 | 含义 |
| --- | --- |
| 横向流动速度 | Shader 双相位 Flow Map 的纹理循环次数/秒；0 停止流动。 |
| 表面上下波幅 | 岩浆顶部的世界单位振幅，限制 0～0.03；默认 0.008。 |
| 上下纹理扭曲强度 | 独立控制纹理内部的纵向位移，范围 0～0.03；默认 0.006，设为 0 时仍可横向流动。 |
| 喷发速率 | 喷发窗口内每秒新粒子数；0 关闭喷发。 |
| 喷发周期、每轮喷发时长 | 喷发窗口间隔与持续秒数；时长大于周期时连续喷发。 |
| 喷出初速 | 粒子向上初速度，同时决定少量横向散开。 |
| 下坠加速度 | 向下加速度，数值越大越快落下。 |
| 由大变小粒子占比 | 每颗粒子随机选择固定大小或逐渐缩小，0 全部固定、1 全部缩小，默认 0.55。 |
| 落地堆积概率、堆积消失时间 | 部分粒子落到视觉块底缘后短暂停留并渐隐。 |
| 大小随机幅度、轨迹随机幅度 | 分别控制每颗粒子的尺寸和喷出方向/速度差异，均可设为 0。 |

运行时可通过 `FlowMagmaVisual` 的 `FlowSpeed`、`WaveAmplitude`、`VerticalWarpStrength`、`ParticlesPerSecond`、`EruptionInterval`、`EruptionDuration`、`LaunchSpeed`、`FallSpeed`、`ShrinkingParticleChance`、`SizeRandomness`、`TrajectoryRandomness` 属性调参，`Restart()` 重新开始周期。粒子为固定容量网格，不生成或销毁单颗 GameObject；不参与物理、伤害或房间状态。禁用预制体后停止，重新启用重置喷发。

图集以 Point、Clamp、无压缩、无 Mipmap 导入，确保细像素不串到邻格。预制体所用材质不应改用双线性过滤。
