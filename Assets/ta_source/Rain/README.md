# 三色四帧雨滴

`Rain_Blue.prefab`、`Rain_Red.prefab`、`Rain_Green.prefab` 分别使用原图右侧的细竖线雨滴：每种颜色两行、每行两帧，共四帧。三个预设体共享一套 `RainSpriteField` 逻辑、Shader 和材质。每个预设体将所有雨滴合为一张运行时网格，不生成单颗雨滴 GameObject，也不修改玩法碰撞或颜色系统。

## 预览和接入

1. 打开本目录 `RainPreview.unity`，编辑模式下即可看到从左到右排列的红、蓝、绿静止雨滴；进入 Play 后开始下落。
2. 将需要的预设体拖入自己的场景，放在所需雨区中心；雨区位于预设体的本地 XY 平面，雨滴向本地 Y 负方向落下。
3. 选中预设体可在 Scene 视图看到雨区边框。每颗雨滴在编辑模式固定显示该颜色的第一帧，不下落、不切帧。手动移动预设体时会重新抽取静态分布；调整宽度或密度等参数时也会刷新，Inspector 同时显示实际雨滴数（宽度 × 密度，最多 512）。打开预设体本身也可直接布置。

## 参数

| 参数 | 作用 |
| --- | --- |
| 下雨宽度、下落高度 | 发射面的世界单位宽高；位置是面片中心。 |
| 雨滴大小 | 单颗四帧图的世界单位尺寸。 |
| 大小随机幅度 | 每颗雨滴独立抽取尺寸；0 为等大，0.35 表示基准大小的 ±35%。每次重新出现会重新抽取。 |
| 密度 | 每单位宽度的雨滴数，实际数量上限 512；设为 0 可关闭发射。 |
| 下落速度 | 雨滴平均每秒移动距离。 |
| 速度随机幅度 | 每颗雨滴独立抽取落速；0 为等速，0.3 表示基准速度的 ±30%。每次重新出现会重新抽取。 |
| 四帧切换速度 | 单颗雨滴四帧循环的速度；每颗有独立相位。 |
| 随机性 | 控制帧相位、轻摆、再出现间隔及噪波对到底概率的影响；不覆盖独立的大小/速度随机幅度。 |
| 到底概率 | 雨滴到达面片底端的概率；其余在中段淡出。 |
| 噪波影响、噪波尺度 | 以位置噪波改变局部到底概率、中途消失高度与轻摆。 |
| 随机种子 | 改变分布。 |

进入编辑模式时，每个预设体立即生成一组静止雨滴，不用等待运行时发射。静态位置在不操作时保持不变；移动物体会重新抽取位置，但不会推进掉落进度。进入 Play 后从初始位置开始下落并播放四帧，在末段淡出并重新排队；各雨滴错峰循环。材质从原始 PNG 的右侧细竖线区域按 16×16 像素格取帧：列起点为 320、352；红色行起点为 160、192，蓝色为 224、256，绿色为 288、320（均为图片左上角坐标）。图片按点采样、无压缩、无 Mipmap 导入。若替换原图或调整排版，需要同步修改 `RainSpriteField.cs` 中的图集尺寸与帧坐标。

预设体是纯视觉效果，没有碰撞、积水、地面溅射或游戏逻辑。演示场景是独立 TA 预览，不加入正式 MainMenu/Gaming 场景序列。
