# 三色交互连线场景接入说明

这份说明用于把现有的交互连线效果接入游戏场景。重点是把组件放到玩家身上并接好材质，不需要给每个可染色物体单独添加连线脚本。

## 放在哪个物体上

把 `InteractionLinkEffect` 挂到**玩家根物体**上，也就是已经挂有 `PlayerController` 的那个对象。它需要和玩家的交互检测器、颜色轮盘在同一个玩家对象上配合工作。

连线和 LineRenderer 会在运行时由组件自动创建为玩家的子对象，因此不用手动创建线条，也不要把这个组件挂到相机或每个可染色物体上。

## Inspector 里要设置什么

在玩家上的 `InteractionLinkEffect` 组件中设置：

| 项目 | 怎么设置 |
| --- | --- |
| 玩家交互检测器 | 选择玩家身上的 `PlayerInteractionSensor`。如果同一个对象上只有一个，通常可留空让组件自动查找。 |
| 玩家当前选色 | 选择玩家的 `PlayerColorWheel`；同一个对象上有颜色轮盘时也可留空自动查找。 |
| 颜色目录 | 拖入项目正在使用的 `ColorCatalog`。 |
| 像素线材质 | 拖入 `Assets/ta_source/LinkEffect/InteractionLink.mat`。 |
| 链条起点锚点 | 可选。若角色模型有合适的手部或身体锚点，可拖入对应 Transform；不设置时使用“无锚点时起点偏移”。 |
| 目标检测层 | 确认可染色物体的 Collider 所在 Layer 被包含在内。 |

检测半径沿用玩家 `PlayerInteractionSensor` 的扫描半径，不用在连线组件里再配置一份。

## 可调整的效果

- **线条生成时长（秒）**：红、蓝线整条淡入以及绿线从玩家端向目标生长所用的时间。
- **断开溶解时间（秒）**：目标离开范围后，线条消散所用的时间。
- 在 `InteractionLink.mat` 材质 Inspector 中调节**链条粗细、像素大小、枝条噪波幅度、效果速度**。
- 材质中的**水纹外围效果强度**只影响蓝线中央主干周围的环绕线和波纹。设为 `0` 时只显示中央主干，数值越大外围效果越明显。

## 场景里的目标需要什么

可染色物体继续使用它原有的组件和 Collider，不用额外挂连线组件。连线会读取现有可染色目标，并且只在以下情况下显示：

- 玩家当前选中红、绿或蓝颜色；
- 目标处于玩家交互检测范围内；
- 目标在检测层中，并且能响应当前选中的颜色。

实际染色仍由原有玩家染色流程负责；连线只做可行性预览。

水面波纹、鼠标预览等 `InteractiveWater` 内部碰撞体不参与颜色连线。水源/水流/气泡柱的交互范围以玩法对象自身 Collider 为准，避免合并放大时把特效检测范围当成接色范围。红色移动平台和曲柄升降平台是信号消费者，不属于可染色连线目标；合并本身不改变这一规则。

## 在测试场景里检查

`Assets/Scenes/Test.unity` 已经有可参考的玩家配置：找到 `TestPlayer`，查看它身上的 `InteractionLinkEffect` 组件。该配置已引用交互检测器、颜色目录和像素线材质；起点锚点留空，使用默认偏移。

`Assets/Scenes/Pick.unity` 的 `TestPlayer` 也已挂载同样的连线效果，引用当前颜色目录和 `InteractionLink.mat`，检测器与轮盘从同一玩家自动读取。场景使用 PC 管线当前的 TA Stencil 像素化参数，并保留之后的 HSV 阶段；不需要复制 Test 场景物体。

进入 Play Mode 后选择红、绿或蓝颜色，再靠近对应的可染色物体。没有选中这三种颜色、物体在范围外或物体不能响应当前颜色时，不会出现连线。

如果看不到效果，先检查玩家是否有 `PlayerController` 和 `PlayerInteractionSensor`，再确认颜色目录、像素线材质、目标 Layer 和物体 Collider 是否正确。
