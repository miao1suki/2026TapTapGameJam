# 交互像素连线预览

场景挂载说明见 [连接效果使用说明.md](连接效果使用说明.md)。

`InteractionLinkEffect` 已挂在 `Assets/Scenes/Test.unity` 的 `TestPlayer` 上。它只读取现有组件的状态，不调用 `TryInteract`、`ApplyColor` 或搬运命令，也不修改玩家、方块或渲染管线脚本。上次新增的红色测试方块已移除。

绿色选色已改为主动绿钩子，本组件只保留红、蓝预览，不再为绿色绘制目标连线；绿色藤蔓材质由 `Project.GreenHook.GreenHookAbility` 复用。

`Assets/Scenes/Pick.unity` 的原测试玩家同样接入当前三色连线配置，保持原关卡布局与轮盘。选择可用颜色并靠近能响应它的目标即可显示效果；固定身份的 ContactCube 不是可染色目标，不会显示染色连线。

## 识别范围

- 只有玩家当前选中红、绿或蓝染色状态时显示预览；无颜色、颜色状态结束、玩家控制锁定或搬运中时立即隐藏。
- 只读读取碰撞体父链上的第一个 `IColorApplicationTarget`，再结合 `CanApplyColor` 与具体组件的 `OnColorApplied` 条件筛选；只能返回“无法染色”的目标不会出现连线。实际接色包括万能方块、红色烧毁弹性植物/植物障碍/藤蔓、蓝色处理岩浆/使尚可生长的母藤蔓增长，以及红色触发水体蒸汽；藤蔓子节段也能被红色烧毁。
- 检测以 `PlayerInteractionSensor` 的扫描圆心和半径为准；扫描时与逐帧绘制前都会核对目标是否仍在圈内，路径弧度也限制在圈内。多个 Collider 按颜色物体或组件 GameObject 去重，最多显示 Inspector 指定数量的线条。

## 表现与使用

`InteractionLink.shader` 根据玩家选色绘制三种像素化轮廓：红线用明亮黄芯、橙色火身、红色外缘和向外漂浮的少量火星表现燃烧；蓝线有带轻微噪波的中央主干，以及断续环绕线和向外波纹，外围效果由材质“水纹外围效果强度”单独控制，设为 0 时仅保留中线；绿线从玩家端向外延伸，长出四条带轻微随机弯曲与回钩的分枝、叶片和逐渐变大的小花。红、蓝线整条从无到有淡入，绿色按长度生长。图案按连线的实际长度生成固定间距的火星、枝叶和花朵，距离变长时增加图案数量，不拉伸图案。三种线头都在两端柔和收尖，断开后按像素噪波溶解退场。

组件 Inspector 的“线条生成时长（秒）”控制红蓝整条淡入以及绿线从玩家端沿长度生长的时间；同一目标在扫描排序变化时保持已有进度，断开后按 `dissolveDuration` 溶解。选色切换会重新播放生成。`InteractionLink.mat` 的“链条粗细”控制可见主干和装饰的尺寸；“水纹外围效果强度”单独调节蓝线的环绕和扩散效果。LineRenderer 额外留出透明空间以容纳叶片、花瓣与火星。材质中的“枝条噪波幅度”和“效果速度”分别控制路径扰动与火、水、叶片的运动。玩家组件可调生成和溶解时长、检测间隔、最多线数、摆动幅度和透明度。

在 Unity 6000.3.12f1 中打开 Test 场景并进入 Play Mode。选择红、绿或蓝色后，靠近对应可染色物体查看连线；无选色时不会显示。目标的实际点击仍由原有玩家脚本决定，连线只提示当前颜色的接色候选。
