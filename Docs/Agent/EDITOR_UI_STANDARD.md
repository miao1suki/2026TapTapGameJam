# 编辑器 UI 统一规范

## 风格与信息层级

采用 Unity 深色工具风格：低饱和深灰背景、明确文本对比、蓝色主操作；红色仅删除/错误，黄色仅警告。
中文短标题，按钮动宾短语，正常字号12–14，标题16–18；间距4/8/12/16。不用装饰性大段文案和聊天语气。
一块面板一个工作目标，主操作最多一个视觉重点；先选择输入，再预览，最后执行。高级参数默认折叠。
明确空状态和缺失条件，无法操作时禁用按钮并解释原因。不要让用户靠 Console 理解正常操作。

## 技术与交互

新编辑器工具使用 UI Toolkit，不以 IMGUIContainer 包裹旧 OnGUI 冒充迁移。
Scene HUD：标题区拖动，按钮区域不触发拖动；Pointer Capture，退出/禁用释放事件；折叠只保留标题，关闭后菜单可重新打开。
位置/折叠/显示状态按项目、工具、SceneView 保存；窗口缩小时夹紧到可见区域；正文滚动，标题和主操作不被图片覆盖。
EditorWindow 原生标题栏负责拖动与关闭；正文用 Foldout/ScrollView，原生停靠能力保留。
图片导入提供 ObjectField；图片预览占主区域，提供缩放与滚动，图框可点选、取消；不要依赖 Project Selection 作为唯一输入。
修改资产/场景支持 Undo、标脏和保存；删除/覆盖批量数据确认范围，生成结果提供实际路径和 Ping。
不阻挡场景导航，不在 Play Mode 执行破坏性编辑。菜单统一 `Tools/2026TapTap/<分类>`。

## 验收

验证拖动、折叠、关闭/重开、空选择、多选择、Undo、窗口缩放、图片大/小分辨率和脚本重编译后的恢复。
新工具文档分别给策划“怎么用”和 agent“接口/所有权/依赖/验证”；只把简短操作提示放进 UI。
旧 Timeline/成就的自定义 Inspector 保留为旧功能适配，不视为新工具规范样板；后续修改它们时逐步改为 UI Toolkit。
