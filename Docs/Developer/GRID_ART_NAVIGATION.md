# 美术工作台：定位、参考与快捷开关

在 Unity 编辑器中按 **N** 开关工作台，入口与关卡编辑器 **M** 一样使用全局菜单快捷键；Project、Inspector 等窗口聚焦时也可使用，不必先点 Scene。输入名称、搜索或数值、运行游戏或正在绘制笔画时不抢快捷键，也不会用快捷键丢弃尚未完成的笔画。菜单入口：`Tools/2026TapTap/关卡美术/切换窗口`。

首次打开会读取当前关卡，定位当前房间；没有美术图、没有白墙的房间也能先看布局。新建美术图会继承关卡格尺寸，不从世界原点开始猜位置。已有视图按场景和美术图分别记忆，刷新来源不会把手动移动的视图拉走。

- 画布上方“房间”选择后自动定位，也可点击“定位房间”。
- “定位关卡”显示完整关卡；“已绘美术”回到实际绘图内容。
- “关卡参考”只控制工作台底图，默认显示、透明度35%；可调整透明度，不改变游戏中的物体、材质或碰撞。
- 参考层使用保留几何批次；缩放、平移只改视图变换与裁剪，不逐格重新生成预览图片。
- “区域效果 · 雨 / 萤火”不要求先创建静态美术图；绘制、擦除、场景绘制会退出区域工具，避免模式互相抢输入。

美术Map自动保存不等于场景已保存。区域效果直接保存在Scene；请点击“保存场景”，交付Scene、同名planning、正式关卡存档、美术Map、素材库、meta与新增依赖，不能只交生成后的Scene。

## 接入与验证

`GridArtLevelSource` 的只读快照给出世界XY房间、物体美术和边界；Planning的Y向下转换仅由适配器负责。`ArtCanvas` 中每格像素为 `zoom`，参考层每世界单位像素为 `zoom / cellSize`。静态美术、参考、区域框均共用同一原点与变换；不拉伸源图，也不改16个有效美术像素对应1格的约定。

视图Key包含项目、场景GUID、美术Map GUID；尚无Map使用场景独立的reference-only键。记忆旧视图使用加载时捕获的Key，不会因Unity先切场景后通知而将旧视图写入新场景。

场景打开、激活事件及来源读取前均按场景GUID和handle幂等检查绑定，不依赖单个场景事件到达顺序。首次自动适配在参考栏改变画布布局时仍保持房间居中，用户开始平移、缩放或主动定位后则保留其视图，不再自动重置。

仅隔离工程 `Library/FlowRetirementProbe` 执行 `Project.GridArt.Editor.GridArtNavigationAudit.Run`：真实附着窗口检查远离原点的首次定位、没有Map/墙的房间、世界与美术格转换、参考默认值与透明度、100次导航几何复用、文字和未完成笔画的N保护、跨场景视图隔离以及N关闭重开。报告位于 `Library/GridArtNavigationAudit.txt`；工具不自动运行Unity。人工还需检查停靠窗口与实际键盘N的冲突提示，以及正式关卡美术可读性。
