# 收集品与尖刺美术

## 素材与像素

继续使用16个有效美术像素=1世界格。`物体道具/E55B9ECE3C45615E2EC3C8F2DF707CCB.png`原图96×48，收集品取左上坐标(0,16)的完整32×32帧。自然外观2×2格，保留透明留白；既有物理碰撞、无重力、玩家Trigger与方块推动规则不变，不把图片压进一格。

尖刺来自`471dca30b9bcb2527867589ad677e3e3.png`，四款均保留完整16×16帧，按源像素显示；不是把大尖刺缩小或把小尖刺放大。

图像Point、FullRect、无MipMap、NPOT不缩放、无压缩。收集品最大尺寸128、尖刺源图512；不改变源PNG。未来法线贴图需使用同一切片、UV和90度方向。

## 放置与状态

关卡编辑器道具栏目增加四款尖刺；它们复用同一个尖刺预制体，以组件参数区分“尺寸、初始带血、朝向”。朝向支持上下左右；“沿用原方向”保留旧四向预制体的方向。旧场景保持原占格、方向与机关绑定，不自动扩格或重建。

玩家真正被尖刺杀死后，只有命中的格切为对应带血图。合并长条仍只有一个逻辑对象，但各格独立染血。无敌保护、已死亡玩家和禁用尖刺不会染血。R、死亡、离区及对象禁用重启保留本次运行的血迹；不写入planning或玩家存档。作者设置的“初始带血”则是正常地图参数，会被规划存档保留。

运行外观按精确覆盖格生成一个Mesh，每格选择干净/带血UV；不会为每根小刺建立Renderer，也不逐帧重建网格。合并空洞不会填补。共享`ObjectArtwork/Spike Cutout.mat`使用双面AlphaClip，只显示源图的实色像素；不能直接使用白块的Opaque材质，否则透明留白会变成实心矩形。

## 接入与验证

显式生成入口：`Tools/2026TapTap/关卡美术/接入收集品与尖刺四款`，对应`WorldItemArtworkSetup.Build()`。只更新源图导入、共享ObjectArtwork库、尖刺Cutout材质和栏目，不保存打开的Scene。生成后应提交两张源图的meta、`ObjectArtwork/Objects.asset`、`Spike Cutout.mat`及其meta、`LevelEditorPalette.asset`及新增源码/meta；用户新增收集品PNG也必须随交付提交。

隔离审计入口：`Project.WorldItems.Editor.WorldItemArtworkAudit.BuildAndVerify`（生成与素材/栏目/稳定SpriteID），以及`.Run`（真实Physics触发、保护、四向/大小、独立染血UV、重置与非序列化）。仅在带`-noaudio`的`Library/FlowRetirementProbe`运行；通过数以整合者实际报告为准，不把自动断言当成完整关卡通关。

关卡协作仍须同时交Scene、同名planning.json、双方meta和新增依赖；正式Gaming另带命名正式存档，不能只传生成场景。
