# 游戏 UI 美术接入

## 场景与组件

- 正式开始界面：`Assets/_Project/Scenes/Start/MainMenu.unity`。开始按钮仍通过 `StartMenuFlowBridge` 进入 Gaming，不恢复旧 Bootstrap 流程。
- 暂停和设置：`Assets/_Project/Content/UI/SharedGameUI.prefab`，由现有 `GameUiRouter` 与 `EscMenuController` 控制。不要另挂一套暂停输入。
- 颜色能力轮盘：唯一标准 `Content/Player/Player.prefab` 上的 `PlayerColorWheel` 管理输入、能力与选色，`PickWheelPrototype` 只显示外观；不恢复旧玩家预制体。

Boss 血条不使用图片材质：外框以外保持透明，拖尾血皮为纯白，当前血量为项目肉红色 `#B23E3E`，血量分段使用无 Sprite 的纯黑竖直 `Image`。外框同样由纯色硬边 `Image` 拼成，使用 1px 黑外缘、`#523B42` 暗红框体和左上/右下 `#F65332` 短角部强调。所有边缘保持硬直，不创建底板、图片描边、Mipmap 或压缩资源；长度、高度、外框、颜色和分隔线宽度仍可在 `BossHealthBarUI` Inspector 调整。

能力扇区顺序为红、绿、蓝，对应右下、上、左下。切分采用不透明像素连通区域识别，不按角度截断色块边缘。未解锁显示问号；悬停沿用硬切白色半透明与 DOTween 等比缩放，轴心是各扇区可见像素重心。暂停菜单直接以美术块作为完整按钮，替换占位扇区，关闭旧底盘表现，不把素材缩小叠到扇区里；按操作枚举绑定，扇形图片随轮盘旋转，文字独立保持正向。

暂停轮盘的W/S、上下方向键、手柄左摇杆及十字键使用统一上下导航方向；按住只切换一次，松开后可再次切换。确认沿用现有Jump/Submit映射。移动端可直接点击美术按钮选择并确认，或上下滑动切换选项，滑动不触发点击确认。手势只操作暂停UI，不改玩家输入和虚拟摇杆。

## 转盘表现基线

左侧轮盘的裁切宽度依据扇形间距、文字半径及最大选中缩放自动扩展，放大时不改变圆心，也不裁掉选项文字。

暂停轮盘包含继续、设置、收藏品、存档、返回主菜单、制作名单六项，60°等分并首尾循环；制作名单直接打开现有设置面板中的名单页。轮盘保留左侧位置，未移至屏幕中央。切片为32×38像素，布局参考圆心是正面两侧边延长线的交点（切片左上坐标约为−7、15），不是矩形中心或底部阴影中心；对应RectTransform轴心为（−7/32、23/38）。六块分别旋转0～300°，按每像素9个UI单位显示，并沿各自方向向外错开64个UI单位，给阴影和选中凸出留出间隙。文字半径随素材尺寸同比调整。径向间距随缩放一起变化，仍以轮盘中心形成凸出。圆心、夹角、像素缩放与“暂停扇形径向间距”集中配置在GameUiArtwork，保留原图。

暂停表现：选中1.08倍、未选中0.94倍；所有选项均保持美术原色与完全不透明，不使用白化或半透明。切换0.6秒OutCubic，打开0.65秒OutQuart，均使用非缩放时间，快速切换打断前一次动画并从当前表现继续。扇形以共同圆心等比放大产生径向凸出；图片含图案一同旋转，文字独立反向补偿，打开、切换和鼠标直接选择时保持正向。使用默认UI材质，不创建独立高亮材质。暂停切片保留CPU可读像素并以Alpha判断命中，透明矩形留白不会遮挡相邻选项；只有六张32×38小图启用此选项。菜单打开/关闭及子页面淡出仍保留，不属于选项白化效果。

颜色能力转盘仍按原有`PickWheelPrototype.SetSector`：选中缩小至0.84倍，0.24秒OutBack；恢复1倍，0.2秒OutCubic；白色半透明0.58硬切，仅缩放缓动。缩放轴心保持扇区可见像素重心；连续切换会停止旧Tween。没有添加暂停转盘的凸出或渐亮行为。

美术接入保留的外观差异：暂停占位几何/旧底盘替换为共同圆心的扇形素材；颜色能力红绿蓝扇区对应新美术位置并采用Point采样和离线切片，中心文字改为白色。打开、关闭、子页面过渡及业务调用沿用原实现。上下方向、Submit及触摸是单独确认的操作适配，不恢复旧方向或禁用移动端。

更换图片优先调整共享资源引用。`Project.Player.Editor.GameUiArtworkSetup.Build()` 是显式重建入口，会按当前原图坐标重切资源，并保存 MainMenu、StartMenuPrototype 与共享 UI 预制体；不会自动执行，也不会重存 Pick。只重建暂停轮盘时使用 `BuildPauseArtwork()`，仅重切六个暂停扇形、更新共享配置和共享UI预制体，不重存主菜单或其他场景。旧五项实例在初始化时补齐制作名单，已有六项不会重复创建。源图排布改变时先修改切分坐标；不要在日常调参时反复运行。

## 水中玩家渲染

玩家像素材质改用 AlphaTest 队列、透明像素裁剪和深度写入，并提供水下底图采集所需的基础纹理/颜色兼容属性。透明留白不会挡水，角色实像素先进入底图，再由水面进行混合；没有通过提高排序把整个玩家强制贴到水前面。玩家层级、碰撞、游泳与 TA 水材质不变。

隔离项目使用真实 PC URP 管线渲染对比：旧透明玩家在水下可辨像素为 0；修复后可辨像素为 5223，其中 4039 像素受水效果混合。截图及记录在 `Library/FlowRetirementProbe/Library`。主菜单、设置、暂停和轮盘已做 GPU 截图检查；当前窗口手感与实机打包仍需测试。
