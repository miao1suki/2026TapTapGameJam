# 2026-10-15 更新

## 功能

- 网格美术编辑器：独立瓦片库、八邻格自动边角、多格装饰、多层视差与持久化分块模型；关卡编辑器可直接进入，玩法存档保持独立。
- 暂停轮盘：加入制作名单组成六等分，按美术扇形圆心布局，扩大扇区间距和整体尺寸，保留键鼠/手柄/触摸选择和原有菜单功能。
- 重生点与弹性植物：三状态重生点美术、弹跳动画；合并植物按格重复，沿用颜色表现与原碰撞。
- MVMap 标注图：替换 MVMapImportTest 旧布局，附共享可编辑规划存档；白墙、水域、定向水流、气泡柱、三按钮一门等均可继续由关卡编辑器修改。
- 修复合并长气泡柱下半段无法上浮；上下方向水流保持旧枚举兼容。
- 安卓触摸：方向、跳跃、冲刺、交互、左右放下、选色、重生与暂停；多指组合输入与失焦/暂停释放，避免触摸一次动作漏读及误染 UI 后方物体。
- 主菜单及暂停 UI 加入安全区/多分辨率横屏适配；构建脚本只收录 MainMenu 与 Gaming，应用名与 APK 名为“形之彩”。
