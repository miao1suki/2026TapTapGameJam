# 物体美术与动画

## 平台与三色单向平台

移动平台已替换为美术新给的6帧曲柄动画和9帧自动动画，仍只在实际移动时播放。每帧48×16，完整保留原图和16像素/格；视觉顶边贴齐真实支撑面，既有单格、合并平台的占格、碰撞、路线和绑定不改变。

道具栏目新增“红色单向平台”“绿色单向平台”“蓝色单向平台”，默认1×1格，三种功能完全相同，颜色未解锁也可站立。在关卡编辑器选择物体→“参数”→“单向平台”→“美术颜色”可改成其他颜色，保存到当前关卡存档即可；Inspector也有同一选项。颜色只用于正式美术和后续HSV褪色，不是颜色能力物体。旧白色单向平台及其既有3格默认、场景占格保留兼容，不会因换图自动移动或扩大。

关卡交付仍需Scene、同名planning.json、双方meta与资源依赖成套提交，不能只交生成的Scene；本次平台外观更新不需要重新生成或保存既有场景。

关卡编辑器仍从道具栏目放置“重生点”和“弹性植物”，无需额外挂动画控制器。既有实例也支持自动补齐表现组件，保存 Scene 后保留编辑外观。原有碰撞、激活半径、复活位置和弹跳参数不变。

## 重生点

| 状态 | 显示 |
|---|---|
| 未激活 | 封闭装置 |
| 已激活、不是当前点 | 打开的静止装置 |
| 当前重生点 | 白色装置18帧循环，每帧0.08秒 |

进入其他重生点后，原点回到第二种外观；再次绑定旧点会重新播放当前动画。离开激活范围不会取消当前绑定。状态来自现有重生逻辑，不由动画修改。

## 弹性植物

- 编辑时显示绿色正式精灵，不显示绿色占位立方体。
- 运行时未解锁绿色，仍显示既有黑白基础方块；解锁后通过统一 HSV 和透明交接渐显植物，基础方块退场。
- 成功触发弹跳后播放6帧动画，每帧0.08秒；结束回到静止帧。普通接触或站在旁边不会触发动画。
- 合并后的植物沿格子重复精灵，每株保持原有像素比例；整块仍只有原来的碰撞体和一套弹跳逻辑，不新增逐格脚本。
- 图片底部贴齐原碰撞体底部，不再为对齐静止帧顶面而抬高整张图片。原图静止帧高13/16格，上方保留美术留白；横向铺满一格。合并宽高、父物体缩放和单元格大小参与适配；动画不缩放碰撞体。
- 离区、R重置、禁用或烧毁会结束临时动画；已解锁绿色不会重新锁定。

配置：`Assets/_Project/Resources/ObjectArtwork/Objects.asset`。可调播放时长、静止帧及对应素材。组件“物体精灵表现”的表面偏移用于避免与方块表面重叠，不改变占格。

源图保留不变，切片与素材副本位于 `Assets/_Project/Art/Generated/ObjectArtwork`。两份道具预制体已绑定：`Respawn_Block.prefab`、`Green_JumpPlant.prefab`。

## 藤蔓

- 使用TA提交的192帧生长素材，预先裁除透明留边、生成12张不超过2048的图集。原始图片保留在 `Assets/ta_source/Particle/Grow/序列帧`。
- 一条母藤蔓及其全部子节段共用一个动画，贴齐母根底部，并匹配当前生长总高度。宽度和生长表现时长仍在藤蔓参数中调整。
- 初始使用第24帧；长成时到第160帧，随后末32帧按12帧/秒循环。红色交互沿本根系从上到下燃烧，同时倒放生长表现。钥匙、攀爬和碰撞规则不变。
- 未解锁只显示基础外观；正式序列帧仍受原绿色全屏HSV与共享透明度渐显控制。烧毁后重置、禁用后重启会重新登记表现，不残留重复实例。
- 序列帧配置位于同一 `Objects.asset`；各端统一使用预烘焙帧，不再在资源缺失时切回实时粒子。旧粒子字段仅隐藏保留以兼容已保存参数。构建前检查192帧、贴图与材质引用，不完整时终止构建。
- 已烘焙精灵不参加实时特效像素化组，绿色颜色层仍参加原HSV链路。Mobile_Renderer与当前PC配置一致，关闭额外的Learning像素化，避免移动端重复降采样；保留其他既有水与HSV管线配置。具体闪烁改善需在最新APK真机验证，不以编辑器渲染代替真机结论。
- 水序列帧尚未交付，本轮不改变现有水效果。

## 机关、方块和钥匙

- 门：竖门占1×2格，横门适配2×1格；开关时门框与图案一起按进度收窄/展开，保留原门轴、碰撞开关和镜头演出。
- 门内图案按绑定次序对应红、绿、蓝，实际有几个按钮就显示几个白色图案；对应按钮按下后替换为彩色，允许蓝色先按下。图案仅表示门按钮进度，与颜色能力无关；隐藏原独立占位提示。
- 门按钮依次使用红、绿、蓝版，每种两帧、0.08秒/帧。新增蓝绿原图按16×16切片，Point、FullRect、无Mip、无压缩、上限64，保留原始像素与透明度。按下后播放触发动画，松开回静止；图片底部对齐所在格子地面。独立红色按钮仍沿用原有玩法。
- 曲柄28帧跟随实际转动进度，松开后按回弹进度从当前帧倒放。回弹等待、速度、载人倍率与基座制动使用原参数，不另起计时动画。
- 移动平台使用已有两套动画，只在实际移动时推进。合并后重复中段、保留两端，不横向放大像素；薄平台顶边对齐碰撞体顶面。
- 红绿蓝接触方块使用对应图案；绿色伸长后随实际碰撞范围铺图。钥匙使用对应颜色核心，拾取和吸引逻辑保持不变。
- 正、侧面梯子使用 `tail.png` 第四行H形梯状瓦片，按各自攀爬范围铺设；不使用道具板里的九宫格边框。岩浆与“重力岩浆”复用静态岩浆图案、尺寸和渲染层级；重力版本仅增加动态刚体与落地碰撞，不改变伤害，且没有任何颜色替换反应。
- 颜色物体在Scene和预制体预览中显示识别图案；Game未解锁保持基础外观，解锁后精灵沿统一HSV/共享透明链出现，不显示旧纯色调试网格。门、梯子与钥匙不受颜色解锁隐藏。

配置位于 `Objects.asset` 的“机关与道具”。源图未修改；基座、植物障碍等缺少明确素材的物体继续使用现有外观。背景仍由网格美术工具布置，不自动覆盖策划关卡。

安卓暂停轮盘已单独反转上下触摸滑动，键盘、手柄及按钮规则不变。本轮未重新生成APK，真机需使用后续重新构建的版本。
