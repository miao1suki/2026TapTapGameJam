# 复活表现

玩家支持两种复活方式，由开发者配置，不向玩家增加选项。标准玩家默认仍为常规复活。

在玩家 Inspector 的“死亡与复活”中选择“复活方式”：

- 常规复活：沿用原有复位和摄像机跟回。
- 加载转场复活：黑幕向玩家收拢，加载背景从右侧入场；背景下完成玩家和房间复位，停留后沿原路退场，再展开黑幕。

选择加载方式后可调整“加载停留（秒）”，默认 2 秒。这个时间不包含前后动画。在运行模式中可修改后点击“运行时调试 / 测试复活”，也可使用现有 R 键；正在播放时的修改对下一次生效。

Boss 战进入/退出的程序调用示例见 [接入 API](../Agent/Integration/PLAYER_RESPAWN_API.md)。目前不自动识别 Boss，不新增 Boss 场景或触发区域。

背景、字体、遮罩和动画速度复用 `Assets/_Project/Content/GameFlow/Resources/GameTransitionSettings.asset` 及菜单美术；修改这些共用动画参数也会影响原大厅转场。加载停留时间则为玩家自身配置，不会改变大厅加载时长。

死亡先正常播放死亡动画，再按当前方式复活。慢速复活期间不能操作玩家或打开暂停；重复复活请求不重启转场。颜色与能力解锁、已拾取钥匙及保持型机关进度不清空，其余恢复规则参见 [房间、通道与重生](ROOM_RESPAWN_AND_RESET.md)。

此表现不会真的重新加载关卡。若返回菜单、禁用玩家或卸载关卡，立即取消并清理遮罩与本次控制锁；如果隐藏期间已经复位，不倒退到死亡位置。
