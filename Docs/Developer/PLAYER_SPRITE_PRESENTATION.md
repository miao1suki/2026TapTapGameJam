# 主角像素动画

现有玩家碰撞、物理、输入和跳跃参数保持不变。表现层使用24×24精灵画布，每张画布对应1×1格，透明留白属于素材本身，不逐帧裁剪轮廓，以免跳动。

外观默认向下偏移0.08格；在玩家的像素表现组件中调整“外观垂直偏移（格）”，负值下移、正值上移，仅影响精灵位置，不改变碰撞或接地判定。

## 状态与所有权

- `PlayerController` 拥有玩法状态；表现组件只读 `CurrentStateId`、接地、速度与输入，不反向请求跳跃、攀爬、游泳、死亡或复活。
- 死亡最高优先级，其次控制锁定/Timeline动作暂停自动播放，再按横向攀附/攀爬、游泳、普通移动分类。
- 房间管理器通过 `PlayerController.CanAutomaticallyRespawn` 等待死亡表现完成后自动复活，默认死亡动画为0.7秒。等待同时覆盖配置的死亡Timeline长度，暂停时不计时；未配置精灵动画也至少等待0.7秒。主动调用 `RequestRespawn()`（R键）仍可立即打断死亡并重生。
- 死亡或主动重生完成后，角色通知相机跟随组件平滑回到重生点；远距离重生不会触发跟随距离阈值硬切。场景首次定位与主动 `Snap()` 保持即时定位。
- 普通空中运动按竖直速度切换跳跃/下落；落地立即切回待机/移动。被平台携带且没有移动输入时不播放跑步。
- 只有一个播放时钟，不用协程、DOTween或重复Animator驱动Sprite。状态改变从第0帧立即播放，旧动画无法在稍后回写。
- Locked/Action期间保持已有动画进度，不持续覆盖Sprite与显隐，允许演出轨道控制精灵；解除后从新状态第0帧恢复。死亡仍可打断演出锁定；复活取消死亡动画并恢复显示。
- 暂停使用缩放时间，不推进帧。攀爬包含水平攀附，暂复用同一套攀爬动作；没有专门搬运动作时沿用移动动画，物体继续由原搬运系统显示。
- 精灵左右翻转只改SpriteRenderer；面向相机只改外观子对象，不旋转玩家刚体。不要再给该子对象添加第二套常态动画驱动。

## 资源维护

精灵切片采用24×24完整矩形、中心轴、24 PPU。共享材质 `PlayerVisuals/PlayerSprite.mat` 使用URP无光照、AlphaTest裁剪与深度写入Shader，透明留白不写深度，实像素进入水下底图后由水效果混合。基础纹理/颜色兼容属性用于水下采集；不要改回透明队列来掩盖排序问题。没有新增灯光或改动TA像素化/HSV配置。

`Project.Player.Editor.PlayerSpriteAssetSetup.Build()` 用于明确重新生成切片、默认动画和两份玩家预制体，不会自动运行。它会重置默认帧率和预制体表现接线；日常调参直接编辑资产，不运行该生成方法。

本次验证覆盖资源尺寸、状态优先级、打断/冻结/复活和运行时自动绑定；实际窗口视觉与打包效果仍需验收。
