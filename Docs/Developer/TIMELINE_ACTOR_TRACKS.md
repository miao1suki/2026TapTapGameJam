# 玩家 / Boss Timeline 轨道

Timeline 工具包新增两条可直接使用的角色轨道：

- `PlayerTimelineTrack`：控制玩家。
- `BossTimelineTrack`：控制 Boss。

两条轨道都可以保持绑定为空，此时会在片段开始时按 Unity Tag 查找角色：

- 玩家默认 Tag：`Player`
- Boss 默认 Tag：`Boss`

也可以显式绑定角色 Transform；轨道会优先使用绑定对象，绑定为空时再按 Tag 查找。

片段 Inspector 已按“角色查找 / 运动方式 / 玩家输入或 Boss 状态”分区，标签项使用 Unity `TagField`。顶部“本片段操作”用于明确这个片段控制的操作：玩家可选角色位移、移动输入、冲刺、按住跳跃、请求跳跃、锁玩家控制或自定义组合；Boss 可选发呆、移动、跳跃、设置运动开关或死亡，不提供自定义组合。选定后只显示对应参数，运动模式也会隐藏无关项；目标位置可直接读取场景内同 Tag 角色的当前位置。

Boss 入场有额外硬约束：每个 Boss Clip 只能做“发呆 / 移动 / 跳跃 / 设置运动开关 / 死亡”中的一件事。需要多个动作时必须拆到多条 `BossTimelineTrack` 上堆叠，不允许在一个 Clip 内组合多个操作。Boss Clip 面板只显示当前动作的数据，以及可选的“是否生成 Boss / Boss 预制体”。Boss 入场相机轨只允许 2D 正交运镜，不允许 3D 环绕或透视机位。

## 运动

片段支持四种运动模式：

- `无`：只执行角色命令。
- `瞬移`：片段开始立即到目标位置。
- `平滑移动`：从片段起始位置按曲线移动到目标。
- `弧线跳跃`：玩家使用弧线位移；Boss 默认调用 `BossController.RequestJumpTo`，落地后回到追击状态。

目标位置默认为“片段挂载物体 + 偏移”，关闭 `useOwnerAsOrigin` 后偏移直接作为世界坐标。

## 玩家命令

玩家片段可以设置移动输入、冲刺、按住跳跃、请求跳跃和跳跃增强速度，并可选择片段期间锁住玩家控制。片段结束时可以恢复进入片段前的输入状态。

## Boss 命令

Boss 片段的“移动”动作只暴露目标位置和移动速度；跳跃使用控制器状态；运动开关只暴露开启或关闭；死亡动作无额外数据。需要生成 Boss 时打开“是否生成 Boss”，并填写 Boss 预制体。
