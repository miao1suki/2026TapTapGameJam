# 绿色钩子

选中绿色能力后，半透明绿绳随鼠标位置自由转向、改变长度，绳尖有轻微缓动。鼠标周围显示半径0.65格的常亮容差圈，点击圈内最近的合法物体即可挂接，不必精确点中小物体。光标圈没有呼吸，与玩家身上原有的染色范围呼吸圈不同；它绘制在场景深度之上，不会被墙遮掉。圈和点击始终使用真实指针，不等待绳尖跟上；当帧开始拉取或荡绳。绿绳与红蓝线共用玩家身上的起点。绳子能穿过墙和道具，但不能穿出当前房间或通道；玩家和物体仍受实体碰撞阻挡。

## 挂接与脱钩

- 红、蓝接触方块及机关基座：优先拉物体靠近玩家，物体被挡住时改拉玩家。障碍解除后重新优先拉物体。实际拉动限制上下左右，不斜向拽入地面。拉物、接触目标以及双方受阻等待时仍可正常走路，不必跳一下才能恢复；只有真正拉玩家或荡绳时才接管玩家运动。
- 藤蔓、弹性植物、绿色接触方块及其生长体：作为荡绳锚点，左右输入沿摆动切线加速，松开方向后保留惯性并缓慢衰减，不拉走物体。
- 连接中直接点击其他有效目标即可换点，也可点击同一物体的新位置；不必先脱钩或重选绿色。切换保留摆动惯性，不把玩家瞬移到新圆周；无效点击不会松开原绳。
- 接触目标、双方受阻、靠近锚点或等待很久都不会自动脱钩。
- 使用现有跳跃或交互操作主动结束。落地时按跳跃可同帧松钩并正常起跳，空中按跳跃只松钩，不额外空中跳。发射基础5格，边缘额外允许0.5格；容差圈不会让真实挂点继续超出5.5格。挂接维持仍为8格，连续超出8格满0.4秒才断，短暂越界后回来不累计。鼠标移到范围外不会松开绳子。
- 挂绳全程及松绳后1秒，不会因碰到藤蔓、绿块/衍生物或梯子自动进入攀爬；保护只屏蔽自动攀爬，不冻结行走。荡绳主动/超距脱钩保留碰撞后的方向与惯性；主动松绳默认沿当前速度额外助推8%，最多增加1世界单位/秒。松绳后0.25秒防止普通移动逻辑立刻抹掉水平速度，反向输入仍能刹车。R重生、死亡、离开房间和目标失效仍会清理连接，超距清理不额外助推。
- 游戏暂停期间不接收脱钩；演出持有额外控制锁时暂停钩子运动。

## 调整

玩家上的“绿钩子”组件可设置拉动速度、接触间距、荡绳加速度、速度上限、阻尼，以及“挂接范围冗余（格）”“持续超距宽限（秒）”。“主动松绳助推比例”默认0.08，“松绳额外速度上限”默认1；比例设0只保留惯性。“瞄准与容差”内可调指针容差半径（默认0.65格）、发射边缘冗余（默认0.5格）、待机绳尖跟随时间（默认0.045秒，0为即时）。出线/换点视觉衔接默认0.1秒，不延迟玩家运动。高级表现参数折叠显示。没有自动超时和受阻倒计时，旧伸长/命中半径字段仅保留兼容，不再用于正常点击挂接。

快速转鼠标的视觉更新由`GreenHookVisualDriver`在相机更新后每个渲染帧执行（顺序1100，相机1000），物理拉取仍在固定更新（-50）；不使用固定物理频率刷新指针。噪波种子固定，不因转向重新随机枝条；容差圈缓存几何。红蓝预览各只显示最近一个逻辑目标，复用预热的单条线，换目标不叠加上一条淡出；这不改变实际点击染色规则。

性能排查也覆盖连线调用的颜色查询：`ColorCatalog.Find`原先的捕获式`List.Find`会在每次查询创建闭包/委托，现改为保留相同精确匹配顺序的for循环。对象池本身不等于整帧没有分配，仍以隔离复测和实机采样为准。

基座无需重建；运行时自动具备钩子运动组件，未被钩住时仍不可由玩家直接推动。基座移动不会改变其已绑定平台的身份。每个关卡须提交 Scene/`.meta`、Scene 引用的作者资产与新增资源依赖；历史 planning JSON 不再同步。

红块挂着绿绳时仍可给接触的基座供能，不必先松开；搬运中的红块仍不供能。红蓝块拉动保留重力，基座的单实例“使用重力”设置优先。

收集品和四向尖刺的放置见 [无色道具](WORLD_ITEMS.md)。

专项验证入口及其隔离运行约束见[绿钩子接入API](../Agent/Integration/GREEN_HOOK_API.md#验证入口)，本说明不代替真实手柄/安卓与实机手感验收。交付仍须同步 Scene/`.meta`、Scene 引用的作者资产和新增依赖，不能只推送派生资源。
