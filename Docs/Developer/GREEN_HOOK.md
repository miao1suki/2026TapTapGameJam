# 绿色钩子

选中绿色能力后，玩家身旁显示一格长、半透明的藤蔓头，随鼠标或世界指针自由转向。合法点击范围内目标即挂接，当帧开始拉取或荡绳；不等待出线动画，不限制瞄准角度。绿绳与红蓝线共用玩家身上的起点。绳子能穿过墙和道具，但不能穿出当前房间或通道；玩家和物体仍受实体碰撞阻挡。

## 挂接与脱钩

- 红、蓝接触方块及机关基座：优先拉物体靠近玩家，物体被挡住时改拉玩家。障碍解除后重新优先拉物体。实际拉动限制上下左右，不斜向拽入地面；拉物期间玩家原地保持是预期表现。
- 藤蔓、弹性植物、绿色接触方块及其生长体：作为荡绳锚点，左右输入沿摆动切线加速，松开方向后保留惯性并缓慢衰减，不拉走物体。
- 连接中直接点击其他有效目标即可换点，也可点击同一物体的新位置；不必先脱钩或重选绿色。切换保留摆动惯性，不把玩家瞬移到新圆周；无效点击不会松开原绳。
- 接触目标、双方受阻、靠近锚点或等待很久都不会自动脱钩。
- 使用现有跳跃或交互操作主动结束。发射默认5格；挂接后额外留3格，即8格内维持，连续超出8格满0.4秒才断，短暂越界后回来不累计。鼠标移到范围外不会松开绳子。荡绳主动/超距脱钩保留惯性；R 重生、死亡、离开房间和目标失效仍会清理连接。
- 游戏暂停期间不接收脱钩；演出持有额外控制锁时暂停钩子运动。

## 调整

玩家上的“绿钩子”组件可设置拉动速度、接触间距、荡绳加速度、速度上限、阻尼，以及“挂接范围冗余（格）”“持续超距宽限（秒）”。出线/换点视觉衔接默认0.1秒，不延迟玩家运动。高级表现参数折叠显示。没有自动超时和受阻倒计时，旧伸长/命中半径字段仅保留兼容，不再用于正常点击挂接。

基座无需重建；运行时自动具备钩子运动组件，未被钩住时仍不可由玩家直接推动。基座移动不会改变其已绑定平台的身份。每个关卡仍须提交 Scene、同名 planning.json、meta 与新增资源依赖。

收集品和四向尖刺的放置见 [无色道具](WORLD_ITEMS.md)。
