# 绿色钩子

选中绿色能力后，半透明绿绳随鼠标位置自由转向、改变长度，绳尖有轻微缓动。鼠标周围显示半径0.65格的容差圈，点击圈内最近的合法物体即可挂接，不必精确点中小物体。圈和点击始终使用真实指针，不等待绳尖跟上；当帧开始拉取或荡绳。绿绳与红蓝线共用玩家身上的起点。绳子能穿过墙和道具，但不能穿出当前房间或通道；玩家和物体仍受实体碰撞阻挡。

## 挂接与脱钩

- 红、蓝接触方块及机关基座：优先拉物体靠近玩家，物体被挡住时改拉玩家。障碍解除后重新优先拉物体。实际拉动限制上下左右，不斜向拽入地面；拉物期间玩家原地保持是预期表现。
- 藤蔓、弹性植物、绿色接触方块及其生长体：作为荡绳锚点，左右输入沿摆动切线加速，松开方向后保留惯性并缓慢衰减，不拉走物体。
- 连接中直接点击其他有效目标即可换点，也可点击同一物体的新位置；不必先脱钩或重选绿色。切换保留摆动惯性，不把玩家瞬移到新圆周；无效点击不会松开原绳。
- 接触目标、双方受阻、靠近锚点或等待很久都不会自动脱钩。
- 使用现有跳跃或交互操作主动结束。发射基础5格，边缘额外允许0.5格；容差圈不会让真实挂点继续超出5.5格。挂接维持仍为8格，连续超出8格满0.4秒才断，短暂越界后回来不累计。鼠标移到范围外不会松开绳子。荡绳主动/超距脱钩保留惯性；R 重生、死亡、离开房间和目标失效仍会清理连接。
- 游戏暂停期间不接收脱钩；演出持有额外控制锁时暂停钩子运动。

## 调整

玩家上的“绿钩子”组件可设置拉动速度、接触间距、荡绳加速度、速度上限、阻尼，以及“挂接范围冗余（格）”“持续超距宽限（秒）”。“瞄准与容差”内可调指针容差半径（默认0.65格）、发射边缘冗余（默认0.5格）、待机绳尖跟随时间（默认0.045秒，0为即时）。出线/换点视觉衔接默认0.1秒，不延迟玩家运动。高级表现参数折叠显示。没有自动超时和受阻倒计时，旧伸长/命中半径字段仅保留兼容，不再用于正常点击挂接。

基座无需重建；运行时自动具备钩子运动组件，未被钩住时仍不可由玩家直接推动。基座移动不会改变其已绑定平台的身份。每个关卡仍须提交 Scene、同名 planning.json、meta 与新增资源依赖。

红块挂着绿绳时仍可给接触的基座供能，不必先松开；搬运中的红块仍不供能。红蓝块拉动保留重力，基座的单实例“使用重力”设置优先。

收集品和四向尖刺的放置见 [无色道具](WORLD_ITEMS.md)。
