# 绿色钩子

选中绿色能力后，玩家身旁显示一格长、半透明的藤蔓头。点击范围内目标，按上下左右方向伸出钩子。绳子能穿过墙和道具，但不能穿出当前房间或通道；玩家和物体仍受实体碰撞阻挡。

## 挂接与脱钩

- 红、蓝接触方块及机关基座：优先拉物体靠近玩家，物体被挡住时改拉玩家。障碍解除后重新优先拉物体。
- 藤蔓、弹性植物、绿色接触方块及其生长体：作为荡绳锚点，方向输入控制摆动，不拉走物体。
- 接触目标、双方受阻、靠近锚点或等待很久都不会自动脱钩。
- 使用现有跳跃或交互操作主动结束；荡绳脱钩保留惯性。R 重生、死亡、离开房间和目标失效会清理连接。
- 游戏暂停期间不接收脱钩；演出持有额外控制锁时暂停钩子运动。

## 调整

玩家上的“绿钩子”组件可设置伸长速度、命中半径、拉动速度、接触间距、荡绳加速度和速度上限。高级表现参数折叠显示。已取消原来的自动超时和受阻倒计时配置。

基座无需重建；运行时自动具备钩子运动组件，未被钩住时仍不可由玩家直接推动。基座移动不会改变其已绑定平台的身份。每个关卡仍须提交 Scene、同名 planning.json、meta 与新增资源依赖。

收集品和四向尖刺的放置见 [无色道具](WORLD_ITEMS.md)。
