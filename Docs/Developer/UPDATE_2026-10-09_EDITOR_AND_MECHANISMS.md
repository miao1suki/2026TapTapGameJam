# 2026-10-09 更新说明：关卡编辑、门机关与颜色表现

本次将 `codex/editor-mechanisms-pixelization` 的累计开发进度并入 `main`。对比基线为 `01156a0`，包含前次分支提交 `c0edca9`、后续门操作修正，以及当前已保存的 Pick 场景。Unity 版本保持 **6000.3.12f1**。

## 关卡编辑器

- 新增与选择、绘制、擦除同级的“合并”和“参数”模式。同一房间内同类、无重叠且填满矩形的物体可生成单一实例，保留一套逻辑；可解除合并并还原原始数据。
- 参数模式区分“栏目中新放置物体的默认参数”和“已放置物体的独立参数”，提供中文字段、分组和用途说明，不改写预制体资产。
- “应用到场景”作为顶部常用操作，默认增量更新。未变化实例保留；增删、尺寸或参数变化更新对应实例。全量重建为独立的确认操作。
- 自动同步按 Scene 记忆，规划编辑自动应用；场景内手动删除受管生成物体会回流至规划，并通过同步暂停与来源绑定避免循环删除。
- 每个 Scene 独立记忆规划、存档路径、视图模式、房间、画布位置和缩放。首次使用的新 Scene 默认空地图；本地工作区不等于已保存的 Scene，也不自动共享给其他电脑。
- `M` 开关窗口；窗口焦点内 `W` 打开世界图、`R` 打开房间详情，文字输入和运行模式不响应这些视图快捷键。
- 窗口打开时，非运行模式下 `Ctrl+Z` 走规划历史，`Ctrl+Y` / `Ctrl+Shift+Z` 重做；关闭窗口后恢复 Unity 撤销。移除临时生成层级的原生 Undo 记录，修正绘制回调修改视觉树的风险。
- 优化道具栏布局、缩略图自动刷新、应用按钮焦点反馈，以及合并长条正面预览的边缘虚化问题。关卡窗口和参数窗口优先使用简体中文系统字体。

详细操作见 [融合关卡编辑器](LEVEL_EDITOR.md)。

## 门与专属按钮

- 新增独立、非颜色的门和按钮状态机，不接收染色，不复用红色拉杆的开关逻辑。
- 在规划道具栏放置门，固定占格 **1×2**，附近自动生成一个绑定按钮。参数模式点击门可追加按钮，选择模式可移动按钮，擦除按钮会解绑，擦除门会清理其所属按钮。
- 门与按钮在规划视图、Scene 中用黄色虚线连接；保存规划保留绑定 ID，增量应用完成后重新绑定实际场景实例。
- 门的鼠标和拖拽提示显示两格，与实际落点一致；一次手势只放一扇门。规划预览以绿色/红色区分放置条件。
- 按钮占位模型改为平放在格底的薄板，无实体阻挡，保留 Trigger。玩家靠近后按现有交互键 `E`，按钮保持已按下。
- 全部绑定按钮按下后，门关闭阻挡碰撞，绕侧边门轴旋转 90°；接入现有 Timeline 相机轨道，移向门、停留后返回玩家。实际相机仍由 Camera Manager 管理。
- 门可响应既有房间重置事件；本次没有把 R 重生或离开房间自动接到颜色/门重置流程。

规划中的自动按钮、追加和解绑应使用房间详情或装配图；世界图上的房间连接“门”是另外一种规划标记。详细操作及接口见 [门与按钮](DOORS.md)、[门 API](../Agent/Integration/DOOR_API.md)。

## HSV 与像素化管线

- 分离编辑识别材质与运行时正式外观。颜色恢复按“黑白基础外观变纯白 → 交接纯白正式外观 → 恢复颜色”执行，Game 不使用蓝色边框识别材质。
- 放慢默认渐变节奏，并适配钥匙演出的等待时间；补充 HSV 管理器的管线状态、通道执行和颜色进度调试信息。
- 调整选择性遮罩的覆盖路径，包括透明水体与粒子拖尾；使用独立遮罩材质和显式 RenderGraph 纹理/参数绑定。
- 接入 URP 学习项目的整数像素块、块级归约和点采样放大算法，附带 MIT 许可。选择范围为 Rendering Layer 位 7（128）或旧 PixelEffect 普通 Layer 12。
- 处理顺序明确为 **场景与透明效果 → 像素化 → HSV → URP 后处理**。旧 `02StencilPixelEffect` 停用，避免重复像素化。
- 描边默认关闭，像素化仍启用。运行时可调用 `PixelizationControl.SetOutlineEnabled(bool)`；PC/Mobile Renderer 均显式绑定新 Shader。

详细说明见 [选择性像素化](PIXELIZATION.md)、[像素化 API](../Agent/Integration/PIXELIZATION_API.md)。屏幕空间算法仍需实际运动与分辨率测试，不保证完全没有格点跳变。

## 藤蔓与玩家

- 连续竖列藤蔓在编辑器仍逐格编辑；生成时按同房间、同列、同预制体和格尺寸组成根系，最下方为母藤蔓，上方为预置子节段，进入游戏时已长满，不让子节段重复生长。
- 母根统一管理 TA 藤蔓粒子，按 30.13 至 32.43 的采样过程过渡；适配根系高度，加粗整束与枝条，未解锁绿色时不生成正式藤蔓表现。
- 红色作用于任意节段时，只在所属根系中自顶向下逐段燃烧，并倒放粒子生长过程；预置节段保留重置能力，不影响其他根系。
- 粒子种子初始化先执行 `StopEmittingAndClear`，避免播放中修改随机种子的报错。
- 攀爬时 W 或朝藤蔓方向的水平输入均可上爬；反向输入离开，朝藤蔓方向加跳跃可向外上方蹬跳，并短暂阻止重新抓附。
- Test 的测试玩家接入新版轮盘，并更新正式玩家相关攀爬参数。
