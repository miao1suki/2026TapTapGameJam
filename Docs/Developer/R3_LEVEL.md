# R3 独立测试关卡

Unity **6000.3.12f1**。场景 `Assets/Scenes/R3/R3.unity`，可编辑存档 `Assets/Scenes/R3/R3.planning.json`，来源 `R3.design.json`。它们与 `.meta`、新增依赖成套交付；不替代正式 Gaming，不加入构建列表。

## 打开与试玩

本机在 Unity Hub 添加／打开 `C:/Unity Programs/2026TapTapGameJam-R3`，再打开上述 R3 Scene，进入播放模式。不要同时在另一 Editor 打开这个同一目录；R1/R2 的独立测试目录不受本关制作影响。

开局场景红、绿、蓝全部启用，玩家仅开放蓝色能力，普通跳跃沿用标准玩家默认 4 格。使用现有项目输入：移动／跳跃、Tab 调色，选蓝后左键命中绿块；F 操作曲柄或搬运，Q/E 左右放下，R 重生并恢复当前区域。按键可在项目设置中重绑，以当前游戏提示为准。

独立试玩从 **Z96** 出生；Y97 仍保留连接下方 R2 的洞口。独立 Scene 不包含 R2，不代表跨关连接已整合。`R3SceneSetup` 只配置独立试玩权限，日后导出片段拼入正式关卡时不要复制它或额外的玩家、相机、UI。

平台底端已移到岩浆上方，平台及附着物全程不进入岩浆，避免蓝块开局冷却整片岩浆；原岩浆占格与现有接触反应均不修改。原表第92行平台只是设计示意，最终起止范围以上表为准。

绿块沿用 main 的蓝色命中生长规则，不另加蓝块。水平第一次生长方向远离玩家；上下方向按玩家相对行决定，长出后锁轴，缩回1格可换向。长度参数是最大限制，蓝色点击并不预设永久生长轴。实际实体或玩家占据新增格会暂停生长，移开后继续。

## 后续编辑与协作

用关卡编辑器加载 R3 Scene 配套规划存档。Scene 与同名 planning 一起保存、提交；不要只改来源 JSON 后重建覆盖已保存的人工微调。`R3LevelBuilder.Build` 仅用于首次创建，拒绝覆盖已存在场景。

`PlanningBox.platformMountId` 保存平台附着关系；Scene 重建、片段导入重映射、布局回采和平台删除清理均保留此规则，不用临时 instanceID 或物体名字绑定。当前 Inspector 只读显示平台与局部锚点，不提供未接入规划存档的临时手动绑定。整合时必须同时带入 `PlatformMount` 及相关规划／接触方块／搬运最小支持，不只复制 Scene。

专项检查入口：`R3LevelBuilder.FinalAudit` 检查来源、Scene、配套和内嵌 planning、一致的碰撞占格、片段关系重映射、删除来源清理、无变更应用及依赖；`R3GameplayVerification.Run` 在静音隔离 R3 目录做实际 Play 检查，`RenderAudit` 另取真实 Game View。报告和截图仅存 Library，不提交。

专项验证不等于从入口到出口的完整人工通关，也不等于 Windows／Mac／Android 打包验收。最终验证范围见 `Docs/Agent/ACTIVE_WORK.md` 的本关记录。
