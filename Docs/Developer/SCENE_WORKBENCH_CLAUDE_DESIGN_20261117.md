# Claude 布局主方案（2026-11-17）

通过既有固定 Claude Code 2.1.34 工作流单次 Design 获得；输入只包含 UI 裁图与本轮产品简报，无项目遍历权限。下文为设计建议，验收状态以实施报告为准。

# 关卡编辑器主方案：一个紧凑主体 + 内嵌资源抽屉

**证据边界**：附图只证明现状。可见问题有四个：①两个同色蓝主按钮并列，层级冲突；②大量 10–11px 灰字，对比不足；③物体与美术分在两个模式，选择区和参数区隔开；④约 40% 纵向空间被说明文字和低频折叠区占用。交互是否通过，需实机验收。

## 1. 信息架构（从上到下，单 Overlay，宽 380 默认）

1. **状态条（高 32，固定）**：左侧是落笔状态圆点加文字「落笔中/暂停」，点击切换；右侧是两个独立徽标「Scene ●未保存」「Map ●未保存」，各自可点保存。取消「继续搭建」大按钮，落笔状态只由状态条承担。
2. **工具条（高 36，固定）**：画 / 擦 / 矩形 / 点选改参 四个等宽图标按钮，快捷键 B/E/R/V。选中态用主色，这是全界面唯一实心主色元素。
3. **图层条（高 28，固定）**：墙 / 水 / 道具 / 美术 四个 chip，每个带眼睛和锁。同格叠放以色条区分：墙在底、水在中、道具在上，悬停格子显示叠放列表。
4. **资源抽屉（可伸缩，默认约占剩余 45%）**：顶部是「物体 | 美术」分段控件和搜索框；下方是缩略卡片网格（卡片 72×72，名称 11px 在下，每行 4 张）；选中卡片有 2px 主色描边。两个 Tab 共用同一网格组件，差异只在筛选项：物体带「玩法类别」，美术带「图层/主题」。**不再开独立选择窗**。
5. **检查器（可伸缩，默认约占剩余 35%）**：点中实例后显示当前选中的缩略图、名称、真实 Inspector 参数，门/按钮绑定在此用「选择目标」拾取按钮，再点一次 Scene 对象完成绑定。未选中时显示空态：「点选场景中的物体以编辑参数」。
6. **房间导航（底部折叠条，默认收起，高 28）**：展开为 5×N 小地图格，格色表示是否有内容，当前房间描边，搜索框按房间号定位。四邻接以格子边缘小箭头表示。导航只读，点击定位时自动暂停落笔并在状态条提示。
7. **危险区（折叠到「更多 ⋯」菜单）**：房间整体移动、批量删除。点击先弹预检面板，显示影响对象数与目标是否冲突，需勾选「确认」后「执行」才可点。

删除常驻的「当前 Scene 只读摘要」，改为导航展开时底部一行小字。

## 2. 物体与美术的合并
选择区与检查器同屏，选卡片后直接在 Scene 落笔，点实例后检查器自动切换，不需要切窗口。通过图层条决定当前写入哪一层，避免物体与美术相互覆盖。

## 3. 宽度与最大化行为
- **正常态 330~420**：卡片列数随宽度自适应（330 为 3 列，420 为 4 列），主体纵向滚动，仅抽屉与检查器区滚动，状态条/工具条/图层条钉住不滚。
- **Scene 最大化**：Overlay 停靠左侧，宽度固定 340，高度不超过视口的 85%，且不占用画布中心。资源抽屉可再折叠成一行「当前选择」缩略条，只剩状态条、工具条和这一行，约 110 高；快捷键 Tab 展开或收起。导航改为悬浮小地图，位于右下角，可关闭。

## 4. 视觉规范
- **背景** #1E1F22，卡片 #2A2C30，描边 #3A3D42。
- **主色** #3B82F6（仅用于选中和落笔中），**成功/已保存** #3FB27F，**警告/未保存** #E0A030，**错误/危险** #E5534B。
- **正文** #E6E8EB 12px，**次要** #A0A5AD 11px（不再用更小的字），**标题** 13px 加粗。
- **间距** 区块 8，内边距 8，控件间距 4。按钮高 28，工具按钮 36×32，最小点击区 24。
- **禁用态**：透明度 40%，并附一行原因文字，例如「落笔暂停中，无法绘制」。
- **空态**：搜索无结果时显示「没有匹配项」和「清除筛选」；错误态用红色描边加一句可执行提示，例如「目标超出房间边界，请缩小移动距离」。

## 5. 验收与首要动作
**验收（需实机确认）：**
1. 在 330 和 420 两种宽度下，状态条、工具条、图层条无需滚动即可见，抽屉与检查器滚动不遮挡它们；Scene 最大化时画布中心无遮挡。
2. 选一张美术卡片落笔、再选一个物体落笔，同格墙/水/道具三层可通过图层条分别隐藏和锁定；点中实例后检查器显示真实参数，并且修改后 Inspector 值同步。
3. 房间移动必须先出现预检面板，未勾选确认时执行按钮保持禁用，导航定位时落笔自动暂停，Scene 与 Map 保存状态各自独立变化。

**最优先实施动作**：先实现「状态条 + 工具条 + 共用资源抽屉（物体/美术合并网格）」，因为这一步直接消除双蓝按钮、独立选择窗和选择与参数分离三个主要问题，其余部分可在此骨架上逐步迁入。实现差异请逐条记录回传，由我复审。
