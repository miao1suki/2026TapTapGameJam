手动调整：

1. 打开 `Assets/Scenes/R1/R1.unity`，Hierarchy选 **Main Camera**。
2. Inspector找到 **R1 弹性植物镜头提示**（脚本名`R1SpringCameraGuide`）。在“镜头大小与过渡”保持 **“自动保证植物入镜”不勾选**，即可直接调整“拉远尺寸”（数值大则视野广，数值小则视野近）。触发后实时改大、改小都生效，变化时长沿用“拉远时间”。此提示只放大、不缩小普通视野，因此最低为相机当前普通Size（现为12）。手动尺寸太小可能看不到植物，需要自己试玩确认；其他区域镜头或演出优先权仍保留。
3. 想交给系统保证完整入镜时，勾选 **“自动保证植物入镜”**。字段随即显示“最小拉远尺寸”：填写值变为下限，系统按实际画幅继续放大并保持本次最大值。此模式才显示高级组的“画面安全边距”。运行中取消勾选，会立即解除自动最大值限制，按手动填写值过渡，不用重开播放。
4. “按钮附近的触发范围”可改宽、高、相对按钮上移；当前保留策划保存的宽3格、高6格、上移0.5格。选中相机、打开Scene辅助线可见金色范围框。这不是实体，不改地图碰撞。
5. 播放期间可试数值，手动模式不需重开即可比较不同大小；若需要长期保存，请退出播放后再填写满意的值、按Ctrl+S保存Scene。尚未进入触发范围时改参数只会影响下一次触发，不改变平时的普通镜头。

人工验收：关闭自动入镜，在U26触发后先填20、再填16，确认能实时拉远及缩近；再勾选自动入镜，确认植物完整可见，取消勾选可回到手动值。离开按钮跳下时镜头提示持续，落上植物/被弹起后平滑恢复12。手动16是否足够看清目标由策划自行确认；可另验已踩按钮后重试、携带落地与R重生均不残留镜头。
