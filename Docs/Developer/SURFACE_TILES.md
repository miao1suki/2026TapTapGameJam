# 方块贴画与不规则切片

这是保留的六面表面贴画工具。横版墙地与背景优先使用[关卡美术工作台](GRID_ART.md)，避免每块玩法物体维护独立外观。旧开发目录图集只用于原开发工具，不扩散为正式美术。

## 建瓦片库

把新图片导入Assets，打开 `Tools/2026TapTap/方块贴画/导入不规则瓦片图`。
在“源图片”字段直接选择图片。主区域显示原图，可以缩放、滚动、拖框新增图块。
“识别完整图块”默认保留整块；“追加独立碎片”会在完整块之外增加碎片，不替换完整块。
点击框选中，右键框/取消模式点击/列表×删除；Delete取消当前选区，Ctrl+Z撤销。
输出设置里配置图集容量、输出路径；统一16有效源像素/格。整数导出倍率只适用于整图严格最近邻放大的素材，生成时会逐像素验证。图集容量不足会提示扩大，不压缩图片来塞入；新方案默认不裁透明边缘。选择“生成瓦片库”后指定给方块。

旧导入方案保留旧排布，不自动改动已绘制场景；有警告时可显式“改用16有效像素/格”后重新生成。直接由Sprite创建的新库使用原像素尺寸；旧ReplaceTiles接口继续保留单格契约，agent新接入使用ReplaceTilesAtNativeScale。完整换算见[场景美术像素标准](SCENE_ART_PIXEL_CONVERSION.md)。

## 贴画与保存

Scene中的方块表面贴画面板：选方块 → 添加可贴面组件 → 指定库和每格世界尺寸 → 开始绘制。
大瓦片按实际格数铺开，可叠加透明图；锚点贴边、旋转/翻转和X/Y微调以格为单位。
透明底仅隐藏原模型颜色，不改碰撞体，不实现单向/视差平台玩法。
面板标题可拖动、折叠、关闭；菜单可重开。Esc退出绘制。
只选择Hierarchy场景实例；拒绝直接编辑Project Prefab及Prefab模式共享源，不应用Prefab覆盖、不改白块共享材质。
“合成贴图并持久化保存”生成Mesh/Material/PNG并写入对象引用。必须先保存Scene，输出按Scene GUID隔离，避免同名关卡覆盖。随后保存Scene，资产和.meta一并提交。
不要只拷贝PNG而丢掉Mesh/Material，也不要把Library缓存当成生成结果。

原六面烘焙仍要求单源图集。多图片的切片集中检索、分层铺绘或自动边角，使用关卡美术工作台共享库，可保留各切片的尺寸与有效裁区。
