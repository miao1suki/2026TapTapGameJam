# 标注地图测试场景

场景：`Assets/_Project/Development/RoomLifecycleTests/MVMapImportTest.unity`。
共享关卡存档：同目录 `MVMapObjects.planning.json`。
源图：同目录 `MVMapSource.mvmap.json`，来自 `map.mvmap (3).json`。

## 继续编辑

1. 打开 MVMapImportTest 场景，按 **M** 打开关卡编辑器。
2. **W** 查看世界图，选择房间后按 **R** 查看房间详情；装配图可以编辑全图。
3. 方块、道具、合并尺寸和组件参数都保存在规划存档中。“应用到场景”使用原有增量同步，也可以开启自动同步。
4. 在存档面板选择“标注关卡 · 门与水域”。这份共享存档会显示在当前场景的列表中，修改后保存到项目文件；提交时场景与 JSON 一起提交。

场景内也保存同一份规划数据。在另一台机器首次打开时，编辑器会从场景恢复地图，并识别同目录匹配的 `.planning.json`，不要求复制 Library 或 EditorPrefs。不是只能操作场景里生成的模型。

## 已制作范围

按标注截图制作源图 **X=27～99、Y=−52～0** 的部分。紫色只作房间范围，不生成墙。

| 内容 | 配置 |
|---|---|
| 上层机关房、下层水域房、右侧水流房 | 三个独立房间；图中未划分的剩余区域独立标为“未划分区”，不推测第四个房间 |
| 白色/灰色墙 | 白方块；保留缺口和不规则几何；合并长条可解除合并后逐格编辑 |
| 标注下层蓝色水域 | 水源预制体，按原几何拆分，不填满包围盒 |
| 上层横向转弯水流 | 右端起点，先向左、转弯向上、再向左；各段方向可在参数模式修改 |
| 右侧两条下流水流 | 顶部深蓝起点向下；最右列按确认改为向下水流，而非上喷气泡柱 |
| 两条上喷气泡柱 | 下方起点向上，包括上部左列及其下方另一列 |
| 单向平台 | 六格长，一个整体物体，使用已有从下穿透/上方落脚逻辑 |
| 左侧门 | 一个 1×2 门，绑定三个按钮；两个一次按下保持、一个持续压住 |

深蓝单格是方向起点，不作为墙或独立可搬运方块。起点并入对应水流/气泡体积。横向水流右上方未明确用途的额外标记保留为可编辑规划注释，未创造新机关。

起点重生点为测试辅助，也通过关卡编辑器数据生成，可移动/删除；没有补入标注外的钥匙、藤蔓或其他玩法。水族仍遵守蓝色解锁，可在既有运行态颜色调试界面解锁蓝色测试。
