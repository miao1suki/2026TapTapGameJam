# 关卡美术工作台

入口：关卡编辑器“网格美术”，或 `Tools → 2026TapTap → 关卡美术 → 网格美术编辑器`。原方块贴画面板也提供“关卡美术工作台”入口。

## 推荐流程

**白块负责碰撞与玩法，美术图负责外观。** 不需要每块地板另做预制体，不修改白块的共享材质。

1. 用关卡编辑器搭白块、合并长墙。从“网格美术”进入，或直接打开美术工作台；工作台会读取当前关卡草稿、配套规划存档，或场景已生成的白块，不需要到Hierarchy选物体。
2. 点击“创建本关美术图”。数据自动放在场景旁的`<场景名>_Art.asset`，无需管理保存路径；默认选择“墙地表面”。已有美术图会自动找回。
3. 左侧选素材，右侧“关卡墙地”选择整关、房间或通道，点击“自动铺绘并跟随墙地块”。黑块、白块及自定义墙地块都支持；新增、擦除、移动、合并后底图随之更新，孔洞不补满。只想铺一次可用“仅铺绘一次”。自动层不可直接涂改；需要自由修改时点“转为手工绘制”，或新建装饰层。
4. 中央画布调整，或勾选“场景绘制”在Scene中画。左键绘制，右键擦除，框选批量铺绘。装饰和大图放独立图层，同一格可以叠多层图片。
5. “自动保存美术”和“实时场景预览”默认开启，停笔约0.65秒后合并处理。最后点“保存场景”即可交付；运行时直接读生成的Mesh/材质，不重新切图和铺格。“刷新场景”用于手动更新预览。

### 自动保存的范围

自动保存写入本工具的美术图和素材库；关闭、切换场景、重编译前补存完成的笔画，进入Play前处理待更新的关卡轮廓。不自动保存整个Scene，避免把其他尚未完成的玩法改动一起保存。状态栏分别显示“美术已保存”“场景待保存”。

Scene尚未保存时不能创建本关美术图，请先保存Scene。即使未保存生成场景，美术数据仍可由工作台找回并重建预览；交付和打包前必须点“保存场景”。开关按本机/项目/场景记忆。关闭自动保存后，数据保留为未保存状态，需主动保存。

检测到美术图文件被外部修改时停止自动覆盖，当前内容备份到`Library/GridArtRecovery`并提示；请先核对外部版本再继续，不能把Library备份当作团队交付。

窗口可拖动、停靠、关闭；素材栏和图层栏可隐藏，高级设置可折叠。素材库支持搜索、分类、大缩略图，按可用宽度自动多列排列，默认侧栏为两列（含高DPI边距取整余量），不横向滚动；选素材保留滚动位置。中键平移、滚轮以鼠标为中心缩放，“居中”找回全部美术；空图按关卡参考轮廓居中。视图按美术图记忆，当前美术图按场景记忆；他人打开已应用的场景时，从场景输出找回美术图，不依赖本机设置。

## 共享素材与切图

默认共用 `Assets/_Project/Content/Art/SceneArtLibrary.asset`。共用素材定义，每关画过的位置仍独立。

- 提供20种墙地纹样、自动白线边框、拆分边框／完整边框、三色壁饰／草饰／波纹／立柱／雨滴，以及已接入正式2D外观的静态摆件。已审计的共享库现有178项；来源、裁区与尺寸见[共享素材盘点](SCENE_ART_LIBRARY.md)。不修改原图，不扩散旧开发图集。
- “切片导入”打开不规则切图工具：选图片、调整选区、生成库。返回共享库窗口时会汇入新切片，也可展开“素材来源”点“同步项目与切片素材”，或菜单“关卡美术 → 同步项目共享素材库”。多张图的切片可共用一库，重复同步不新增重复项。
- Unity Sprite Editor切好的图片或单个Sprite，可拖进“图片／切片”，点击“加入当前库”。统一16有效源像素/格；普通Texture请先切片或设为单张Sprite。
- 保留切片的有效内容范围，不把图集防串色留边当作图片缩边；大图保持占格比例，细长图支持小数显示尺寸。
- “配置当前素材”或右侧“当前素材设置”编辑名称、分类、逻辑占格、颜色归属、整数导出倍率、法线图集和边角规则。显示尺寸由有效源像素计算，不能任意拉伸。旧比例显示警告，确认后可“恢复原像素比例”；会影响共享此素材的其他美术图。定义由各关共享，位置数据各关独立。
- 草饰拆分片是单款，草饰组合保留原图两行排布，不代表动画。雨滴只作为原始图片，不会自动创建下雨效果；实际下雨／萤火虫请用“区域效果·雨／萤火”。“道具外观·无玩法功能”和“告示牌外观·无触发”仅作摆件，需要可交互机关时仍用关卡编辑器。
- 旧GridArt图要统一素材时，使用“接入共享素材库”：追加原笔刷并重映射全部图层，不直接换库引用。已有编号不能重排或删除。

原图建议Point、无Mipmap、无损或不压缩，最大尺寸足够保留像素。帧动画板不要当单格静态装饰。

## 墙地与装饰

墙地是固定XY平面的外观，不是投射式Decal。默认Z=-0.51适用于中心Z=0、厚度1的白块；其他深度、厚度要调整图层Z，避免藏在模型内部或深度竞争。

自动地形配置九宫格（左上／上边／右上、左边／中心／右边、左下／下边／右下）及四内角，相同笔刷按八邻格连接。缺内角时提示并回退中心，不生成不存在的美术。tail白线边框尚缺独立内角，复杂内凹轮廓需补图。

大图按宽高铺开，框选按占格排布，不压进单格。细长显示尺寸保留透明叠底。同层同锚点只留一个笔刷，叠图请新增装饰层。轮廓铺绘仅接受单格或自动地形，防止多格装饰重叠。

例如墙面叠草边：墙地表面放墙图，点击“+装饰”后在同一格画草边；需要再叠叶片就再建一层装饰。图层列表越上方越靠前，“前移／后移”调顺序，勾选框控制显隐，“锁定”防误画。透明PNG自动透出下层，整层透明度在“深度、受光与网格 → 颜色／透明度”调整。

素材“解锁颜色归属”决定场景颜色解锁时的HSV褪色；图层默认“继承素材”，也可覆盖为指定颜色或全部无色。同一美术层可混放红绿蓝，生成时按颜色分别合批并使用颜色目录的Unity层，互不串色。它们不成为可交互颜色物体，不生成碰撞；解锁前保留原图形状，只受褪色控制，不参与初始白块/真实材质的透明切换。

自动轮廓读取黑白及自定义墙地块（包括旧Platform白块），排除水、道具、房间范围与规划区域；合并块保留覆盖孔洞并去重。优先当前关卡窗口的草稿，其次同名planning.json；没有规划数据时读取场景LevelEditorPlacedBlock的非道具占格。规划坐标自动转为世界XY。旋转物体、非矩形模型请用手工图层，不按所有碰撞体随意铺图。其他工具如需提供轮廓可接入GridArtLevelSource适配器。

## 大图与视差背景

1. 将背景图导入为Sprite，通过“素材来源”加入库。640×320原始像素图显示40×20格；若是经确证的4倍最近邻导出，设置整数导出倍率4后显示10×5格。不能只为缩小背景而填写倍率。
2. 点“+远景”或“+中景”，选背景图片，在画布或Scene放置。没有背景素材时，不默认拿主菜单UI图代用。
3. 拖画布下方“视差预览”看相对位移；不移动真实相机、不改存档。
4. 应用保存后，运行中的GridArtScene自动读取主相机，也可在Inspector指定跟随相机。

远景／近景背景的正Z深度显示在关卡参考后方，不会遮住用于定位的黑白墙和道具；表面／前景的零或负Z深度仍显示在参考前方。前移／后移调整同一背景或前景分组内的叠放，不能把背景移到玩法前面。顶部“关卡参考”仍可单独隐藏或调整透明度；这些定位设置不修改关卡与美术存档。

| 预设 | 视差速度 | 用途 |
|---|---:|---|
| 墙地、装饰 | 1 | 普通世界物体 |
| 远景 | 0.25 | 远处背景 |
| 中景 | 0.6 | 较近背景 |
| 前景 | 1.15 | 镜头前装饰，可遮挡玩家 |

0保持屏幕位置，1为正常世界速度。根据相机相对初始位置算绝对偏移，移回不漂移；新背景按16有效像素/格吸附。旧背景保留原值，Inspector可显式统一。完整尺寸换算见[场景美术像素标准](SCENE_ART_PIXEL_CONVERSION.md)。

当前仅固定XY水平／垂直平移视差。没有大图无限循环、缩放补偿、转向重投影、多地形过渡、随机变体或动画瓦片。给镜头移动留足背景覆盖余量。自动底图会随房间白块更新；手工装饰和背景不会自动随房间搬移。

## 实例安全与协作

Prefab实例本来就可以不同外观；影响全部实例的是改共享源材质、将覆盖应用到Prefab源或共用同一份绘图数据。本工具不改白块材质，不向白块Prefab应用覆盖。

美术图首次应用后记录所属场景，其他场景只读打开，需“独立副本”后再绘制／应用。复制会切换当前场景已有输出，避免叠两份；生成文件按Scene GUID隔离，同名关卡也不互相覆盖。

交付包含Scene、同名`.planning.json`、美术图、素材库、原图、生成Mesh/Material及各自`.meta`。不能只交Scene或PNG。生成目录为 `Assets/_Project/Art/Generated/GridArt/<场景GUID>/<美术图GUID>/`。不要将手工物体放入“美术层_”生成子树；应用替换该子树，不删除其他根和手工兄弟节点。

绘图、图层支持Undo；画布Ctrl+Z／Ctrl+Shift+Z撤销／重做，自动保存与预览随后更新。自动生成不额外占用撤回步数。Scene退出取消当前未完成笔画，关闭窗口释放工具。未引用生成资产不会自动删除，避免误删他人资源。跨关卡复制时自动层先转手工，防止旧房间ID造成图案被清空，需重新选择本关铺绘范围后再联动。

## 响应与性能

绘画时不落盘、不生成场景；结束笔画后延迟合批。侧栏不随每一笔销毁重建，移动指针不扫描项目；空闲只检查待办标记。绘制/擦除使用格子索引，缩放预览剔除屏幕外图块并复用绘制缓冲。实时生成保留未变化的层/网格对象，只写有变化的Mesh/Material，不把整关当作每帧重建对象。

画布瓦片预览按纹理和原图层顺序分批缓存；平移与缩放只更新视图变换及批次可见性，不重写每张瓦片的顶点。绘画、撤回、素材修改及视差变化才更新相应预览。远景网格自动稀疏，近景恢复逐格；实际绘制仍按原单元格命中，不改变图片、图层、地图尺寸或生成场景效果。

首次大图生成仍需要创建资产，可能比日常编辑慢；低性能设备可关闭“实时场景预览”，继续流畅编辑后主动刷新。当前优化不等于无限地图无开销，请按关卡拆分数据。

## 六面与法线

正方体六面、表面旋转／翻转／贴边／微调继续用[方块贴画](SURFACE_TILES.md)。只改当前Scene实例，拒绝直接修改Project Prefab及Prefab模式共享源；合成文件按Scene GUID隔离。

新库保留“法线图集”，必须与颜色图同尺寸、同排布、按法线贴图导入。图层启用“接收3D灯光”后走URP Lit；默认Unlit。Mesh含法线和切线，同UV采样。**尚未接入URP 2D Light/Sprite-Lit路径**。颜色归属已接现有分层HSV，TA其他Shader、像素化、转向效果需分别验证。
