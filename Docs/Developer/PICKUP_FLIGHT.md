# 拾取飞行动画测试

打开 `Assets/Scenes/Pick.unity` 并运行。测试玩家附近有三个彩色测试球；走近任意一个，它会先沿弧线甩向远离玩家的随机落点，转向时仍保留一点向外的惯性，再绕弧线快速飞到头顶，短暂放慢朝中心移动，最后较快地收进玩家中心并消失。三个球只用于观察动画，不会解锁颜色、获得道具或改变背包。

选中测试球上的“拾取飞行动画”组件，可调整反弹时间与距离、随机幅度、后续三段时长、头顶高度和路径弯曲范围。视觉对象是独立子对象；播放完成后只隐藏该外观，测试物根对象仍留在场景中。正式三色钥匙现已通过 `DropItemBase` 接入同一飞行动画：进入玩家拾取感知圈时先磁吸，碰到玩家后解锁、飞行并播放镜头演出，表现结束后回收。详见 `Docs/Agent/Integration/PICKUP_FLIGHT_API.md`。
