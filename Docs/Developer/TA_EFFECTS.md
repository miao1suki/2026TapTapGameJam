# 岩浆、燃烧、RGB 与雨区

现有岩浆会自动使用 TA 流动表面和喷溅；蓝色冷却时出现一次蒸汽。普通藤蔓、植物障碍和弹性植物使用烧毁表现，原有烧毁、房间恢复和碰撞规则不变，无需重建已有关卡。

标准玩家死亡会播放 RGB 分离效果，真正复活完成后淡出；Boss 真正开始右移追逐时启用轻度版本，死亡效果优先。没有把演示场景加入正式流程。

## 放置雨区

1. 打开要编辑的关卡，选择 `Tools/2026TapTap/关卡美术/创建雨区`。
2. 设置红/绿/蓝、位置、覆盖范围、密度与种子，点击创建。
3. 在 Scene 选中雨区，在 Inspector 调整下落速度、错峰与范围；支持 Undo，运行时不能创建。
4. 保存场景。雨是独立美术对象，不会因关卡编辑器“应用到场景”被清除。

雨区初始随所属颜色褪色，颜色解锁后恢复；不产生碰撞或能力互动。雨滴严格按 16 有效像素/格显示，密度不够时调密度，不缩放单颗雨滴。每区上限 512 颗；不建议用多个完全重叠雨区堆密度。

雨区目前保存在 Scene，而非 planning；提交时仍必须连同关卡同名 planning.json、meta 和新增资源一起交付。用关卡片段拼接只会转移玩法记录，独立雨区须同时移交或重新按参数创建。

## 放置萤火虫

选择 `Tools/2026TapTap/关卡美术/创建萤火虫区域`，设置范围、位置、数量与固定种子，创建后保存场景。Inspector可调整游动、近玩家驱散、呼吸与柔光；实时点光默认关闭，确有受光材质需求时才少量开启，最多4盏。

萤火虫是中性美术，不随颜色解锁，不产生碰撞或交互。硬光点为1/16格，不缩放单颗来提高密度；每区上限128只。它与雨区一样保存在Scene，跨关卡拼接时需单独移交，不能只导出玩法存档。

更多开发接口及分支来源见 [TA 效果接入](../Agent/Integration/TA_EFFECTS_API.md)。
