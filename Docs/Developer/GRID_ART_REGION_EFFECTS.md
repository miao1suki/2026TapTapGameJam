# 工作台区域效果

关卡美术工作台右侧的“区域效果 · 雨 / 萤火”可以直接画区域，不需要先在 Hierarchy 选物体，也不要求先建静态美术图。

1. 选择“框画雨区”或“框画萤火区”，设置颜色、密度或数量。
2. 在中间画布拖出矩形，松开生成；Esc取消。中键平移、滚轮缩放沿用工作台操作。
3. 自动切回“选择区域”；点击活动框或区域列表，在同一面板改范围、位置、颜色、动画、随机种子和深度。重叠区域可从列表准确选择。
4. 删除使用“删除此区域”，支持 Undo / Redo。绘制、擦除图案按钮会退出区域工具。
5. 点击工作台上方“保存场景”。区域存在 Scene，**不写入 planning 或 GridArtMap**；交付须包含 Scene/`.meta`、引用的作者资产与资源依赖，历史 planning 不再同步。跨 Scene 移交时需显式带上这些独立美术根及其依赖。

画布显示活动范围框，不把整片雨或萤火压缩成一个格子的缩略图。真实外观在 Scene 里立即可见；范围框不会进入游戏画面。既有独立创建雨区 / 萤火区菜单继续可用。

## 原像素与预算

- 当前关卡的格尺寸由工作台传入独立美术根的 `ArtEffectRegionGrid`，不是缩放整个 Prefab。雨滴完整16×16有效像素对应1格；每个萤火硬点为1/16格。
- 每区雨滴最多512颗；萤火最多128只，实时补光默认0、硬限制4盏。大面积天气建议合理分区，不靠放大单颗素材覆盖场景。
- 雨是三色装饰，跟随现有颜色解锁 / HSV，不参与染色目标、连线、碰撞或房间机关重置。萤火是中性装饰，不声明绿色能力归属。
- 参数与种子不变时编辑态缓存不重建。工作台只在层级变化、Undo、参数变化或场景切换时重读区域；平移、缩放只重绘少量活动框。

## 萤火可见平面

新区域根位于关卡平面 Z=0，活动范围位置不因为前景显示而被移走。硬点与光晕使用同一个 `renderDepthCells`，默认相对根 Z=-0.25格；负值靠近相机，工作台和 Inspector 都可调整。

标准玩家精灵位于角色中心，普通道具为透明、关闭深度写入的原生像素 Sprite。萤火沿用排序20，在这些透明图案之后绘制；Shader 保留 `ZTest LEqual`、不写深度。默认不透明墙正面在 -0.5格，因此墙仍会遮挡位于 -0.25格的萤火。没有使用 Always 深度测试或强行穿墙的排序层。

旧 Scene 的区域根位置不会自动迁移；已存在的根若在 Z=1，可在面板核对根位置和可见偏移。自定义不透明道具也会按真实深度遮挡；若将可见面手工移到墙前，它也会越过墙，需在本关画面中确认。
