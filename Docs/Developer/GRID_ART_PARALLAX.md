# 美术图层视差

美术工作台中选择图层，展开“当前图层设置”。左右、上下速度独立：1为不相对世界偏移，低于1为远景，高于1为前景。“锁定左右位移”“锁定上下位移”分别禁止对应轴的视差偏移，保留该轴原速度设置，解除锁定后恢复。

“最大偏移（格；0 为不限）”下的“左右”“上下”两行数值是相对本次视差参考位置的每轴正负位移上限；每轴0表示不限，负值通过界面归零。分行输入避免窄侧栏的X/Y复合字段挤掉数值；输入后按Enter或离开输入框确认，支持Undo。到达上限就停住，镜头返回时沿原路径恢复，不累计积分、不反弹。不会裁切图片、改动占格或缩放素材。该限制不是相机移动范围，也不是整个房间的边界。

底部“左右预览”“上下预览”可组合检查，复位同时归零；切回绘制也退出模拟。预览与游戏共用同一计算，按单格/16吸附。上限不是整数像素时向内取整，确保既不超过阈值也不引入半像素。编辑后仍按原流程保存/应用美术，Undo有效。运行时在相机更新之后的LateUpdate按绝对参考位置计算，每帧只移动图层根节点，不重新生成网格。

## 正式 Gaming 初始配置

保留TA `ad1a4dd` 的4层、2424个美术格、素材索引、旋转、天气区域及生成依赖。远景保留左右速度0.3，锁上下，最大左右偏移4格；近景保留左右速度0.7，锁上下，最大左右偏移2格。墙地表面与场景装饰原速度1保持固定。不自动删除白色纹饰，也不把作者背景改成墙面。上述阈值是有限尺寸背景的保守起点，可由美术逐层调整。

旧地图新增字段默认不锁轴、0上限，完全保持原行为。已生成的Scene运行启用时按稳定图层ID读取Map设置，不要求为了新增参数重建网格。显式“重设视差参考点”恢复层根位置，并以随后相机位置为新参考；禁用组件恢复原位置。

## 参考

- [Pro Camera 2D 官方视差说明](https://www.procamera2d.com/user-guide/extension-parallax/)：分层速度、独立X/Y开关、参考偏移复位。
- [Godot Parallax2D 官方说明](https://docs.godotengine.org/en/stable/classes/class_parallax2d.html)：分轴滚动倍率与滚动边界。

采用这些方案的控制思路，不复制其源码、不引入插件、多相机或重复背景。本项目的阈值限制图层偏移；Godot的limit限制相机滚动区，两者不是同一参数。
