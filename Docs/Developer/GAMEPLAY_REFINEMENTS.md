# 玩法物体参数与交互衔接

## 能力目标预览

一条藤蔓的母根、预置节段和运行时生长节段视为同一个逻辑目标。能力连线只显示距玩家最近的有效实体接触点；靠近另一节时更新端点，不重复播放整条线的出现动画。独立根系仍分别显示。合并物体继续按真实碰撞形状计算距离，水体保留墙格遮挡。

## 藤蔓生长边界

每次生成下一节之前检查该节的真实实体空间。墙、植物障碍、平台及其他可碰撞实体阻止生长；只长到最后一个空闲格，不穿过障碍。水、触发器、同根节段和无碰撞装饰不阻挡。持续接触水时，移开障碍后可继续生长；单次蓝色操作受阻后需再次触发。组件运行状态中的“生长阻挡”显示当前阻挡物。

## 植物障碍连通燃烧

红色烧到植物障碍时，同一房间内上下左右接触的完整植物障碍同时烧掉，可沿相邻障碍继续传播。仅斜角接触、隔空、不同深度、不同房间、已破坏或已禁用的障碍不连接。合并障碍按实际实体体积计算，不将包围矩形中的空洞当作植物；合并物体仍是一个逻辑对象。

这一行为共用原有红色交互入口，不增加轮询脚本；每次燃烧只播放一次燃烧声。R、死亡或离开所属房间时走原房间重置，恢复全部障碍及碰撞，不清除颜色解锁。隔离验证入口为 `PlantObstacleBurnAudit.Run`。

## 弹性植物高度

关卡编辑器切到“参数”，点击现有弹性植物，调整“弹跳”内的“普通回弹高度（格）”。在道具栏目选择植物后调整参数，可作为后续放置默认值。高跳高度和搬运跳跃高度独立配置，不随普通回弹一起改动。既有植物默认值保持普通8格、高跳8格、搬运4格。

## 基座搬运

基座复用玩家已有搬运系统和按键，不另建搬运控制器。对应场景红色未解锁时不可搬；场景颜色解锁即可搬，不要求玩家红色能力。拿起期间停止能源信号，物理位姿由搬运系统独占；放下后重新检测相邻红块，原平台/曲柄消费者绑定不变。

基座仍按布置房间限制迁移，不能带到其他房间；R、死亡或离开所属区域恢复作者位置与状态，不清颜色进度。旧场景实例在功能启用时补接搬运组件，无需重建整个关卡。

“物理 / 启用重力”默认开启，基座激活后会竖直落到实体支撑面；横向与旋转受保护，玩家不能推走基座。关闭后保持原先的静态悬浮行为，仍可搬运或用绿钩子拉动。搬运和绿钩子占用期间基座不争抢物理，释放、R或离区复原后尊重实例重力参数。

## 持续按钮的关门缓冲

门参数新增“松开后关门延迟（秒）”，默认0.6秒。持续按钮松开后，门在缓冲期间保持开启和无阻挡；重新按齐按钮会取消本次关门。延迟结束才关门和恢复阻挡。一次保持按钮的进度不被关门清除。

原“图案展示时间”仍控制开门前的等待，两者互相独立。关门缓冲使用游戏时间，暂停时不计时。重置、禁用和销毁清理计时及镜头资源，不遗留延迟回调。

## 验证入口

`GameplayRefinementAudit.Run` 只允许在 `Library/FlowRetirementProbe` 隔离工程执行，检查藤蔓阻挡/同根最近连线、植物实例高度、基座现有搬运/颜色/区域重置、门双向延迟和告示牌资源参数往返。它创建临时空场景，不保存或改写正式关卡。

`DecorationsHsvAudit.Run` 在同一隔离工程用实际工作台 Builder 生成三色笔刷与透明洞，保存并重新打开场景后进入 Play，以当前 URP 相机和 RenderTexture 读取最终画面。检查初始三色灰度、仅绿色解锁、第二钥匙只解能力、透明洞不污染背景、禁用重启和重新加载后绑定仍有效，截图与结果写到隔离工程 `Library/DecorationsHsv*`。该审计需要可用图形设备，不能使用无图形模式运行。

## 字幕告示牌

字幕激发道具的“告示牌外观”可直接选择7种图样，也可拖入其他 Sprite。留空时使用默认告示牌，取消“显示告示牌”只隐藏牌面。关卡编辑器的道具组件参数窗口提供相同图样缩略图，选择结果随存档以持久化资源标识保存。

告示牌按16源像素对应一个关卡单元格显示，保持美术原始比例，不随字幕触发区域缩放。字幕内容、播放一次/重复触发、触发碰撞体与字幕服务均维持原语义；牌面不会替代屏幕上的文字字幕。旧道具的占位 Mesh 仍隐藏，独立牌面保持显示。生成的外观子层为临时对象，不写入场景或规划存档。
