# 协作地图与片段交换

## 共享存档

日常新存档默认保存在 `Assets/_Project/Content/LevelMaps`，不再把 Library 当作交付目录。旧 Library 存档仍可读取，继续编辑保存时会复制进项目，旧文件保留。

保存规划地图对应的 Unity 场景时，会生成同目录、同名的 `.planning.json`。应用到场景也会更新这份存档。打开该场景的关卡编辑器时，队友更新过的同名存档优先于本机过期缓存；没有独立存档的旧场景仍可从场景内的规划数据恢复。

若共享文件在窗口开启期间被外部更新，旧窗口会停止覆盖，将当前本地地图备份到 `Library/PlanningConflicts` 并提示重新打开。备份需手动导入或另存到项目才能交付，不要上传 Library。

提交关卡需一起提交：场景及 `.meta`、同名 `.planning.json` 及 `.meta`、新增的预制体/栏目资源及依赖。如果日常存档另存到了 LevelMaps，也一并提交对应文件。不要提交 Library。

每位成员只需在自己的克隆中执行一次 `git config core.hooksPath .githooks`。提交检查会阻止“有规划场景但没有配套存档/元数据”或存档修改未暂存的提交。已有自定义 hooks 的成员应把检查脚本加入原 pre-commit，不覆盖原流程。也可手动运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File Ops/LevelMaps/Test-PlanningMapCommit.ps1`。

Git hook 不能替代分工：正式 Gaming 由指定关卡策划在任务分支继续制作，其他成员制作独立小地图或片段，由整合者导入。不要多人同时手动合并同一个大 JSON。正式交付需包含 Gaming 场景、同名规划文件及 `Assets/_Project/Content/LevelMaps/正式关卡.json` 和各自元数据；旧 Gaming 使用者先同步新版再编辑。所有成员仅推送自己的分支，不自行合并或推送 main；详见 [正式关卡交接](../Agent/Integration/FORMAL_LEVEL_DELIVERY.md)。

## 移动房间

世界图选择工具点选、Ctrl/Shift 多选或框选房间/通道，再拖动整体。内部物体和出生点默认跟随，不需另开选项。开启自动同步时场景跟随，否则点击“应用到场景”。

规划区域背景仅为注释，不自动代表其中所有房间。跨多个所有者的装配合并物体必须连同所有涉及的房间一起移动，不能切断一个物体。

## 导出部分地图

世界图右侧展开“协作与片段”：

- “导出选中房间 / 通道”：导出当前选中整体及其内容。
- “框选区域导出”：拖拽框选世界格范围，允许只取某个房间的一部分。
- “导出选中规划区域”：按所选区域背景的矩形范围导出。

导出不会删除或修改原地图。普通逐格绘制的矩形可沿边界裁剪；边界切过完整物体（含合并物体、门等单实例道具）时会拒绝导出，扩大选区或先解除合并。指向片段外的基座/曲柄绑定会解除并提示；门不在片段中的孤立按钮不导出。片段内部绑定保留。JSON 只含布局、参数及资产引用，不包含贴图/预制体文件，需一起交付依赖。

## 导入到当前地图

在“协作与片段”拖入 JSON 资产或点“浏览 JSON”。调整“导入左上格”，或点“放到地图右侧”。绿色轮廓表示可导入，红色表示与当前房间/通道重叠。确认后点击“导入当前地图”。

导入会追加到当前存档，不替换原地图；所有内部 ID 重新生成，支持重复导入，不会串绑原机关。默认保留当前出生点，按需勾选“使用导入的出生点”。一次导入可用编辑器“撤回”整体撤销。导入后按原有自动同步/应用流程生成场景。

## 水中放置物品

在水覆盖的同一格直接放置物品即可，水与物品分别保存、生成和增量同步。房间图与装配图的水预览在底层，物品在上层。普通选择/擦除优先操作上层物品；勾选右侧“仅操作水层”则只选择或擦除水，保留同格物品。

同一层仍受场景生成的占格限制，此功能不是任意两个实体重叠的开关，也不改变运行时水、碰撞或颜色解锁逻辑。

## 连续编辑与保存

绘制、擦除和拖动的撤回记录立即更新；磁盘存档在连续修改停止约 0.35 秒后保存，避免每一步操作都写整张地图。关闭窗口、切换场景、进入运行及应用到场景仍会刷新待保存内容。自动同步保留原有增量应用行为与外部存档冲突保护。

画布仅生成视口内的预览，缩略图生成后复用；平移画面会补上新进入视口的内容。水和道具使用独立预览层，不改变存档占格或运行时显示。

缩小到远景后，网格自动以2、4、8等整格间隔显示；放大后恢复逐格网格。只是参考线密度变化，绘制、选择、擦除和存档仍按原来的1格处理。房间/通道范围复用精确轮廓预览，保留孔洞和不规则形状，不再逐格重复描边；整体移动同样使用轮廓预览。装配图复用每个房间的坐标原点，平移时不逐物体重新扫描房间范围。
