# 大量未合并墙地块的画布预览

普通 Solid／Platform 方块的前视图不再逐格创建 UI Toolkit Image。画布按同一预览纹理收集四边形，每 512 格一个只读 Mesh 批次；几何使用固定的逻辑格坐标，平移／缩放仅改变父层变换。批次按视口显隐，不在鼠标移动时重新分解合并形状或重新创建全部节点。

这只改变编辑器预览，不合并作者记录，不改 Scene、不改物理、不改变世界格或美术格。未合并块仍逐格重复原前视图；合并块仍使用原合并前视图与形状矩形。道具、平台动画、藤蔓、水面和 Timeline 图片继续走原来的美术路径；水的邻接／叠层规则不变。选取、框选、合并选择轮廓由原画布逻辑处理，批次不能接收鼠标。

文档修改、调色库变更、视图／选中房间变更及合并选择变更会使对应保留几何失效。世界图默认仍只画区域，打开“世界图显示房间物体”才显示墙体批次。

机关连线每轮共享一个稳定 ID 索引，避免每个平台／基座／按钮重新扫描全图；无道具 ID 的墙地块不会反复扫描道具素材表。

验证入口：`PlanningEditorPrototype.PlanningCanvas.VerifyRetainedBlockPreviews`。使用内存文档创建 12000 个未合并块，检查无逐格 Image、24 个批次、120 次平移缩放保持同一批次实例、不修改作者数据、世界图开关、编辑后重建及水路径排除。结果写入 `Library/RetainedBlockPreviewsVerification.txt`。该入口不保存场景；实际窗口的绘制耗时和 GPU 显示还需配合窗口测试。
