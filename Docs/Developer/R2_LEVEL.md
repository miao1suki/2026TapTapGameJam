# R2 独立关卡

Unity 版本：6000.3.12f1。任务分支：`codex/ilorr/r2-level`，基于 main `2ab461c`。

## 打开和测试

合入main后，在 Unity Hub 打开主项目 `C:/Unity Programs/2026TapTapGameJam`，然后打开 `Assets/Scenes/R2/R2.unity`，点击播放。原独立R2目录仍可用于分支制作；不要在正在测试R1的项目窗口切分支或覆盖场景。

这是独立关卡，不替换正式 Gaming、不加入构建列表，也没有制作 R3。门只负责开关，尚未接正式关卡间跳转。

默认操作沿用项目输入设置：方向移动、空格跳跃、F 交互/搬运，Q/E 左右放下，Tab 选色、左键染色、R 重生。曲柄在旁边按住 F 上升，松开稍候下降；平台上有人时按原系统加快下降。门按钮踩一次保持，不需要一直站在上面。

开局解锁场景红、绿、蓝物体，玩家仅开放蓝色能力，红/绿能力锁定。标准玩家和普通最大上升4格不改。

## 生长与烧毁规则

按照策划要求，场景没有额外蓝色接触方块。整合main后保留已有玩家蓝色能力：选蓝色并左键点击范围内的绿接触方块，会持续生长至最大长度，不必保持点击。新增格被真实实体或玩家占据时暂停，移开后继续；R／离区清除请求。本次只使用main现成功能，不另加蓝块或改变颜色规则。

方向不是强制锁定参数。玩家蓝色点击时，同一世界网格行内沿背离玩家的左右方向生长；玩家在根块上方行则向上、下方行则向下。因此AK114向右至AU114须从同一行左侧点击，BG115向左至AY115须从同一行右侧点击。已伸长后锁方向，缩回单格才可改向。原有蓝块接触生长仍有效，首次沿远离蓝块的方向长出；这里只配置各自最大长度，不强制生长方向。

红块接触绿接触方块只能缩回最短1格；植物障碍则整片连通燃烧。AR116与收集品周围7格使用的是植物障碍，保留原绿色占格与AP118空洞。玩家没有红能力，可通过原红方块接触规则烧毁。

固定AK114沿用作者刚体FreezeAll，禁用搬运组件；共享攀附组件只额外承认作者固定状态，不修改普通方块的落稳要求、移动或生长触发。

## 编辑、保存和交接

可编辑存档为 `Assets/Scenes/R2/R2.planning.json`，和Scene同目录。通过项目融合关卡编辑器读取该存档后编辑，保存并应用到场景；提交Scene、planning、各自meta和新增依赖。不要只提交Scene，也不要把Library缓存当交付。

平台回落由曲柄组件的回落进度速度及载人下降倍率控制，平台的路径距离控制总行程。通过编辑器参数修改并保存到planning，避免仅改运行中的Inspector。

`R2.design.json` 是来源映射与确认规则记录，不是自动同步源。`R2LevelBuilder.Build` 只允许在此独立R2工作目录首次生成，已有Scene/存档时拒绝覆盖。人工微调后不要删除Scene来重跑生成器。

验证入口：`R2LevelBuilder.Preflight`（来源）、`R2LevelBuilder.Verify`（场景/存档）、`R2GameplayVerification.Run`（静音独立R2或指定整合探针目录的实际Play测试）。验证日志与截图写入Library，不提交。Play测试用的临时红/蓝接触夹具不保存到Scene；玩家蓝色点击另由`BlueContactCubeGrowthAudit.Run`验证，不以接触夹具冒充点击测试，也不代表完整路线通关或正式打包验收。
