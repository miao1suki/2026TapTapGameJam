# Timeline 对话轨道

## 使用方式

1. 在 Timeline 中点击“添加轨道”，选择“对话轨道”。
2. 不需要给轨道绑定任何对象。
3. 在轨道上创建片段，把片段拉伸到需要显示的时段。
4. 在片段 Inspector 中填写“对话内容”，再按 WordNote_UI 的方式设置样式。

片段播放时会向场景中的 `WordNote_UI` 申请一条消息。Timeline 消息和普通 API 消息进入同一个总队列、同一个位置队列和同一张 Canvas，只在来源标记上区分：

- 普通业务调用：API 调用。
- 对话轨道：Timeline 申请。

片段结束时只释放本次 Timeline 申请的消息，不影响其他 API 消息。

## 可用参数

参数与 `WordNoteStyle` 一致：

- 字体、字号、富文本、字体颜色、文字对齐、描边和描边颜色。
- 显示位置（含最左侧）、是否参与堆叠、显示模式、显示时长。
- 入场动画类型和完整入场运动参数。
- 出场动画类型和完整出场运动参数。
- 组合通道中的显隐、水平/竖直移动、缩放和打字机。
- 动画时长、初末位置、初末透明度、初末缩放、初末速度和变速比例。

## 默认行为

新建对话片段默认向 WordNote_UI 申请消息；具体的位置、对齐、颜色、描边、打字速度和入退场参数由片段 Inspector 配置。
