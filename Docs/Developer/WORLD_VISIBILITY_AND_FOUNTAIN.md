# 二维遮挡光照与喷泉

## 启用光照

现有 URP、Unlit、像素、HSV 与水体链路保留。光照只控制画面，不停用黑区内物理或机关，不按照房间 ID 点亮整房。

1. 打开要试验的场景，选择 `Tools/2026TapTap/光照/在当前场景添加二维光照`。
2. 主相机获得 `WorldVisibility2D`，确认目标相机与观察者。以主相机 Game 视图预览；普通 Scene 相机不应用此后处理。
3. 调节玩家光半径、视线半径、环境亮度与核心比例。半径单位是世界格；单格尺寸应与地图一致。
4. `Tools/2026TapTap/光照/添加场景光源` 添加独立光源，移动它并配置颜色、半径。默认最多四个附加光源。
5. 确认效果后自行保存场景；关闭组件即可恢复原画面。本次没有自动启用 Gaming 或改写用户正在编辑的 Pick。

规划实体墙自动阻光，保留实际碰撞箱的空洞；关闭的门阻光，开门移除遮挡。水、道具、玩家、平台不默认阻光，其他实体可挂 `VisibilityOccluder2D` 并指定非 Trigger 的 BoxCollider。新建动态门或由自定义代码修改静态墙形状后可调用 `WorldVisibility2D.InvalidateAll()`，Inspector 也有刷新缓存按钮。

默认“墙后不可见”会将附加灯光与玩家视线相交，不能隔墙看见远方灯光。关闭该选项则允许独立光源点亮其他区域。光照是明暗相乘，不会给未解锁物体恢复原颜色。屏幕覆盖式 HUD/菜单不变暗；世界空间 UI 属于世界画面。

## 喷泉

`Assets/_Project/Content/Art/Fountain.prefab`，也可通过 `Tools/2026TapTap/美术/定位喷泉预制体` 定位。只有表现组件，无碰撞、Boss 判定或结局逻辑。

八帧完整 82×66，严格导出倍率 1、16 有效像素/格，因此自然大小 **5.125×4.125 格**。底部中心固定、保留黑色内部与透明留白、不逐帧裁包围盒。Point、FullRect、无 mip、无压缩、NPOT 不缩放；父缩放由原像素换算补偿。

默认每秒 10 帧可调整；运行自动循环，可用 `FountainArtwork.SetPlaying(bool)` 暂停/恢复。编辑态显示首帧，不用常驻实时粒子模拟。未来玩法脚本可引用这个预制体，不应把结局逻辑塞进表现组件。

## 验证与限制

Unity 6000.3.12f1 隔离工程实际 D3D11 GPU 覆盖墙后、开闭/移动遮光体、真实空洞、远处灯光视线限制及亚像素相机移动。Pick 只读副本完成实际 Play：运行时墙缓存、真实相机合成、喷泉动画/原生尺寸、覆盖式 UI 均检查。

算法复用多边形 Mesh、列表和低分辨率 RenderGraph 遮罩，静态墙按区块缓存；鼠标转动不触发全场景扫描。动态门/显式遮光箱每次合成检查，最多四个附加光默认控制成本。当前为正交 XY 玩法相机；透视相机直接旁路，避免错误黑屏。不是 3D 体积光或自动法线受光系统。

本轮尚未做 Android 真机性能、全 Gaming 通关或新包验收；不能把局部 CPU Prepare 耗时当作整帧/手机帧率。持续大量光源、复杂斜向碰撞或远超默认半径须另做性能评估。
