# 白线自动边框

在共享素材库选择原有“白线边框”，保持“自动边角”开启，再铺绘连续墙地格。外侧四角与孔洞/凹角都沿实际格边界显示；填满缺失的斜邻格后，原凹角消失。需要保留孔洞，不要把无墙的格补满。

本次修正保留原笔刷编号、占格与所有已画位置，无需重新画。普通“白线边框·左上/上/…”原图拆分片和“完整5×5”属于原始装饰图，不改变；它们不是自动地形笔刷。
