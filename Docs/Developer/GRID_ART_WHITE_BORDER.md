# 白线自动边框

在共享素材库选择原有“白线边框”，保持“自动边角”开启，再铺绘连续墙地格。外侧四角与孔洞/凹角都沿实际格边界显示；填满缺失的斜邻格后，原凹角消失。需要保留孔洞，不要把无墙的格补满。

本次修正保留原笔刷编号、占格与所有已画位置，无需重新画。普通“白线边框·左上/上/…”原图拆分片和“完整5×5”属于原始装饰图，不改变；它们不是自动地形笔刷。

## 像素与维护

原 `tail.png` 经过验证为4倍最近邻导出。白线原切片有6个有效像素的装饰留白，不适合直接按格切四象限；旧配置也没有四个内角，缺片回退黑色中心。`GridArtBorderLibrary` 从原图的白线拐角和连续直边提取原像素，重新排列为13张16×16规则片（含4张内角），不缩放、不插值、不改变线条像素大小。四像素宽的线条移至边缘，内部保持原黑色。

生成图集和Sprite作为共享 `SceneArtLibrary.asset` 的子资源持久化，原图和旧Sprite均保留，原 `#frame` 笔刷只更换规则引用。`GridArtProjectLibrary.Import` 幂等维护此配置，不增加近似重复笔刷，不改其他素材、地图、碰撞或图层。自定义库中同源自动边框也可通过“同步项目与切片素材”修复。

## 验证

仅在静音隔离工程运行 `Project.GridArt.Editor.GridArtBorderAudit.Run`。核对旧槽位/尺寸/普通原图不变、全部13张有效原像素规则片、白线不落格中、L形内角选择、斜邻填满后消除内部线、重复同步幂等。报告和图集对照位于隔离工程 `Library/GridArtBorderAudit.txt`、`Library/GridArtBorderAtlas.png`；实际运行结果由整合交付记录补充。
