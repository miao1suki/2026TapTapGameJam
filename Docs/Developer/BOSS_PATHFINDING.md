# Boss 追击寻路

当前 Boss 预制体已切回“只向右移动”，不再挂载寻路、马夫或自动烘焙组件。以下导航代码保留作为未来可复用能力，不是当前 Boss 战斗的默认路径。

`BossPathfinder` 在 Boss 专用有向节点图上计算到玩家的路径。`BossPathExecutor` 作为“寻路马夫”，只读取路径段并向 `BossController` 下发运动指令；`BossController` 作为“马”，负责实际 Rigidbody 运动、重力和跳跃。传送、阶段血量和特殊道具仍由后续系统处理。

## 节点与边

1. 在场景中沿 Boss 追击回环放置 `BossPathNode`。
2. 每个节点 Inspector 中配置“后继节点”。
3. 后继边可选通行类型：跑动、爬升、跳跃、下落、乘平台、危险通过、自定义。
4. 回环地图只需要把最后一个节点的后继连回起点。
5. 危险边默认不会被寻路规避；Boss 会直接沿该边追击。

如果不想手摆节点，`BossNavAutoBaker` 会在运行时从关卡方块顶面烘焙节点图：按 Boss 3×3 体型做净空检查，并自动生成跑动、跳跃、下落边。运行时图不写回场景；场景里已有手摆节点时默认跳过。

## 追击路径

`BossPathfinder` 会按目标 Tag 找玩家，并定期从 Boss 最近节点寻路到玩家最近节点。路径中的每一步保留边类型，交给 `BossPathExecutor`。

路径是节点序列和带类型步骤。执行器的基本规则：

- 跑动：水平移动到目标节点；如果目标带明显高度差，会自动转为跳跃或下落，不再持续水平顶墙。
- 阻挡：跑动方向前方探测到方块且 Boss 在地面时，会自动改发跳跃指令。
- 跳跃：到达可用地面后调用 `BossController.RequestJumpTo`。
- 爬升：给竖直方向速度，Rigidbody 重力保持原样。
- 下落：保留重力，向落点水平移动。
- 乘平台：按高度差临时按跑动或爬升处理。

跑动和下落只控制水平速度，竖直速度不被马夫覆盖；只有明确请求爬升时才由马夫提供竖直速度。

`autoJumpHeight` 和 `autoDropHeight` 控制跑动节点自动转跳跃/下落的高度差阈值。
`autoJumpOnObstacle` 控制前方方块自动跳，`obstacleProbePadding` 控制探测余量。
跳跃的横向速度、最大跳高和最大垂直速度由 `BossController` 持有；重力使用引擎的 `Physics.gravity`，不做任何操作修改。马夫只能请求跳跃目标，不能传入或提高这些能力。

自动烘焙参数包括格子尺寸、Boss 占格宽高、最大上跳高度、最大跳跃水平距离、最大下落高度和每节点最大边数。

## 调试

- Scene 视图会绘制节点颜色和所有有向边。
- 选中 Boss 时，当前路径会以绿色线段显示。
- Inspector 可查看路径节点数量、起止节点、路径版本和当前执行步骤，并可手动重算或清空。
