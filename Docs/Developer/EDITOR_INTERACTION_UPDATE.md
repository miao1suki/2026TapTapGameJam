# 关卡编辑器：视口操作与片段协作

## 视图与拖动

右侧的“世界图 / 房间详情 / 装配图”仅高亮当前视图。快速切换视图时，不会被前一次排队的视图恢复重新拉回。

绘制、擦除、合并框选、世界图框选以及拖动物体时，按住鼠标移到画布四边会连续平移视口；越接近边缘，平移越快。选区的起始格保持不变。离开画布、松开鼠标、切换工具、窗口失焦或失去鼠标捕获会停止平移。

平移只改变视图和拖动预览，不会逐帧保存、同步场景或创建撤回记录。完成一次实际编辑才记录一次。单击选中且没有移动，不增加撤回记录。拖动被窗口失焦或鼠标捕获打断时，已经移动的物体位置保留并记为一次编辑；未完成的绘制、擦除和世界图移动预览不提交。

## 导入另一份存档

右侧三视图按钮下方始终显示“导入存档拼接…”，不需要先展开世界图高级栏目。

1. 打开“导入存档拼接…”，选择项目内存档或浏览 JSON 文件。
2. 默认预览位置在当前地图右侧；也可以修改“导入左上格”。坐标与世界图一致，Y 向下。
3. 绿色预览可导入；红色预览或错误信息表示与现有区域重叠或依赖不完整。不会覆盖已有房间。
4. 按需勾选“使用导入的出生点”；默认保留当前出生点。
5. 点击“导入当前地图”。导入使用新的稳定 ID，保留片段内部机关绑定；指向片段外部的绑定会在确认后解除。源存档不被改写。

关闭面板仅收起操作界面；“取消预览”清除尚未导入的内容。导入后仍需交付当前地图 Scene、同名 planning.json、各自 meta 及新增资源依赖。

## 导出一部分地图

点击右侧“导出地图片段…”，选择：

- “导出当前选中的房间 / 通道…”：先在世界图选择一个或多个整体。
- “在地图上框选区域并导出…”：操作面板会自动收起，再在世界图拖动框选区域，随后选择 JSON 保存位置。
- “导出选中的规划区域…”：先选中一个彩色规划区域。

导出不修改原地图。边界切到完整合并物体、门或其他单实例物体时会拒绝导出并提示扩大选区，避免截断模型或静默丢失绑定。

## 平台图像

平台预览使用正式动画的首帧，而不是带留白的方形 Prefab 缩略图。横向使用原始像素比例，竖向绕中心旋转 90°；长平台延长时按原生格宽重复，末段裁切，不把 5 格高度压成一格，也不修改已有平台的占格和碰撞尺寸。

## 正式美术预览

道具栏目、房间图和装配图共享正式2D素材描述，不再用已接入美术道具的3D预制体缩略图。图像按16有效源像素/格显示；大尺寸装置不压进1格，合并的平铺物体不拉伸原图。水根据相邻水格选择TA水面、水中和水下素材，藤蔓使用序列帧的像素采样缓存。侧梯方向、尖刺朝向、按钮绑定顺序与实例告示牌素材覆盖均保留。

编辑器保持彩色识别，锁定/解锁与HSV表现仍只由游戏运行时处理。开启“仅操作水层”时非水道具预览半透明；导入或修改美术资源会使预览缓存失效，不需要重新点击栏目。

## 验证入口

`EditorInteractionAudit.Run` 仅允许在 `Library/FlowRetirementProbe` 隔离工程执行。它附着真实 UI Toolkit 窗口，检查指针捕获、松开及丢失恢复、四向边缘平移、事务次数、竖向平台预览、模式高亮与片段面板入口。结果写入隔离工程 `Library/EditorInteractionResult.txt`。
