# 融合关卡编辑器

新增非颜色“门”道具：1×2 占格、自动专属按钮、参数模式追加按钮、选择模式移动、擦除解绑与虚线关系；详见 [门与按钮](DOORS.md)。这不是世界图上表示房间连接的规划门。

窗口获得焦点时，`W` 打开世界图，`R` 打开当前房间详情；文字输入与 Play Mode 不响应这两个编辑快捷键，不改变玩家键位。

入口：`Tools/2026TapTap/关卡规划原型/打开融合编辑器`；在 Unity 非文本输入状态下按 `M` 可打开或关闭窗口。窗口重新打开时恢复上次模式、房间、缩放与画布位置。

## 当前能力

- 世界图：房间区块、通道、房间与通道详情、装配图。
- 详情图：使用现有方块栏目绘制，支持擦除、矩形操作、组件模板和贴画。
- 详情聚焦：切换房间或通道详情时定位到方块最密集区域，并按内容范围自动缩放到尽量看到全部方块。
- 玩家贴纸：设置玩家参考后自动把玩家限制到 XY 平面，并在装配图、房间详情和通道详情中常态显示为最高层贴纸。贴纸显示玩家缩略图和“玩家”文字，可直接拖动来同步修改场景玩家的位置；玩家实际位置超出当前视口时，贴纸会钉在对应边缘保持可见。它不占方块格、不参与覆盖、擦除、删除或场景生成。拖动进入规划编辑器自己的历史；撤回或重做时，只有当前指定玩家仍是拖动时的那个对象才会恢复位置。点击“聚焦玩家”会同时聚焦 SceneView 和当前网格画面。
- 场景收纳：所有生成内容放在 `__PlanningMapGenerated` 下；每个房间或通道使用自己的名称作为子物体，绘制方块时自动挂到当前选中对象下。
- 道具栏目：内置红、绿、蓝三色钥匙预制体和 `ScreenNoteTool`，也可通过新增按钮填入其他预制体；不包含旧测试项目临时道具。编辑道具时可点击“编辑组件数值”打开独立窗口，覆盖已有组件的数值，用于区分同一预制体的不同配置；默认组件排在最后并默认收起，保存后放置和规划生成都会应用这些覆盖，不修改预制体资产。字幕触发组件在该窗口中复用与正常 Inspector 相同的分组、位置、动画、重复激发和预览结构；每个组件可恢复预制体默认值。`Transform` 不参与覆盖，道具位置始终由放置格或规划生成格决定。
- 演示字幕条目：除锚点和已有字幕块外，每个现有功能道具额外生成一个复用 `DisplayBlock` 的字幕展示栏目；条目名使用 `字幕：xx道具`，`DisplayBlockFeature.text` 只等于对应道具名，便于在演示时作为道具标签放置。
- 场景应用：顶部主按钮“应用到场景”将规划同步到当前活动 Scene，生成根节点为 `__PlanningMapGenerated`。默认增量比对：保留未变化的实例及其手工调整，仅增删规划变化的物体；尺寸或独立参数改变也会更新实例，预置藤蔓节段变化按整条链替换。规划已应用时，规划撤回会同时恢复场景；应用按钮本身不创建一条额外历史。结果显示新增、删除、保留数量。
- 自动同步：顶部勾选后立即应用一次，之后每次完成绘制、擦除、移动、合并或参数保存会增量同步。Unity 中手动删除这些生成物体，也会删除对应规划单元；删除合并物体会删除整个合并项，删除藤蔓母物体会连同其生成节段回流。仅跟踪当前活动场景的规划来源标记，不采集普通场景物体。同步期间暂停删除检测并重新绑定结果，避免反馈循环。开关按 Scene 记忆，窗口重开和脚本重编译后恢复；进入另一 Scene 使用该 Scene 的设置，未设置时默认关闭。恢复开关不立即全量写入场景，自动同步仍不保存 Scene 文件。
- 场景工作区记忆：各 Scene 独立保存当前规划文档、存档文件路径、视图模式、房间、缩放和画布位置。活动 Scene 改变时先保存原工作区再恢复目标工作区；首次使用的其他 Scene 从空地图开始，可自行载入存档。已保存 Scene 使用资产 GUID 识别，改名或移动仍保留记忆；尚未保存的 Scene 仅在本次 Unity 会话内可靠区分。旧全局工作区只迁入升级后首次打开的 Scene，原全局数据不删除。
- 全量重建：在顶部“更多”菜单中，需要确认；工具先生成临时结果，成功后才替换原规划根节点，失败时保留旧场景。成功重建仍会覆盖规划根节点中的手工调整，可通过 Unity Undo 撤销，执行前建议保存场景。
- 右侧面板：房间详情中的“方块 / 道具放置器”默认展开；“选中项设置”独立折叠，两者一次只展开一项。常用的场景应用不再藏在选中房间的折叠区。
- 应用反馈：执行后按钮立即退出焦点高亮，结果显示在底部状态栏。道具栏目获得更高的可滚动区域，缩放后卡片自动利用行宽；预制体预览完成后自动更新，不需要点击栏目刷新。
- 撤销：关卡编辑器窗口打开且不在播放模式时，`Ctrl+Z` 使用规划历史，`Ctrl+Y` / `Ctrl+Shift+Z` 重做；窗口不必拥有焦点。没有规划历史时不退回 Unity 全局撤销。关闭窗口后恢复 Unity 原有快捷键。历史包含规划、栏目默认参数与玩家贴纸位置，重新编译或关闭窗口后不保留。此窗口的增量应用不再记录原生场景 Undo；临时生成层级也不进入 Undo。
- 格子尺寸：放置和生成时会把关卡编辑器当前的格子世界尺寸写入 `LevelEditorPlacedBlock`；能源、曲柄、基座、移动平台、水泡和藤蔓等按格功能统一读取该值，不再各自配置每格大小。
- 栏目职责：方块栏目只保存地图墙壁、地形和几何碰撞；所有红、蓝、绿玩法预制体都通过道具栏目放置。颜色玩法预制体使用 `Red_*`、`Blue_*`、`Green_*` 命名，方块栏目不再保存三色管理数据，也不会给普通墙块补颜色功能宿主。
- 合并模式：与选择、绘制、擦除、玩家、参数同级。在详情图或装配图单击物体切换选中状态，拖动框选逐项切换同类物体的选择。点“合并选中项”生成一个连续尺寸的预制体实例，保留一套功能逻辑，不生成逐格实例组；支持普通方块和道具。当前要求同一房间、同一种栏目、无重叠且填满矩形；跨房间或含空洞的选区会提示拒绝。一次绘制形成的多格矩形也能直接转为单个实例。合并整体采用最先放置物体的参数，原始物体及各自参数写入规划存档；选中整体后点“解除合并”恢复原始数据，并支持移动后解除、再次合并。擦除合并项的任一格会删除整体。
- 参数模式：点击网格中的物体打开其已有组件的参数界面，保存为该规划项的独立覆盖；点击方块或道具栏目则编辑该类型之后新放置时的默认值。既有物体不会因更改栏目默认值而改变，预制体资产不被改写。藤蔓的攀爬、增长、触发等配置复用现有组件界面；`Transform` 仍由格子位置和整体尺寸管理，不作为数值覆盖。普通连续藤蔓应用时仍按最下方母藤蔓及初始节段规则整理，最大初始生长格数由实际节段数决定；合并后的大物体不参与逐格藤蔓链转换。
- 存档：`新建 / 存档`打开存档面板；本地槽位位于 `Library/PlanningEditorSaves`，可读取、保存、重命名和导出 JSON。
- 内置示例地图：存档面板第一位，只读，可读取和导出。示例数据保存在 `PlanningEditorPrototype/Editor/DefaultPlanningMap.json`，由当前项目确定的规划地图固化而来；代码里的旧示例只在资源缺失或解析失败时作为兜底。
- 栏目删除兜底：删除方块栏目时，该栏目已经放置到场景和规划图里的方块会一起删除，避免遗留无效引用。
- 场景物体引用：在房间详情或装配图选中已经同步到场景的方块时，“聚焦玩家”所在的顶部工具行会只读显示对应场景物体；选中时会按房间、场景格、方块/道具类型和栏目名称重新解析当前实例。引用不能在这里替换，点击“定位方块”会选中目标并主动聚焦到 SceneView，之后在正常 Inspector 中编辑。
- 存档门槛：顶部“保存到当前存档”替代旧“同步到装配图”按钮。只有在当前存档已保存、保存后没有新的未保存改动、并且选中方块已经生成到场景时，“定位方块”才可用。

装配图使用自上而下的规划 Y 坐标，生成到 Scene 时会转换为自下而上的场景格子：`场景 X = 装配 X`，`场景 Y = -装配 Y - 1`，场景物体中心再取格子中心。例如装配图 `(-100,-26)` 会生成到场景格 `(-100,25)`，世界位置为 `(-99.5,25.5,0)`。

## 数据边界

存档只保存规划文档数据，不包含 Scene 本身。场景生成仍需在活动 Scene 中执行，所需预制体和栏目引用必须已存在于比赛项目。
方块栏目只按普通预制体或自定义模板放置，不再校验颜色目录。颜色玩法物体必须从道具栏目放置，颜色钥匙、解锁和固定功能重组仍按颜色系统各自的开发状态处理。

## 接入与验证

合并物体的网格预览按实际格数生成正交正面图，不再拉伸单格缩略图；预览不添加额外留边，使用 Point 采样避免长条两端被放大成虚化渐变。该显示修正不改场景模型、碰撞或合并数据。

实例参数与栏目默认参数窗口复用组件的 `BlockParameter` 中文名称、分组和用途说明，以及 `InspectorName` / `Tooltip` 元数据；说明在参数下方显示，并可悬停查看。新功能组件须填写中文参数元数据，不在这个窗口另维护一套英文变量名翻译。

`PlanningBox.isMerged` 表示该矩形只生成一个实例；`mergeParts` 保存可解除的原始 JSON，避免递归序列化。`hasComponentOverrides` 区分“已有默认覆盖”与“沿用栏目默认值”，空覆盖也是有效配置。新绘制物体会快照当前栏目默认值。

`LevelEditorPlacedBlock` 的 `PlanningBoxId`、`PlanningLocalCell` 和 `PlanningSignature` 仅用于编辑来源绑定、删除回流和增量比较。运行时玩法不应依赖这些字段；不要把暂存物体加入原生 Undo 或从绘制回调修改视觉树。

菜单 `Tools/2026TapTap/关卡编辑器/验证规划数据逻辑` 在独立内存文档中验证选择切换、道具合并/解除、移动后还原、存档往返、空洞保护、删除回流和事务通知，不修改场景及存档。交互验收还应在未保存的测试场景中检查：合并后 Hierarchy 只有一个实例；参数默认与独立值互不影响；自动同步时手动删物体再 Ctrl+Z 可恢复；连续撤回/重做无原生崩溃；切换场景后自动同步关闭。
