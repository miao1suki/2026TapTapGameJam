## 隔离验证

Unity 6000.3.12f1，静音隔离工程 `Library/FlowRetirementProbe`，独立产品名与 Library 测试存档目录；不操作主 Unity 或真实存档。

- `CollectiblePersistenceAudit.Run`：57 项真实物理/生命周期断言通过，包括 Trigger/飞行结算、离区、重生、新轮通知重入、冷恢复、稳定 ID 和隐藏块深度。
- 修复前后对照：将隔离工程三份收集品运行时代码还原为 origin/main 58c6df7，在同一测试中稳定失败于“new run cannot re-register old collected IDs”；修复后完整通过。对照仅改隔离副本，不改作者工程或原存档。
- `CollectibleFormalSaveAudit.Run`：采用 origin/main 58c6df7 的正式 Gaming，实际启动并加载测试存档，已收集物品隐藏；未收集物品实际碰撞/飞行拾取，自动存档写入，房间重置后进度保留。

这些结果确认初始化路径存在缺陷并已覆盖修复；未取得策划当时的原始存档及完整操作录像，不能断言其所有“清零”反馈均只有同一原因。地图变动后作者 ID 改变也需单独排查。
