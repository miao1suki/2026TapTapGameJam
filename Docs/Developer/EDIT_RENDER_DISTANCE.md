# 编辑渲染距离

菜单：

```text
Tools > 2026TapTap > 编辑器性能 > 编辑渲染距离
```

## 使用

1. 打开正式关卡或其他包含 `__PlanningMapGenerated` 的场景。
2. 勾选“启用编辑渲染距离”。
3. 保持“同时降低规划窗口刷新频率”开启，可显著减少规划窗口的周期性维护工作。
4. 调整“可见半径（格）”，默认 `80` 格。
5. 在 SceneView 中移动视野，工具会以 SceneView 中心为圆心更新可见房间。
6. 点击“刷新房间缓存”可以重新计算房间边界。
7. 点击“关闭并恢复全部”会关闭工具并恢复所有房间可见性。

## 显示规则

- SceneView 半径内的房间保持可见。
- SceneView 当前所在或最近的房间始终可见。
- 当前选中物体所在房间始终可见，因此可以从 Hierarchy 或关卡编辑器选中远处对象。
- 非当前房间按内部实际规划方块样本判断距离，不使用整个不连续房间的总包围盒，避免横跨多片区域的房间被误判为一直可见。
- 轻量刷新开启时，关卡编辑器和规划编辑器的基础刷新由 `0.1` 秒降到 `0.35` 秒，调色板维护和预览刷新降到 `1` 秒。
- 当 SceneView 获得焦点、编辑器窗口失去焦点时，两套编辑窗口进一步降到 `0.75` 秒刷新一次。
- 区域标签也从固定 `0.1` 秒刷新降到 `1` 秒。

## 性能诊断

窗口底部会显示：

```text
更新间隔 / 规划窗口 Tick / 关卡面板 Tick / 2D 美术预览绘制 / 房间缓存 / 可见性应用
规划画布绘制（地图 / 装配 / 详情） / 预览刷新 / 区域标签 / 玩家标记
```

“更新间隔”是两次 `EditorApplication.update` 回调之间的时间，不是严格的 GPU/CPU 帧时间；Unity 可能在空闲时主动降低回调频率。超过 `60 ms` 时，Console 最多每两秒输出一次 `[EditPerf]` 日志，用于判断热点在规划窗口、UI Toolkit 画布、2D 美术预览还是 Unity 原生界面。

房间缓存优先使用 `LevelEditorPlacedBlock` 的格尺寸和缩放计算，并保留每个规划方块的样本包围盒用于距离判断，不再只依赖整个房间的总包围盒；Renderer 只在没有规划块时兜底。SceneVisibilityManager 的隐藏/恢复操作进入队列，每个编辑器 Tick 最多处理一个房间，避免第一次批量隐藏 20 多个房间时产生单帧长卡顿。

## 边界

- 只改变 Unity Editor 的会话可见性，不修改 GameObject、Renderer、Collider、组件参数、Scene 文件或 Planning JSON。
- 不改变运行时摄像机、玩法、碰撞和渲染距离。
- 进入 Play Mode、保存场景、关闭窗口、脚本域重载或退出编辑器时会恢复全部可见性。
- 隐藏后的远处房间也会暂时从 Hierarchy 中隐藏，这是 Unity `SceneVisibilityManager` 的预期行为。
