# 植物燃烧效果

`Assets/ta_source/Burn` 提供红色成功烧毁绿色植物时的独立视觉效果。它使用目标当前 Renderer 的材质、纹理与 Alpha 轮廓，不修改正式红色反应判定，也不使用 `Assets/ta_source/GivingColor` 的临时染色覆盖。

## 播放规则

- 红色成功作用于藤蔓、弹性植物或植物障碍后，碰撞立即关闭，玩家不能继续攀爬或触发弹跳。
- 藤蔓只沿命中节段所属的母根燃烧。焰边从 Renderer 本地高度底部向顶部推进，烧过的像素先变为炭灰并逐渐消散。
- 完成后，植物障碍隐藏外观；弹性植物沿用房间反应隐藏机制；藤蔓保留已烧毁状态并在区域重置时恢复。
- 区域重置、组件禁用或对象关闭会取消动画、销毁临时材质并恢复原材质状态。

## 调整参数

默认共享配置为 `Assets/ta_source/Burn/Resources/Burn/PlantBurnEffectSettings.asset`。植物组件的“燃烧效果配置”留空时自动读取它；指定另一个配置资产即可单独调整该对象。

| 参数 | 作用 |
|---|---|
| 燃烧时长 | 火线由底向顶推进的基础时长 |
| 燃烧速度 | 速度倍率，0.25–4，数值越大越快 |
| 火焰边宽度 | 控制移动火线的厚度 |
| 橙色焰边强度 | 调整橙红轮廓和火线亮度 |
| 像素化程度 | 将源纹理采样为较粗像素块，范围 0–1 |
| 火焰边缘扰动 | 调整燃烧前沿的起伏 |
| 灰烬消散时长/颜色 | 控制烧过部分的残留和淡出 |

藤蔓还保留“每节燃烧时长”，用于按根系节段数延长整体动画时长。实际推进速度继续由共享配置中的“燃烧速度”控制。

## Renderer 与渲染要求

- 支持 `SpriteRenderer`、带 `MeshFilter` 的 `MeshRenderer` 和 `ParticleSystemRenderer`。
- Sprite 保留 Sprite UV/图集纹理及顶点颜色；网格读取源材质的 `_BaseMap` / `_MainTex` 和颜色。Shader 依据 Renderer 本地高度决定火线位置。
- 目标材质被临时替换为 `2026TapTap/Plant Burn`；完成或取消后恢复原材质。源场景材质与纹理不会被写入。
- 目标须使用 URP，并有受支持的 Renderer。没有可播放 Renderer 时，玩法仍按原反应完成并立即隐藏/回收目标。

共享材质位于 `Resources/Burn/PlantBurnEffect.mat`，以确保 Shader 被正式构建收录。可调参数在配置资产中设置。
