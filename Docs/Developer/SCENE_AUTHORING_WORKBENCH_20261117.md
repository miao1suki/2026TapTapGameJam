# Scene 作者工作台：2026-11-17 进度检查点

这是用户要求的中途推送，不代表编辑器与美术验收完成。分支 `codex/editor/scene-authoring-redesign`，Unity 6000.3.12f1，基于 69a8a4b7；只在独立工作树开发。正式 Gaming、正式 GridArt Map、历史 JSON、正式 Palette/Prefab 和用户 D 盘工作树不作修改。

## 当前实现

- 单个 UI Toolkit Scene Overlay：顶部状态/保存/工具/通道常驻，物体与美术共用可搜索资源卡片，实例参数嵌入真实 InspectorElement。Scene 最大化时仍在同一 Scene 内操作。旧独立窗口保留为高级兼容入口。
- Claude 固定工作流给出布局及“墨蓝工坊·三色标签”视觉方向。物体珊瑚、美术紫、房间青只用作清晰识别，背景与文字同时提供深浅主题值。浅色主题尚未人工验收。
- 房间导航使用真实格集合的只读快照，保留洞、分离岛及重叠候选，支持缩放/平移/筛选/定位。区域关系由四邻接推导。区域装配支持名称多选与冲突预检。
- 区域/美术笔画先暂存，取消零写入，提交进入单个 Undo。区域擦除检查占用；Prefab 变动显式记录 override。物体连续笔画保留实际经过格，预览绘制有数量上限。
- 资源卡片不随每一笔 Map revision 重建；搜索做短延迟合并，选中状态只在变化时刷新；导航折叠时不持续绑定快照；会话视觉状态相同时跳过重复样式更新。
- 新增统一 `SceneWorkbenchInput` 边界检测，三种 Scene 画笔在工作台范围内拒绝落笔。此项来自真实 UI 测试发现的点击透传问题；后台已通过，必须继续前台复验。

## 美术进行中

通过用户既有固定 n8n 生图工作流得到苔石水廊概念、13 片地形源图、9 件道具源图及远景。请求模型名为工作流默认值；服务端实际模型没有独立验证。未改用另一模型或角色工作流。

`SceneAuthoringShowcase` 当前只有候选 PNG，尚无完整可编辑展示 Scene、Map、Palette。裁切处理仅测量源图边界、洋红去底、最近邻像素采样，不把概念图假装为已搭建关卡。

用户最新明确要求厚实草包边，覆盖所有暴露边与孔洞凹角。Claude 已判第一版返工，给出 32×32 设计尺度顶部 8px、侧边 6px、底部 5px，以及外角、凹角、单格横竖条、孤岛、T/十字和跨 32 格分块检查规范。新候选源图虽增加了四边苔草，但实际拼接图仍显细、凹角连续性也需复核，**未通过美术验收**。工程实际像素标准仍为 16px/格；若最终采用高分辨率源图，需要显式处理源像素比例，不能静默修改全局标准。

底层是 GridArtMap + 32×32 分块平面 Mesh，不是 Unity Tilemap。UI 融入 Scene 本身不保证性能更好；本轮优化针对重复索引、卡片重建、样式刷新、笔画预览与增量块构建。
