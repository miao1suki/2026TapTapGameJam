# 搬运方块

左右放置按玩家身体所在格的紧邻格判断，不向下搜索地面，不强制落到地面。虚线框与真实放置共用检测。占格使用实际胶囊中心，站在物品旁边即可出现面朝侧搬运提示，无须跳起。

轻微进入相邻放置格时，放下动画会通过玩家控制器平滑让位，不瞬移。一格通道不再因额外安全间距误报非法；真实墙体、其他物品、过深重叠或跨原属房间仍拒绝放置。动画期间若空间被占用，保持搬运，不强行启用重叠碰撞。

搬运时，头顶方块和玩家作为同一移动组合检查障碍。方块碰墙或顶面会阻止对应方向移动，可以沿障碍移动或反向离开；合并的大方块按完整体积检查。搬运期间不推动墙体或其他方块。

键位沿用项目输入配置：交互键搬起、左右放置键放下、重生键返回重生点；没有新增按键。R、死亡和离开房间仍恢复方块布置状态。

附近候选方块中心显示“当前交互键 / 搬运”，触屏只显示“搬运”。统一像素字体、黑字白边，合并放大方块不会拉伸文字。

玩家朝向决定附近提示和搬起目标，松开移动后保留最后朝向，不再轮流提示左右物体。携带时，面朝侧显示预计放下位置的虚线框：青绿可放、红色不可放，合并块按完整尺寸显示。左右放置键仍可指定方向，角色随之转向；暂停、放下动画和重生期间隐藏预览。

Pick、Test、Gaming 均接入原有屏幕提示：搬运操作、非法放置、死亡复活、颜色选择和染色反馈。这些提示只在对应操作发生时出现，不会常驻列出所有操作。
