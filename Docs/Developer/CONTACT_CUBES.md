# 三色接触方块

在关卡编辑器“道具”栏目选择“红色接触方块”“绿色接触方块”或“蓝色接触方块”放置，应用到场景。也可直接拖入 Content/ContactCubes 中的对应预制体。三种方块始终保持自己的类型，不接受玩家点击染色。

三色方块初始未解锁，拿到对应颜色钥匙后启用搬运和接触反应。红块也是能源，放到已解锁基座的检测侧即可通电，任何红块都可使用。旧能源预制体已兼容替换，新布置使用红色接触方块。R 与离区恢复布置位置和状态，颜色解锁不会被清除。平台、曲柄的绑定见 [机关与跳跃](MECHANISMS_AND_JUMP.md)。

绿块接触蓝块时每秒向远离蓝块方向长一格；接触红块每秒短一格；同时接触红、蓝时锁住长度。移开后保持当前长度。Inspector“长度与接触”可配置最大长度、初始长度、变化间隔；默认最大六格。长出的部分是同一个实体。

红蓝接触持续生成水柱，水柱从蓝块向远离红块方向喷出。蓝块 Inspector“水柱”可设置射程、宽度、速度和占位材质。它能推动玩家和三色方块；水平喷出后的短暂重力保护可在物理组件中调整。

三色方块接触已解锁的既有颜色功能物体，会触发与玩家对应颜色能力相同的反应。绿色横向长出的部分允许玩家在下方悬挂前进，或在上方缓行；两者均进入横向攀附状态，跳跃操作改为脱手下落。横向部分可沿外边缘上下绕角，单格/竖向绿块及普通藤蔓也支持两侧向上翻到露出的顶部，不会在连续节段中间误翻顶。原始一格不进入横向攀附，不使用旧藤蔓母根/节段系统。离开所属房间或重生时恢复布置状态。

本版提供简单不透明占位模型和带重力的刚体。绿块与长出的部分始终是实体，玩家不能穿过或水平推走，落稳后可站立，并可在母块或长出部分两侧攀爬。红、蓝块仍在空中不碰撞玩家，落稳后可站立、不可推走。水柱仍能推动三色方块。黏住与最终美术尚未接入。可直接拖入预制体测试掉落，或在关卡编辑器放置相邻方块测试接触反应。

三色方块已接入原搬运：靠近方块根格，使用现有搬运键（默认 F）拿起，左右放下键（默认 Q/E）放下；实际按键以项目输入绑定为准。搬运中关闭碰撞、暂停生长和喷水，保留绿块当前长度；放下完成后恢复物理与反应。长绿块需要整个实体都有空位，不能穿墙放置。R/死亡和离开房间仍按原区域规则恢复布置位置与初始状态，不会把放下位置变成新的重置点。

编辑器布置位置是基础位置，不会把运行时落地或移动后的位置当作新的基础位置。在已应用规划的关卡中，R 或离开所属房间恢复布置位置、初始长度和静止反应状态，清除速度、水柱及攀附。三色方块都可以压下门按钮；保持或持续触发由按钮参数决定。

方块只能留在放置时的房间或通道内，归属不会随搬运改变。跨区放下会被拒绝；若方块根中心被推到别的区域或地图外，会回到布置位置。玩家离开房间时取消携带并复原来源房间。房间范围使用世界图真实占格，需先应用规划到场景；不使用模型包围盒猜测房间。
