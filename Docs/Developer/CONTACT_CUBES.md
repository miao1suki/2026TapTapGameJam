# 三色接触方块

在关卡编辑器“道具”栏目选择“红色接触方块”“绿色接触方块”或“蓝色接触方块”放置，应用到场景。也可直接拖入 Content/ContactCubes 中的对应预制体。三种方块始终保持自己的类型，不接受玩家点击染色。

绿块接触蓝块时每秒向远离蓝块方向长一格；接触红块每秒短一格；同时接触红、蓝时锁住长度。移开后保持当前长度。Inspector“长度与接触”可配置最大长度、初始长度、变化间隔；默认最大六格。长出的部分是同一个实体。

红蓝接触持续生成水柱，水柱从蓝块向远离红块方向喷出。蓝块 Inspector“水柱”可设置射程、宽度、速度和占位材质。它能推动玩家和三色方块；水平喷出后的短暂重力保护可在物理组件中调整。

三色方块接触已解锁的既有颜色功能物体，会触发与玩家对应颜色能力相同的反应。绿色横向长出的部分允许玩家在下方悬挂前进，或在上方缓行；两者均进入横向攀附状态，不能跳跃。原始一格仍是普通方块，不使用旧藤蔓母根/节段系统。离开所属房间或重生时恢复布置状态。

本版提供简单不透明占位模型和带重力的刚体。空中不碰撞玩家；落稳后可站立、不可被玩家推走。搬起、放下和黏住尚未接入，最终美术也未接入。可直接拖入预制体测试掉落，或在关卡编辑器放置相邻方块测试接触反应。
