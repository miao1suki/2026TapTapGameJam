# Gaming：MVMap16 分房与方块类型

当前布局按 `Ops/LevelMaps/Map16/source.mvmap.json` 制作，承接 b991bc0 的实际关卡和手工参数。当前结果为18个互不重叠的房间区域、1402项规划物体及实际实例、6277项物体占格累计（允许水与其他物体分层共格）。

## 坐标与房间

- JSON单格(x,y)对应Unity单格(x,-y-1)，保持已纠正的地图方向。保留原始分界宽度，不压缩、不平移。
- 无专名紫色长条提供分房元数据：Unity横条取上边缘、竖条取右边缘，厚条内部不重复切分。仅沿实际线段切分，未画闭合的开口保持连通。
- 名称优先，紫色的“基座”“隐藏方块”按名称生成道具；未命名单格紫色生成曲柄。分界线自身不生成实体。
- 跨房间物体按实际占格拆分并分别记录RoomResetObject归属，合并形状的孔洞保留。玩家出生点和相机初始位置不变，Main Camera和Side2D均保持size8。

## 类型与材质

地形使用已有白方块栏目；功能物体使用项目已有道具预制体及其材质，不修改共享材质或颜色系统。颜色物体仍按当前钥匙规则门控：同色首把激活场景颜色、第二把开放玩家能力；初始锁色状态可能显示白色。

| 源标记 | 实际类型 |
|---|---|
| 灰白 | 白色实体地形 |
| 单格深蓝 / 连续深蓝矩形 | 蓝色接触方块 / 水域 |
| 浅蓝条及紧邻的已确认起点 | 含源格的定向水流，按当前方向设置四向参数 |
| 单格深绿 / 深绿长条 | 绿色接触方块 / 逐格藤蔓 |
| 红色单格 / 长条 | 红色接触方块 / 岩浆 |
| 橙色单格 / 长条 | 基座 / 移动平台 |
| 无专名粉红 | 单向平台 |
| 黄色竖两格 / 单格 | 门 / 一次保持按钮 |
| 浅绿 | 弹性植物 |
| 专名 | 优先使用按钮、持续按钮、尖刺、隐藏方块、收集品、蓝色钥匙、复活点等对应预制体 |

204(-48,-69)继续按用户点名设为绿块。绿块仅以四向实体接触判定可移动性，孤立者固定。命名复活点取画面下方那格（source较大Y），不改运行时复活算法；浮空复活点仍留给作者手动调整。藤蔓、植物、尖刺逐格生成；已有侧向梯子占格与参数保留，梯子标记其余位置使用已有正面梯子。已标注平台终点的路线依据源差值配置向上9格。

## 保留与替换

优先复用37个同占格同类型作者物体，并保留810个仍有有效占格的作者物体。白地形仅应用MVMap15到16的源图增删差量，保留此前手工增补及删除；新增功能物体与旧表示重叠时，按最新类型移除旧表示的对应格，避免两套实体叠放。34项旧物体存在部分或全部被替换格，包括27个单格水源、5个白体、一处复活点和一处平台；具体原ID及source坐标见清单replacedCells。未冲突物体不挪动，拆分后的占格可精确还原。

15个按钮按同房间门配对，多候选使用生成时确定的排列，结果和按钮顺序持久保存。用户已确认本次只完成类型和分房：其他新增曲柄、基座与平台不自动连线，后续按作者指定配置。曲柄已记录初始配套处理状态，重开编辑器不额外生成JSON之外的平台。涌现之泉继续暂缓，无色标记及平台终点不单独生成实体。
