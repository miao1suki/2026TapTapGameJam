# 颜色属性与褪色

颜色是可交互物体的基础属性。编辑交互逻辑请打开 `Tools/2026TapTap/物体交互管理器`，不要使用旧的颜色工作台或颜色交互图入口。

## 制作与预览

1. 在关卡编辑器放置红、蓝、绿方块。打开物体交互管理器时，三种方块会自动出现在物体列表。
2. 选中方块栏目卡片后点击“交互”，即可直达该方块的物体图；道具栏目也使用同一入口。
3. 在图中使用玩家进入/离开、物体触碰/停留、受到颜色、褪色、恢复、延迟、Timeline 和方法调用节点。
4. 颜色钥匙仍触发解锁和 Timeline 相机演出；`ColorRuntimeService` 会先建立基础恢复状态，再由物体图的手动节点进入恢复链。服务启动时颜色目录默认褪色，锁回颜色时重新褪色，因此相机演出中断也不会留下错误的材质或水体状态。
5. 玩家右键打开颜色轮盘，只能选择已经解锁的颜色。选色只写入玩家的 `PlayerColorWheel.SelectedColorId`，不会直接改变目标物体；目标物体的 `Manual` 交互图通过 `RequirePlayerColor` 决定是否执行效果。
6. 玩家周围的虚线圆是 `PlayerInteractionSensor.ScanRadius` 的可视化。扫描、右键选中和交互执行使用同一个半径，超出圆形范围的物体不会被选中或触发。
7. 蓝色方块的水体渐显、绿色方块的攀爬和红色方块的碰撞能力由挂载的 `BlockFeature` 提供，图负责触发时机。

## 边界

`ColorRuntimeService` 只负责颜色解锁、当前颜色和蓝水视觉；`PlayerColorWheel` 只负责玩家选色与轮盘显示；`HSVColorFadeManager` 只负责按颜色层渐变；这些模块都不是物体交互规则的拥有者。旧颜色工作台、颜色交互图、颜色交互执行器和颜色世界管理器已删除。
