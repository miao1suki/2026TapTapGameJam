# 颜色物体与钥匙解锁

颜色是固定物体的解锁分组，不是运行时可随意改变的当前颜色。

## 外观恢复

恢复节奏：默认请求总时长为 5 秒，钥匙等指定时长的请求默认乘 3（现有 1.5 秒钥匙实际为 4.5 秒）；两段分别放慢，立即重置仍不延迟。运行时 HSV 管理器 Inspector 可调整默认时间与指定时长倍率。

水体与藤蔓保留蓝/绿颜色 Layer，像素化单独使用 Renderer 的 Rendering Layer 第 7 位（数值 128），不需要手工改成 PixelEffect。一个 GameObject 只有一个普通 Layer，Rendering Layer 是独立的多选位掩码。TA 独立测试物体的 PixelEffect 层保持不变，由新像素化通道处理。

像素化现已迁入 URP学习 的独立三阶段实现，先像素化再 HSV。描边默认关闭，调用开关和调试方式见 [选择性像素化](PIXELIZATION.md)。原 TA 02StencilPixelEffect 已停用，避免重复处理；原有 PixelEffect 层物体改由新通道处理。

### 藤蔓表现与燃烧

藤蔓整束默认宽度为 1.2 格，枝条拖尾宽度为原素材的 3 倍；两项分别在“藤蔓表现”调整，不改变碰撞与攀爬判定。实例先彻底停止并清空粒子，再固定随机种子并建立姿态缓存，避免运行中修改种子的报错。

### 全屏处理路径与检查

PC 默认使用 `PC_RPAsset → PC_Renderer`，Pick 摄像机使用默认 Renderer。`SelectiveHsvRendererFeature` 在透明渲染之后、后处理之前，为红/绿/蓝普通 Layer 生成深度测试遮罩，然后全屏合成当前颜色的白色混合与 HSV 饱和度。不是通过改变水或藤蔓材质颜色完成渐变。

运行时选中 `HSV Color Fade Manager`，Inspector 的“渲染状态”显示当前管线、全屏通道是否执行，以及三色的饱和度 S / 白色混合量。现有钥匙恢复约 4.5 秒，前 30% 推白、后 70% 从纯白恢复；通道应显示“运行中”，数值连续变化。该状态证明通道提交执行，不替代 GPU 遮罩像素与最终画面验收。

遮罩使用独立材质的默认白纹理，不读取原 Shader 不统一的 MainTex/BaseMap。藤蔓通过专用属性传入拖尾 alpha 纹理和顶点 alpha，仅裁剪透明孔洞；全屏通道在执行时绑定本颜色的纹理，避免跨颜色共享遮罩。任意透明物叠加、复杂 Shader 位移仍需在 Game / Frame Debugger 检查。

母藤蔓使用颜色目录中的 TA 粒子预制体，未解锁时不生成粒子；解锁后加入绿色褪色通道。初始粒子时间 30.13，长成时间 32.43，默认用 2.3 秒推进，按实际根系格数缩放，而不是为每一格重复生成一套长藤蔓。预置已长满的根系直接显示长成状态。参数在藤蔓组件的“藤蔓表现 / 燃烧设置”调整。

触碰已激活水体使母根生长到配置上限；玩家直接蓝色交互保持逐块/瞬间生长设置。玩家直接红色交互或万能方块广播红色，都从该母根最上方逐节烧到母根，默认每节 0.45 秒，并反向回放粒子、缩短可见高度。燃烧中的节段立即断开攀爬，该节完成后取消实体碰撞；不会扫描并连带其他根系。预置节段保留为休眠实例，房间重置会恢复；运行时生长物仍由母根清理。

TA Grow 场景的 Particle System 与 Particle System (1) 引用同一预制体，已保存差异只有摆放位置，因此接入其共用资源，不额外假定存在密度不同的版本。

验收建议：同场景放两根独立藤蔓，测试未解锁、绿色恢复、浇水生长、任意节段红色交互、万能方块广播、烧到母根后房间重置。Game 中检查水波与藤蔓透明轮廓、像素边缘和被地形遮挡时的表现。

编辑器中的彩色边框是识别外观，不参与 Game 的表现。未解锁物体使用黑白基础材质；解锁后基础外观一边变白一边淡出至完全透明，随后交接正式外观，正式外观从完全透明渐显并恢复颜色。总时长前 30% 用于基础外观淡出，后 70% 用于正式外观恢复，交接两侧均为完全透明。“颜色表现管理器”显示基础与正式外观的不透明度，HSV 调试面板只显示饱和度与白化。材质需支持 `_ColorRevealOpacity`；现有基础、水体和藤蔓已适配，其他不兼容 Shader 不能只靠 Layer 就实现透明。

蓝色水域、水流、水柱的正式外观由水体组件提供，基础模型在完全透明交接时关闭，不会恢复为蓝色边框。其他道具可在“颜色物体 / 正式外观材质”配置实际材质，或使用功能组件对该渲染器配置的专属材质；两者都为空时，交接后隐藏识别模型，碰撞与功能不因此删除。颜色钥匙仍显示对应颜色，不参与颜色物体层的褪色。

### 藤蔓跳与环境弹起

玩家 Inspector 的“攀爬”分组可调整蹬跳慢落时间（默认 1.2 秒）、下落限速（默认 3.5）、顶部向内冲量倍率（默认 1.5）和顶部起跳速度倍率（默认 1.12）。顶部范围按母根完整根系的最高处向下一格计算；中段仍向外蹬跳，顶部改为向藤蔓方向蹬跳。慢落只影响蹬跳后的短暂下落阶段，重置玩家时清理。

“环境弹起”分组提供额外喷出速度（默认 2.5）和喷出速度保护时间（默认 0.2 秒）。气泡柱、弹跳和红色与水交互产生的蒸汽弹起都经玩家控制器统一处理；短暂保留喷出速度，防止游泳减速与松开跳跃的额外重力立即抵消。持续蒸汽请求提高的是目标速度下限，不会无限累加速度。现有来源为向上弹起，不改变输入键位。

颜色层渐变也覆盖同层的不交互场景物体和透明水体。Scene 编辑状态保留识别外观；褪色表现仅作用于运行中的 Game 摄像机。

## 房间流程

```text
开局：红、蓝、绿物体白色失效
→ 拾取对应颜色钥匙
→ 该颜色组恢复原色并启用固定组件
→ 离开房间
→ 全部失效并清除临时效果
```

## 物体形态

形态在放置时固定：

- 蓝色可以分别是水源、定向水流、浮力柱。
- 绿色可以分别是藤蔓、弹性植物、植物障碍。
- 红色可以分别是岩浆、机关基座、移动平台、尖刺、梯子等。

同一物体不会跨颜色变化，也不会在运行时切换形态。

## 关卡编辑器栏目

- 方块栏目只负责地图墙壁、地形和几何碰撞。
- 红、蓝、绿玩法物体全部放在道具栏目。
- 玩法预制体位于 `Assets/_Project/Content/ColorBlocks/Prefabs`。
- 命名使用 `Red_*`、`Blue_*`、`Green_*`。

## 组件

- `ColorObject`：新固定颜色物体入口。
- `BlockAbilityHost`：只启停预制体上已有的 `BlockFeature`。
- `BlockRuntime`：单物体内部信号、命令和调试。
- `ColorRuntimeService`：颜色解锁、房间重置和颜色物体注册。
- `ColorKeyPickup`：进入玩家感知范围后先播放磁吸；真正碰到玩家后才解锁颜色、隐藏钥匙、锁定玩家操作并进入镜头演出。
- `HSVColorFadeManager`：颜色层渐变。

固定功能组件已经按预制体形态接入：

- 红色：岩浆、能源方块、机关基座、按钮锁、曲柄平台、自动移动平台；升降机、尖刺、机关梯子组件已准备，等待对应预制体。
- 蓝色：水域、定向水流、浮力水柱。
- 绿色：可攀爬藤蔓、弹性植物、植物障碍。

三色物体之间的直接反应已开始接入：红色清除绿色物、蓝色让藤蔓向上生长、红色替换蓝色物、蓝色作用于岩浆。左键点击时，屏幕射线直接寻找 `IColorApplicationTarget`；`BlockFeature` 子类通过 `OnColorApplied` 处理自己接收到的颜色。

机关交互约束：按钮无实体阻挡但接玩家交互键；曲柄使用长按交互；能源方块是唯一允许迁移的物体，迁移方式为交互圈内长按“搬运”键拿起、鼠标网格吸附拖拽、松手放下；搬运键默认右键并锁定长按；基座只检测贴贴能源并输出信号；移动平台从自己这一侧绑定基座、按钮和曲柄，支持路线、格数、驱动方式、载人和标签筛选。水泡不再按最高格数停机，默认推力为 7；玩家碰撞体与任意蓝色物的垂直重叠超过自身高度一半时持续上浮，露出超过一半后立即移除气泡水状态、清空浮力和剩余向上速度，重新下沉会立即恢复，横移离开气泡列才清除。组件按格计算时统一读取关卡编辑器格子世界尺寸。

当前输入约定：`Tab/F` 调色动作只开关染色轮盘，`E` 负责按钮、曲柄等交互目标，左键在轮盘关闭时对已选颜色执行染色。藤蔓和弹跳植物是实体阻挡物；按钮按格半径检测交互；移动平台碰到方块后反向。

弹性植物只在下落距离有效时触发摔落弹跳，同平面走入不会自动弹。回弹高度按落差乘回弹比例计算：落差越高，比例越接近“高落差回弹比例”，默认最低保留一半；连续弹跳再乘衰减比例，预测高度低于“最低弹跳高度（格）”时不再触发。

移动平台只承载站在顶面的玩家。平台把每帧位移交给 `PlayerController`，由玩家的 Rigidbody 统一应用；侧面碰到平台不会被带走，也不会通过改变玩家父物体来载人。

母藤蔓的“生长物预制体”绑定 `Green_LadderSon`。生长物使用 `LadderSonFeature`，可以被玩家攀爬、可以被红色烧毁，但不会被蓝色再次浇灌，因此不会套娃生长。

红色作用于蓝色物体时会在其顶部触发蒸汽热浪：可选瞬间或持续，持续模式可配置时长，并统一配置推力、作用高度和热浪特效资源。实际操作前把热浪特效预制体拖到蓝系组件的“热浪特效”槽位即可。

具体玩法组件必须继承 `BlockFeature`，并声明：

- 中文 `DisplayName`
- 固定颜色组 `DefaultColorId`
- 功能类别 `Category`
- 交互类型 `Interactions`
- 依赖、冲突和最大数量

旧的水体、藤蔓和动力功能组件已经删除。当前颜色 prefab 只有渲染、碰撞、`ColorObject`、`BlockRuntime` 和 `BlockAbilityHost` 骨架，等待后续按固定形态挂新组件。

## 万能方块

`UniversalColorBlock` 是前期辅助代理。玩家选择已解锁颜色后点击它，它自身显示对应纯色，并按关卡格向左右上下四个紧邻的 `IColorApplicationTarget` 广播同一颜色；实际反应由每个目标自己的固定组件处理。

基础预制体是 `Content/ColorBlocks/Prefabs/Universal_Block.prefab`。它只挂 `UniversalColorBlock` 和基础碰撞、渲染，不挂 `ColorObject`、`BlockRuntime` 或 `BlockAbilityHost`。

万能方块不能搬运，不拥有玩法能力，不参与物体之间的固定反应。

## 交互距离

`PlayerInteractionSensor.ScanRadius` 是交互圈半径。左键先通过屏幕射线命中最靠前的可交互物体，再检查目标是否在交互圈内；超出圈外或点击 UI 不执行交互。选色完成后，目标如果是 `IColorApplicationTarget`，直接调用 `ApplyColor`；如果是万能方块，则自身显示纯色并向四个紧邻目标广播颜色。万能方块可配置持续染色或延迟褪色，延迟时间在 Inspector 中调整。

玩家的拾取感知半径单独使用“拾取感知半径（格）”，不使用交互圈半径。掉落物进入该范围后开始磁吸，但只有真正碰到玩家才结算拾取。

完整架构约束见 `Assets/_Project/Code/Systems/ColorBlocks/SKILL.md`。

## 分类表现管理

运行时由“颜色表现管理器”集中处理基础方块、水体和藤蔓。前 30% 时间，基础外观变白并淡出；完全透明时交接，正式外观从全白且透明开始，余下时间恢复原色并渐显。基础方块和藤蔓按源材质、颜色组及表现阶段共用运行时材质，不修改美术原件，也不让每个物体逐帧改外观。水体保留独立波纹和反射资源，在过渡期间集中更新，完成后停止写入。

“HSV 褪色管理器”只控制全屏饱和度与白化参数，单独调用它不会解锁物体、切换材质或隐藏水体。正常测试继续从颜色系统调试面板解锁颜色；表现管理器 Inspector 可检查共享材质数量、水体/藤蔓数量和两种外观的透明度。首次显示前完成材质和遮罩初始化，零透明度处不绘制 HSV 遮罩。

藤蔓使用专用透明运行时拖尾 Shader，保留源纹理和颜色；粒子生长、燃烧和攀爬判定不由 HSV 控制。材质透明排序和像素化后的边缘效果需要在 Game 中验收。

水体使用适配三维网格的 URP Unlit 透明 Shader Graph，保留 TA 的波纹、折射、焦散与反射。水面和横截面在解锁过程渐显，完全恢复后保持原始透明度；不使用编辑器的蓝色边框识别材质。只调 HSV 参数不等于解锁水体，测试时请使用颜色系统的解锁入口。
