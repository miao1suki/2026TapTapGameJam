# 颜色物体与钥匙解锁

颜色是固定物体的解锁分组，不是运行时可随意改变的当前颜色。

## 房间流程

```text
开局：红、蓝、绿物体白色失效
→ 拾取对应颜色钥匙
→ 该颜色组恢复原色并启用固定组件
→ 离开房间
→ 全部失效并清除临时效果
```

## 物体形态

形态在放置时固定：

- 蓝色可以分别是水源、定向水流、浮力柱。
- 绿色可以分别是藤蔓、弹性植物、植物障碍。
- 红色可以分别是岩浆、机关基座、移动平台、尖刺、梯子等。

同一物体不会跨颜色变化，也不会在运行时切换形态。

## 关卡编辑器栏目

- 方块栏目只负责地图墙壁、地形和几何碰撞。
- 红、蓝、绿玩法物体全部放在道具栏目。
- 玩法预制体位于 `Assets/_Project/Content/ColorBlocks/Prefabs`。
- 命名使用 `Red_*`、`Blue_*`、`Green_*`。

## 组件

- `ColorObject`：新固定颜色物体入口。
- `BlockAbilityHost`：只启停预制体上已有的 `BlockFeature`。
- `BlockRuntime`：单物体内部信号、命令和调试。
- `ColorRuntimeService`：颜色解锁、房间重置和颜色物体注册。
- `ColorKeyPickup`：进入玩家感知范围后先播放磁吸；真正碰到玩家后才解锁颜色、隐藏钥匙、锁定玩家操作并进入镜头演出。
- `HSVColorFadeManager`：颜色层渐变。

固定功能组件已经按预制体形态接入：

- 红色：岩浆、能源方块、机关基座、按钮锁、曲柄平台、自动移动平台；升降机、尖刺、机关梯子组件已准备，等待对应预制体。
- 蓝色：水域、定向水流、浮力水柱。
- 绿色：可攀爬藤蔓、弹性植物、植物障碍。

三色物体之间的直接反应已开始接入：红色清除绿色物、蓝色让藤蔓向上生长、红色替换蓝色物、蓝色作用于岩浆。左键点击时，屏幕射线直接寻找 `IColorApplicationTarget`；`BlockFeature` 子类通过 `OnColorApplied` 处理自己接收到的颜色。

机关交互约束：按钮无实体阻挡但接玩家交互键；曲柄使用长按交互；能源方块是唯一允许迁移的物体，迁移方式为交互圈内长按“搬运”键拿起、鼠标网格吸附拖拽、松手放下；搬运键默认右键并锁定长按；基座只检测贴贴能源并输出信号；移动平台从自己这一侧绑定基座、按钮和曲柄，支持路线、格数、驱动方式、载人和标签筛选。水泡不再按最高格数停机，默认推力为 7；玩家碰撞体与任意蓝色物的垂直重叠超过自身高度一半时持续上浮，露出超过一半后立即移除气泡水状态、清空浮力和剩余向上速度，重新下沉会立即恢复，横移离开气泡列才清除。组件按格计算时统一读取关卡编辑器格子世界尺寸。

当前输入约定：`Tab/F` 调色动作只开关染色轮盘，`E` 负责按钮、曲柄等交互目标，左键在轮盘关闭时对已选颜色执行染色。藤蔓和弹跳植物是实体阻挡物；按钮按格半径检测交互；移动平台碰到方块后反向。

弹性植物只在下落距离有效时触发摔落弹跳，同平面走入不会自动弹。回弹高度按落差乘回弹比例计算：落差越高，比例越接近“高落差回弹比例”，默认最低保留一半；连续弹跳再乘衰减比例，预测高度低于“最低弹跳高度（格）”时不再触发。

移动平台只承载站在顶面的玩家。平台把每帧位移交给 `PlayerController`，由玩家的 Rigidbody 统一应用；侧面碰到平台不会被带走，也不会通过改变玩家父物体来载人。

母藤蔓的“生长物预制体”绑定 `Green_LadderSon`。生长物使用 `LadderSonFeature`，可以被玩家攀爬、可以被红色烧毁，但不会被蓝色再次浇灌，因此不会套娃生长。

红色作用于蓝色物体时会在其顶部触发蒸汽热浪：可选瞬间或持续，持续模式可配置时长，并统一配置推力、作用高度和热浪特效资源。实际操作前把热浪特效预制体拖到蓝系组件的“热浪特效”槽位即可。

具体玩法组件必须继承 `BlockFeature`，并声明：

- 中文 `DisplayName`
- 固定颜色组 `DefaultColorId`
- 功能类别 `Category`
- 交互类型 `Interactions`
- 依赖、冲突和最大数量

旧的水体、藤蔓和动力功能组件已经删除。当前颜色 prefab 只有渲染、碰撞、`ColorObject`、`BlockRuntime` 和 `BlockAbilityHost` 骨架，等待后续按固定形态挂新组件。

## 万能方块

`UniversalColorBlock` 是前期辅助代理。玩家选择已解锁颜色后点击它，它自身显示对应纯色，并按关卡格向左右上下四个紧邻的 `IColorApplicationTarget` 广播同一颜色；实际反应由每个目标自己的固定组件处理。

基础预制体是 `Content/ColorBlocks/Prefabs/Universal_Block.prefab`。它只挂 `UniversalColorBlock` 和基础碰撞、渲染，不挂 `ColorObject`、`BlockRuntime` 或 `BlockAbilityHost`。

万能方块不能搬运，不拥有玩法能力，不参与物体之间的固定反应。

## 交互距离

`PlayerInteractionSensor.ScanRadius` 是交互圈半径。左键先通过屏幕射线命中最靠前的可交互物体，再检查目标是否在交互圈内；超出圈外或点击 UI 不执行交互。选色完成后，目标如果是 `IColorApplicationTarget`，直接调用 `ApplyColor`；如果是万能方块，则自身显示纯色并向四个紧邻目标广播颜色。万能方块可配置持续染色或延迟褪色，延迟时间在 Inspector 中调整。

玩家的拾取感知半径单独使用“拾取感知半径（格）”，不使用交互圈半径。掉落物进入该范围后开始磁吸，但只有真正碰到玩家才结算拾取。
