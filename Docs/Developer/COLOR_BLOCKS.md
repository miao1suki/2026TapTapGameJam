# 颜色方块与褪色

入口：`Tools/2026TapTap/颜色/颜色工作台`。关卡编辑器的红、绿、蓝方块栏目直接放置对应 `ColorBlock_*` 预制体，分别使用 `Color_red`、`Color_green`、`Color_blue` 层。Scene 和栏目缩略图使用编辑识别材质；Game 与构建版在未解锁时显示统一白色基础材质，解锁后隐藏该网格，由正式效果接替，不会出现 RGB 编辑识别材质。碰撞和颜色属性与可见外观独立，解锁时属性立即更新。

## 制作与预览

1. 在关卡编辑器放置红、绿、蓝方块，或从 `Assets/_Project/Content/ColorBlocks/Prefabs` 拖入预制体。道具栏目提供红、绿、蓝三色钥匙预制体；颜色工作台也可创建同一预制体的场景实例。钥匙从游戏开始就显示对应的红、绿、蓝色。
2. 颜色交互图用触发、条件、操作节点连线。目录只保存有明确用途的节点类型，不再保存自由文字节点。图数据位于 `Assets/_Project/Resources/ColorBlocks/ColorCatalog.asset`。
3. 拾取钥匙时，Timeline 先拉远镜头（正交 2D 同步扩大视野）并停住；随后开始颜色恢复，完成后经相机 Manager 较快地返回原机位。三个内置钥匙共用各自的默认 2 秒拉远 Timeline。自制 Timeline 可调整；没有有效相机轨时仍会解锁，但没有运镜。
4. 在 `Tools/2026TapTap/颜色/褪色调试` 中进入 Play Mode，先点击对应颜色的“解锁”，再按“褪色”或“恢复”观察过渡。普通场景物体也可在编辑态指定颜色层，无需挂 `ColorBlock`。
5. 蓝色方块解锁后，白色基础网格立即隐藏，TA 水效果从透明渐显，顶面同步展开；RGB 编辑识别材质不会进入 Game。相邻矩形区域共享一组视觉实例；合并后的大方块按整体边界显示效果。进入蓝色方块的触发区域时，玩家切换为游泳状态，方向输入控制水平和竖直移动，跳跃键也可上游。红、绿解锁前是白色基础方块；正式表现尚未接入，因此解锁后暂不可见，但碰撞与交互仍在。

`RoyTestScene` 中原有的 2031 个旧彩色基础方块已一次性替换为对应颜色预制体。黑色和能源方块不属于这次迁移。新场景不需要再运行迁移工具。

## 边界与性能

颜色层上的其他不透明场景物体由 `SelectiveHsvRendererFeature` 处理；`ColorBlock` 未解锁时使用 `ColorCatalog.NeutralMaterial`，解锁后隐藏基础网格，绝不在 Game 使用 RGB 编辑识别材质。蓝水特效的渐显由水视觉实例控制，不依赖不透明物体遮罩。TA 的水模拟资源由运行时视觉实例共享，水面反射在颜色方块实例上关闭，避免每个方块创建独立高分辨率模拟和反射相机。水效果源文件保存在 `Assets/ta_source/InteractiveWater`，其普通独立预制体仍可由 TA 单独使用。

颜色工作台目前提供基础交互图节点；策划的九种完整交互和两色合成新物体尚未落地。染色入口也还没有接入玩家的轮盘与范围判断。接入约束与 API 见 [COLOR_BLOCKS_API.md](../Agent/Integration/COLOR_BLOCKS_API.md)。
