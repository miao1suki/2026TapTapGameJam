# 关卡水体与定向气泡

水域、定向水流和浮力水柱使用 TA 的像素水面、水中、水下面片及前方透明折射板。现有关卡和新增道具共用同一路径，无需重新放置或重建地图。

## 面片与显示顺序

- 相邻水格自动连成连续视觉水体。最上沿使用水面，下一格使用水中，深处使用水下；不同水域、水流和浮力柱相邻时也识别连接，不在内部重复画水面。
- 合并后的大水块按关卡格尺寸重复纹理，不将单张图片拉伸到整块。TA原图底部的一行透明留白不占格。
- 可合并不规则水域，不必把包围矩形补满。孔洞保留为空，水面按实际相邻水格识别，空洞和墙体遮挡区域不会被透明折射板填上。
- 墙、藤蔓、植物障碍及机关等可与水同格放置。墙覆盖的格子不显示水或水的颜色交互连线；同格点击优先非水物体。关卡编辑器的“仅操作水层”可淡化前景并单独编辑底层水。
- 从后到前依次为水体后片、角色与气泡、透明折射板。角色和气泡会被折射，但不会被水体后片遮住。
- 蓝色未解锁时仍显示原黑白基础外观。解锁后基础外观先淡出，真实水和气泡再一起渐显并恢复色彩；不显示蓝色边框编辑材质。

## 流向气泡

定向水流自动生成左、右、上、下气泡；浮力水柱生成向上气泡，并延伸至其上方连续水体的顶部。普通水域不额外生成流向气泡。气泡只作表现，原水流速度、浮力和游泳逻辑不变。

选中水流或浮力柱，在组件或关卡编辑器的参数中调整“流向气泡”：显示开关、密度（排/格）、速度（格/秒）。默认每排两颗、密度1.1、速度1.4。长度随实际水体范围自动适配；超过10格的流向或宽水流自动分段，不把特效截成10格。

统一资源配置：[WaterPresentation.asset](../../Assets/_Project/Resources/ColorBlocks/WaterPresentation.asset)。Inspector 的“水体面片”“流向气泡”分区可替换图片、材质和预制体。图片/材质数组顺序固定为水面、水中、水下。TA独立测试预制体仍保留供调试，不用拖入关卡的每个水格。

房间重置、禁用和重新启用会清理旧表现再创建一次，不留下重复面片和气泡。关卡存档、碰撞体积及房间归属不变。
