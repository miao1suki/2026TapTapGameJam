# 三色方块重力与美术图案旋转

## 三色方块

在关卡编辑器的物体参数中展开“接触方块运动 / 物理”，逐实例调整“启用重力”。红、绿、蓝采用相同的 `ContactCubeMotion.useGravity` 布尔参数，默认开启，与基座的显式配置形式一致。颜色身份、能力解锁和生长参数不受此开关影响。

- 开启：方块自然下落；水平绿钩拉取仍受重力，水柱沿用既有短暂保护。
- 关闭：空闲时保持悬浮；依旧参与接触反应、可搬运，红蓝仍可被绿钩拉动；放下、脱钩和房间重置后继续无重力。
- 旧实例的刚体锁轴和作者运动学固定状态保留，不批量重排场景或存档。重力开关不会擅自解除作者的 FreezeAll / 单轴锁定；绿钩只解除运动器自己的落稳锁，不能解除作者锁轴。
- 无重力、作者固定或真实落稳的绿色本体及伸长实体都能提供攀爬。横向伸长体的上、下表面沿用攀附与外转角保护。挂绳期间及松绳保护仍优先，不靠攀爬中断荡绳。

程序读取 `UsesGravity`；动态配置用 `ConfigureGravity(bool)`，不要让外部组件直接反复改 `Rigidbody.useGravity` 与本运动器争抢。关卡存档通过现有组件布尔覆盖保存，不需增加第二套物理存档。

## 关卡美术工作台

在右侧“当前素材”下点击“逆时针90° / 顺时针90°”，然后在画布或 Scene 放置。旋转是每个已放图案独立的数据，不修改共享素材库，其他关卡不会一起旋转。要修改现有图案，可在同一锚点重绘；整笔支持 Undo / Redo，旋转随美术图保存和独立副本保留。

只允许 0 / 90 / 180 / 270 度；长方形会交换自然宽高与逻辑占格，不拉伸、不重采样源图片。例如48×8有效像素图案从3×0.5格转为0.5×3格，仍是16有效像素 / 世界格。擦除、框选排布与悬停框采用旋转后的尺寸。普通单格贴图的自动铺绘会保存所选旋转，后续新增白块也继承它；自动连接边角地形仍由邻接规则决定朝向，不适用独立旋转。

画布和生成 Mesh 共用 `GridArtQuad.UV`；同UV法线图与色图一起旋转，Mesh重新计算切线。新字段 `GridArtCell.quarterTurns` 默认0，旧美术图不会被自动旋转或调整尺寸；不合标准的旧图仍需显式“恢复原像素比例”。

## 验证入口

只在静音 `Library/FlowRetirementProbe` 隔离工程运行 `Project.ContactCubes.Editor.ContactCubeGravityRotationAudit.Run`，禁止在主Unity窗口执行。报告 `Library/ContactCubeGravityRotationAudit.txt` 包含：

- 48×8矩形四向的原像素密度、预览/生成Mesh同UV、保存/重载、覆盖重绘、Undo/Redo与旋转后擦除。
- 三色实例重力启停、绿钩/搬运/重置、规划参数覆盖往返、旧FreezeAll保持。
- 固定蓝块与悬浮/固定绿块真实接触，向四方向长满后母体和衍生实体侧面攀爬、横向上下攀附，以及重置释放攀爬状态。

该审计不替代完整关卡通关、手感或双端包验收。交付仍需 Scene/`.meta`、新增依赖、共享素材库、本关美术 Map/区域归属，不只交生成网格；历史 planning JSON 不再同步。
