# 收集品与四向尖刺

打开关卡编辑器，在右侧“道具”中选择“收集品”或“尖刺·上/下/左/右”并绘制。它们都是独立的一格道具，可放在水体同一格，预览显示在水体上层。应用、自动同步、存档、片段导入/导出沿用关卡编辑器流程。

若道具栏目缺失，退出运行模式后执行 `Tools/2026TapTap/关卡/补齐收集品与四向尖刺`。该操作只补缺失资源和栏目，不覆盖已有配置。

## 收集品

白膜球体带重力，可由红绿蓝接触方块或移动中的机关基座推动。玩家接触后播放现有拾取飞行动画，动画结束再回收。不是颜色能力目标，不会因鼠标染色而收集。

参数模式或 Inspector 可设置收集品编号、数量及收集完成事件。当前不预设分数、背包或成就规则，后续系统通过事件接入。R 重生或离开所属区域会恢复布置位置和可收集状态，因此需要永久累计的奖励接入方应按关卡/物品稳定标识去重。

## 尖刺

四种预制体表示四个朝向，尖刺三角区域为 Trigger，不是整格致死矩形。碰到后走玩家现有死亡和重生流程；复活保护期间不会重复致死。无颜色解锁、无染色交互，底下需要实体地板时另放地面方块。

支持合并成长排或带空洞的形状：运行时按实际占格生成接触区，不会把整排缩成一个三角形，也不会让孔洞致死。R 重生、离开房间后仍保持正确伤害区域。重生安全位置会避开尖刺。

2026-10-17 修复了“有外观、碰到却不死亡”：原触发器在子物体，伤害脚本在父物体，缺少物理事件转发。既有四向预制体和已放置场景自动使用修复，不需要重新摆放或覆盖关卡存档。

预制体位于 `Assets/_Project/Content/WorldItems`。尖刺已接白色美术；替换外观时保留拾取/触发碰撞和组件。收集品不要把可见子物体提前关闭，否则拾取飞行动画不可见。
