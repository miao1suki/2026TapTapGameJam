# 2026TapTap

Unity **6000.3.12f1** · URP · 新 Input System。
仓库：**https://github.com/miao1suki/2026TapTapGameJam**。

打开 `Assets/_Project/Scenes/Bootstrap/Bootstrap.unity` 并运行。

agent首先读取 [AGENTS.md](AGENTS.md) 和 [系统索引](Docs/Agent/SYSTEM_INDEX.md)。
