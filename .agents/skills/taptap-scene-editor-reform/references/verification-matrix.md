# 验证矩阵

测试必须与风险匹配。编辑器编译通过不等于作者数据安全；nographics 测试不等于 SceneView 交互验收。

## 零写入门槛

在一个已保存且干净的测试 Scene，以及正式 Gaming 的只读审计中分别验证：

| 操作 | 必须保持不变 |
|---|---|
| 打开/关闭 Overlay | Scene dirty、Map/Palette dirty、Undo、磁盘哈希 |
| 进入/退出正交编辑 | 上述全部；退出后 SceneView 原状态逐字段恢复 |
| 区域/对象/绑定/美术切换 | 上述全部 |
| 选择、聚焦、框选预览、导航 | 上述全部 |
| 切换活动 Scene/SceneView | 原 Scene 不保存、不迁移；新 Scene 不自动生成 |
| 脚本重编译/Domain Reload | 作者资源不写；编辑会话安全释放 |
| 进入/退出 Play Mode | 不提交未完成笔画，不执行迁移或 Apply |
| Undo 栈为空时浏览工具 | 不生成伪 Undo 项 |

同时检查 `LevelEditorBlockFactory.MigratePlacedBlocks`、`GridArtBuilder.Apply`、`AssetDatabase.SaveAssetIfDirty`、`EditorSceneManager.MarkSceneDirty` 没有从只读路径被调用。

## 房间与通道

- 新房间、新通道的 ID 唯一且改名不变。
- 单格、连续和矩形笔画各自一个 Undo；空操作不产生 Undo/dirty。
- 房间与通道不能重叠；错误预览不写数据。
- 新区域必须四邻接；擦除导致断裂时拒绝并可显式拆分。
- 已有分离区域打开不被修改；允许整体移动和不增加分量的编辑。
- 通道连接只由四邻接得出，移动后即时更新，没有残留 from/to。
- 区域格与 `FindRegion` 的世界位置换算在正/负坐标、管理器非零 Transform、非 1 cellSize 下正确。
- 擦有对象的区域默认拒绝；三种显式处理都只影响清单内目标。
- 保存重开、Undo/Redo 后 `RoomLifecycleManager.RebuildOwnership()` 结果一致且无意外重叠日志。

## 对象与逻辑组

- 墙、水、道具在同格时能分别选择和擦除，不出现任意命中。
- 新对象有非空唯一作者 ID、正确 Cell/cellWorldSize、正确父容器和区域归属。
- 新对象记录方块/道具 Palette 稳定栏目来源；关闭重开后仍能在资源库定位原模板。
- 旧对象来源扫描零写入；Prefab 唯一匹配和唯一名称匹配可显式认领完整作者组，一次 Undo/Redo；重复栏目、无匹配、失效来源和 Prefab 不一致不会被批量猜写。
- Palette 资源库搜索、方块/道具筛选、空结果、无 Prefab 基础方块、资源 Ping、模板编辑和 3000+ Scene 已认领计数可用；全 Scene 来源扫描不进入 200ms 刷新。
- 七实例同 ID 或等价测试组只能整体移动/删除，不能留下孤儿。
- 合并形状按真实覆盖命中，洞内不误选，移动后覆盖同步。
- 门 1×2、多格平台、旋转/深度允许项的预览与实际占格一致。
- 使用 Unity Move Tool 和自定义手柄都同步 Transform 与 Cell；非法跨区默认回滚。
- 删除有反向引用的对象默认被阻止；显式解绑删除可一步撤销。
- 新建、复制、移动、删除、Undo/Redo 后对象索引无重复、无漏项、无跨 Scene 串联。
- Prefab 资产及其他实例不因实例参数编辑改变。

## 稳定身份与房间重置

- 颜色钥匙、普通收集品在放置时获得稳定身份。
- 单对象移动、区域整体移动、改名、换父容器后稳定身份字符串不变。
- 复制对象获得新作者 ID，不复制已收集/已消费身份。
- `RoomResetObject.regionId` 与作者区域一致；跨区显式重绑后更新，普通搬运运行时不改归属。
- R、死亡、离区只恢复相关区域；门、保持按钮、已拾钥匙、收集品和锚点遵守现有 Persistent 规则。
- 颜色首把/第二把钥匙、玩家能力、万能方块、接触方块与生成物继续满足颜色系统 Skill。

## 参数与引用

- 现有自定义 Inspector 的中文分组、条件显隐和只读状态在 Overlay 嵌入后仍可用。
- 改实例参数只生成 Scene Prefab override；保存重开保持，恢复默认只影响该实例。
- 门与按钮双方引用一致，删除/解绑不会留下单边引用。
- 平台的 linked controls、曲柄、基座、PlatformMount 在移动、Undo、保存重开后仍指向原对象。
- 平台路线以作者 Transform 为原点；区域平移只平移整条路线，不改变距离、方向、速度或进度参数。
- 关系线只在 Editor 绘制，不进入 Scene Hierarchy 或构建。

## 区域整体移动

准备包含房间、通道、墙、水、道具、门按钮、平台曲柄、钥匙、收集品、标记、装饰和美术的测试区域：

- 预览清单与实际提交对象完全相同。
- 与未选区域碰撞时整笔拒绝，零写入。
- 受保护全局对象不会因位置落在区域内被带走。
- 选中多个相邻区域时内部引用无警告，跨选区引用明确列出。
- 提交后区域格、Transform、Cell、父容器、regionId 和已认领美术使用同一格增量。
- 作者 ID、作者局部格、实例参数和 Unity 引用逐项不变。
- 一次 Undo 完整恢复；Redo 再次得到字节/字段等价结果。
- 未认领旧美术和全局背景/天气保持原位。

## GridArt

- 打开/关闭美术模式、切层/笔刷、只导航时 Map、Scene、生成资产哈希不变。
- 普通笔画、矩形、擦除、旋转、大笔刷、自动地形各一个 Undo 组。
- 笔画只修改当前未锁定可见层；自动层拒绝手绘。
- 重复写入相同格是空操作，不增加 revision、不保存、不重建。
- 只重建受影响的 32×32 块；未变 Mesh/Material GUID、时间戳和内容哈希不变。
- `GridArtScene.IsBuiltFor` 相同时 Apply 完全零写入、Scene 不 dirty。
- Undo/Redo 后 Map、归属表、网格和画面一致。
- 新笔画跟随当前区域时产生稀疏归属；擦除清理归属；跨层同坐标不串归属。
- 旧美术认领先预览；取消零写入；确认只添加清单项，不改格内容。
- 区域移动只移动已认领锚点；大笔刷跨边界按锚点策略显示警告，不暗中拆笔刷。
- 自动墙地层在真实墙体移动后更新；手绘层不被同步覆盖。

## 性能

使用正式量级副本验证：

- 3000+ 作者标记建立索引不在每个 Repaint 重扫 Scene。
- 鼠标移动/网格 Hover 不分配随对象数线性增长的 GC。
- 区域选择和框选使用索引，不逐格对全部对象调用 `FindObjects`。
- 1.38 万美术格的一格笔画不全量重建所有层/块。
- SceneView 远距离裁剪工具仍只调用 `SceneVisibilityManager`，不改变索引所有权或作者数据。

记录测试机器、Unity 版本、对象/格/块数量、中位数和最坏耗时；不把静态推断表述为实际性能通过。

## 正式 Scene 放行

在任何正式写入前：

1. 重新记录 `Gaming.unity`、GridArt Map 和依赖哈希。
2. 只读打开新 Overlay，执行零写入矩阵。
3. 输出缺失 ID、重复 ID 组、区域歧义、空引用和美术归属报告；报告不得自动修复。
4. 在隔离副本执行一次代表性区域移动及 Undo/Redo，核对全部关系。
5. 运行 Editor 编译、相关 Editor tests、房间/颜色/收集品/机关专项和最小 Play Mode 冒烟。

只有这些通过后，才能由作者在正式 Scene 执行真实编辑。交付说明必须区分：静态核对、Editor 自动化、SceneView 人工操作、Play Mode、完整通关和构建，未执行项明确写出。

## 旧工作流退役

- 新克隆删除/移走 planning JSON 后仍能打开、编辑、保存、运行和构建。
- 没有菜单、快捷键、窗口恢复逻辑或自动同步重新打开 PlanningCanvas。
- 没有 Runtime/正式 Editor 路径读取 `PlanningDocument` 或把 Scene 回写 JSON。
- 提交 hook 不再要求三份规划；改为检查 Scene、GridArt Map/归属资产及新增依赖完整性。
- 当前文档不再指导存档槽、片段导入导出、JSON 合并或“应用到场景”。
- Legacy 回读工具如暂留，必须显式标记只读/一次性、默认隐藏、无自动执行路径。
