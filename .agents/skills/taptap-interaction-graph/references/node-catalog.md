# 交互节点速查

| 类别 | 节点 | 用途 |
|---|---|---|
| 触发 | 玩家进入 / 玩家离开 | 进入、离开目标物体的玩家事件 |
| 触发 | 物体触碰 / 物体停留 | 具体物体之间的接触关系 |
| 触发 | 经过时间 | 物体注册后延迟启动一次 |
| 触发 | 手动执行 | 脚本、Timeline、颜色解锁等外部入口 |
| 条件 | 本物体 | 保留物体自身语义，适合扩展图和复用链 |
| 条件 | 需要玩家 | 确认 actor 是玩家 |
| 条件 | 需要其他物体 | 确认碰撞/触碰来源是另一个交互物体 |
| 条件 | 受到颜色 | 比较另一方的当前颜色属性 |
| 条件 | 受到物体 | 比较另一方 `ObjectId` |
| 调度 | 延迟执行 | 等待指定秒数后继续 |
| 表现 | 褪色 / 恢复 | 调用 HSV 颜色层服务，值填颜色 ID，秒数填时长 |
| 表现 | 播放 Timeline | 用引用的 PlayableAsset 或来源物体上的 Director 播放 |
| 执行 | 调用方法 | 值填方法名，可选 GameObject 或字符串参数 |
| 属性 | 设置当前颜色 | 修改来源物体的当前颜色属性 |
| 调试 | 输出日志 | 值填日志内容 |

节点是顺序执行图，不是自动推断规则。一个节点如果没有从触发器连入，就不会执行；多个触发器可以分别连接到同一效果节点。
