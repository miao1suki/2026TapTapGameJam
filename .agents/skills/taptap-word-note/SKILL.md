# 玩家提示与设备文案入口

本 Skill 是玩家屏幕提示和按键说明的强制入口。

## 开始前必须读取

修改 `WordNoteUI` 或任何全局提示消息前，完整读取：

`Assets/_Project/Code/Systems/WordNote/SKILL.md`

如果改动同时涉及搬运、颜色物、复活或关卡编辑器道具，还必须读取对应的 `taptap-color-gameplay` 规范。

## 唯一画布

- 全局提示使用 `Systems_UI` 中与 `GameUI` 同级的 `WordNote_UI`。
- 不要把新的全局提示 Canvas 放进关卡、Bootstrap 或临时脚本创建的 Canvas。
- 不要为此新增第二个 `EventSystem`。
- `WordNoteUI` 维护一个总队列、九个位置队列，并为每条消息创建独立文本视口。

## 设备文案规则

所有含按键的提示必须根据当前设备生成，禁止写死键名：

- 电脑键鼠或手柄：显示当前真实绑定，并放进中括号。
  - 例：`按[R]以复活`
  - 例：`按[Q]/[E]将方块放置在左/右侧`
- 手机或触屏：不显示物理键名，改成动作语义。
  - 例：`按下复活以复活`
  - 例：`按下放置左侧以放置方块`
- 设备判断统一使用 `GameInput.ActiveDeviceMode` 和 `GameInput.PlatformMode`。
- 文案拼接统一使用 `InputPromptUtility` 与 `InputBindingDisplayUtility`。
- 手柄优先读取手柄绑定；键盘鼠标读取键盘/鼠标绑定。

## 颜色

- 普通消息可选择红、橙、黄、绿、青、蓝、紫。
- 系统提示还允许白、黑。
- 当前搬运提示、非法提示、复活提示统一使用白字黑描边。
- `WordNoteStyle.richText` 控制 TMP 富文本；需要局部颜色时用 `<color=#RRGGBB>...</color>`。

## 当前固定消息规则

### 搬运提示

- 位置：居中下方分区。
- 模式：长期驻留。
- 堆叠：参与位置队列堆叠。
- 入场/退场：显隐，各 `0.5` 秒。
- 白字黑描边。
- 玩家死亡、放下、复位或任何退出搬运状态时统一强制关闭。

### 非法放置提示

- 文本：`位置非法，请留出足够空间`
- 位置：居中下方分区。
- 模式：显示 `2` 秒。
- 入场：显隐 + 左移。
- 退场：显隐 + 右移。
- 移动距离短，时长各 `0.5` 秒。
- 白字黑描边。

### 复活提示

- 位置：屏幕正中。
- 模式：长期驻留。
- 入场/退场：无动画。
- 字体很大，白字黑描边。
- 只在玩家死亡后出现，按下复活后消失。

### 染色反馈

- 玩家持有待用颜色并点击无效目标时显示 `这个物体好像不能与这个颜色反应`。
- 点击目标超出交互范围时显示 `无法触碰到这个物体`。
- 颜色成功应用到目标时显示 `染色成功`。
- 两条消息都与非法放置提示共用居中下方、显示 `2` 秒、显隐与左移入场、显隐与右移退场、白字黑描边和堆叠规则。
- 点到 UI、没有持有待用颜色时不显示染色反馈。

## 堆叠与动画

- 同一位置的后续消息显示在上一条下方，公共间距由 `stackSpacing` 控制。
- 上一条消失后，后面的消息通过 DOTween 向上补位。
- `participateInStackLayout = false` 的消息固定站在第一位置，不占堆叠序号，也不影响其他消息。
- 入退场支持四条独立组合通道：显隐、水平移动、竖直移动、缩放。
- 方向、距离、时长、初末速度、变速指数均可编辑。
- 支持打字机通道：入场逐字显示，退场逐字消失，打字速度由 `typewriterCharactersPerSecond` 控制。
- 新动画一律使用 DOTween。

## 选色提示

- 玩家选择颜色后，显示 `当前选择X色`，其中 `X` 使用颜色目录的显示名。
- 位置为居中下方，显示 `2` 秒，显隐与左移组合入场、显隐与右移组合退场，各 `0.5` 秒，白字黑描边。
- 颜色词使用 `ColorCatalog.displayName`，并用该颜色的 `swatch` 作为 TMP 富文本颜色；其余文字保持白色。
- 再次选择其他颜色时替换旧提示；颜色被消费后不强制截断，让本次提示按 2 秒自然结束。

## 可搬运物提示

- 当前搬运候选队列第一名的物体，其正中心显示搬运提示。
- 使用与系统提示一致的 `Cubic_11 SDF` 字体。
- 样式固定为黑字白描边；当前字号为 `2.7`，描边宽度保持克制，避免黑字发灰。
- 渲染必须高于场景和玩家：使用最高 Sorting Layer、最大 Sorting Order、高 Render Queue，并让 TMP 的 ZTest 为 Always。
- 电脑或手柄显示当前交互键，按键单独一行，再下一行显示“搬运”，每行居中。
- 手机或触屏只显示 `搬运`。
- 不显示在队列后面的物体会在队列刷新时隐藏。
